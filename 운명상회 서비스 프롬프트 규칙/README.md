## 상태 표기

- **확정**: 현재 프롬프트, 서비스 코드, 상품·라우트 코드에서 직접 확인한 값.
- **관찰**: 화면 자산이나 기존 운영 기록에서 보이지만 프롬프트 계약으로 고정되지 않은 값.
- **편집 초안**: 서비스 차별화를 위해 제안한 값. 승인 전에는 운영 사실로 취급하지 않는다.
- **미정**: 현재 코드에 계약이 없고 추정해서는 안 되는 값.

## 가장 중요한 현재 결론

- 20개 서비스 모두 전용 목소리 프롬프트가 있다.
- **페르소나 성별은 `saju_master`의 기존 남부대공 운영 기록 외에는 코드상 명시 계약이 없다.** 옷, 색, 이미지 분위기만 보고 성별을 확정하지 않는다.
- 서비스별 전체 해석 단위는 1개부터 70개까지 차이가 크다.
- **PDF는 현재 브라우저 인쇄 기반이라 고정 페이지 수 계약이 없다.** 해석 단위 수와 PDF 장수는 같은 값이 아니다.
- 따라서 먼저 페르소나와 편집 장수를 승인한 뒤, 그 값을 코드의 단일 계약으로 옮기는 순서가 안전하다.
