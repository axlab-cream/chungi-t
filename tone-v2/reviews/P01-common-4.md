# P01 공통 규칙 §4 검수 — 유료 해석의 밀도

검수일: 2026-09-12

## 판정 범위

- ZIP-003-036, 043, 046은 제목·개정 메모 표지·후속 조항 참조이므로 REFERENCE/PASS다.
- ZIP-003-037~042, 044~045는 생성 결과의 내용과 항목 간 관계를 바꾸는 ACTIVE 규칙이다.
- 정적 검출과 생성 후 차단은 구현했지만 실제 제공자 출력 전체를 의미 단위로 감수하지 않았으므로 ACTIVE 규칙은 IN_PROGRESS로 유지한다.

## 구현 계약

`reviewPaidSectionDensity()`는 각 생성 항목에 다음 네 요소가 관찰 가능한지 확인한다.

1. hook이 질문을 그대로 반복하거나 되묻지 않는 직접 답인가.
2. 본문에 개인 진술·관찰·계산 또는 답을 만든 판단 조건이 있는가.
3. 독자가 알아볼 수 있는 구체적 생활 장면이나 명시적으로 구분된 가상 장면이 있는가.
4. 유지·비교·대화·기록·관찰·선택 등 다음 판단 기준이 있는가.

생성 저장 직전의 기존 길이·문체·사실·코퍼스 검수와 함께 실행한다. 네 요소 중 하나라도 없으면 해당 시도는 저장 완료로 처리하지 않는다.

## 반복 구조와 평온한 사용자

- `문제 → 경고 → 해결`과 `결론 → 근거 → 놓친 것 → 권고`처럼 명시적 레이블로 만든 편집 프레임이 완료된 형제 항목과 같으면 실패한다.
- 입력이 만족·안정·문제없음 상태인데 `실제로는 숨은 위기` 같은 반전 위기를 만들면 실패한다.
- 프롬프트에도 같은 편집 틀을 복사하지 않고 평온한 입력에 억지 위기를 만들지 말라는 조건을 넣었다.

## 검증 한계

- 이 검사는 정규식 기반 최소 하한선이며 답의 정확성, 장면의 공감도, 조언의 실효성 또는 예측 정확성을 보장하지 않는다.
- 레이블 없이 같은 논리 순서를 바꾸어 반복하는 경우와 70개 항목 전체의 체감 중복은 실제 완성 리포트 평가가 필요하다.
- Production 배포, 기존 코퍼스/RAG 전환, 실제 OpenAI 생성, 릴리스 부착은 이 슬라이스에서 실행하지 않았다.
