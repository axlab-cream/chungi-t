# 운명상회 Tone V2 말투·캐릭터 게이트

## 문제

서비스 말투 정의가 있어도 생성문은 같은 종결어미를 반복하거나, 재미를 위해 근거 없는 화자 설정과 과장된 무속 연출을 만들 수 있다. 옛 규격에는 하게체와 격식체 범위가 최신 페르소나 결정과 충돌하는 문장도 남아 있었다.

## 적용한 패턴

1. 실행 기준은 최신 decision과 컴파일된 persona registry로 단일화한다.
2. 폐기된 원문 규칙은 삭제하지 않고 task index에서 `SUPERSEDED`로 보존한다.
3. 서비스별 말투 검수와 별도로 3문장 이상 동일 종결어미 반복을 차단한다.
4. 명사형 판정문은 말투 판정에서 제외하되 주변 발화 문장은 계속 검수한다.
5. 화자 나이·출신·경력·자격·초능력·과거의 임의 생성과 비하·유아어·과장된 무속 연출·독심 표현을 차단한다.
6. 관찰 가능한 생활 장면과 작은 비유는 허용해 재미 자체를 제거하지 않는다.

## 검증

- 서비스별 최종 말투 배정, 하게체 거부, 명사형 예외를 단위 테스트로 고정했다.
- 동일 종결어미 3회는 실패하고 다양한 종결어미와 짧은 2문장 문구는 통과한다.
- 허구 설정과 유해 연출 fixture는 실패하고 생활 비유 fixture는 통과한다.

## 재사용 시 주의

정규식 게이트는 자연스러움이나 캐릭터 완성도를 증명하지 않는다. 실제 모델 출력의 의미 검수와 서비스별 샘플 평가를 별도로 수행해야 한다.
