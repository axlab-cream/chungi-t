# 운명상회 Tone V2 pass-angle 전체 목차 이어쓰기 증거

## 결과

기존 합성 격리 레코드의 1/52 상태에서 2번 항목부터 순차 실행했다. 2번 `지금이 붙는 구간인지`는 첫 시도의 장면·다음 기준 실패를 자연 repair가 고쳐 complete가 되었고, 저장 원고 재검수도 PASS했다.

3번 `밀어주는 기운 vs 잡는 기운`은 첫 시도에서 문단·결손 번역·장면·다음 기준을 실패했다. 두 번째 시도는 앞의 세 규칙을 고쳤지만 `nextCriterion` 하나가 남아 failed가 되었다. 중단 규칙에 따라 4~52번 호출은 0건이었다.

## 재사용 규칙

- 부분 완료 전체 목차를 이어 쓸 때 같은 version을 재사용하고 `--fresh`를 쓰지 않는다.
- 각 실행 전후에 읽기 전용 replay로 저장 상태와 공용 검수를 확인한다.
- 자연 repair 성공을 전체 repair 성공으로 일반화하지 않는다.
- 첫 미해결 실패 즉시 중단하며 이후 호출 0건을 기계적으로 증명한다.
- 원문과 비밀값 대신 상태, 실패 규칙, 사용량, SHA-256만 증거로 남긴다.

## 다음 좁은 진단

저장된 3번 두 번째 응답을 새 provider 호출 없이 재평가하여, 구체 대상/행동이 실제로 없었는지 또는 기존 `nextCriterion` 인식 경계가 비교형 문장에서 놓친 것인지 먼저 구분한다. 검수 완화나 모델·재시도 변경은 진단 전 금지한다.
