# 운명상회 Tone V2 항목별 고유성 게이트

날짜: 2026-09-12

## 재사용 지식

다항목 리포트에서 완전 일치만 검사하면 단어 몇 개를 바꾼 복제 문단과 동일 결론 재사용을 놓친다. 생성 저장 전 현재 항목을 완료된 형제 항목과 비교해 정규화 hook 동일성, 긴 문단의 문자 shingle 유사도, 제작용 소제목, 질문과 무관한 범용 문구 누적을 함께 확인한다.

근접 복제는 긴 문단 두 개 이상일 때만 실패시켜 공통 배경 설명 한 문단을 과잉 차단하지 않는다. 질문 핵심어 부재도 단독 실패 사유로 쓰지 않고 범용 문구 신호가 누적될 때만 적용한다.

## 예방 규칙

- 문자열 유사도 점수를 의미 정확성으로 보고하지 않는다.
- 완료된 형제 항목만 비교 대상으로 사용한다.
- 제목형 소제목은 제작 공정명이 아니라 독자가 바로 알아볼 생활 장면이어야 한다.
- 라이브 전체 리포트에서 레이블 없는 의미 중복을 별도 평가한다.
