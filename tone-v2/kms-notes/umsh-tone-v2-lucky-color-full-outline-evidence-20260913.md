# 운명상회 Tone V2 lucky_color 전체목차 실출력 증빙

## 재사용 패턴

서비스별 전체목차 실출력은 원천 파일의 SHA-256과 항목 순서를 먼저 고정하고, 고유 버전의 합성 입력을 ignored 격리 저장소에서 순차 생성한다. 첫 미해결 실패에서 즉시 중단하고, 완료 항목은 저장 당시 코퍼스 스냅샷으로 production-equivalent 검수를 다시 실행한다.

## 이번 성공 근거

- `lucky_color` 3개 원천 파일, 6개 그룹, 24개 항목의 해시·순서 계약 통과.
- 합성 격리 결과 24/24 완료, replay 24/24 통과.
- 최신 실패 시도 자체가 raw를 갖지 않아도 그보다 앞선 실패 시도 중 가장 최신 raw를 찾아 전체 검수 후 복구하도록 수정.
- 추적 증빙에는 provider 본문 대신 모델·시도·토큰 집계와 레코드/항목별 SHA-256만 저장.
- 전체 회귀 894/894, typecheck와 Vercel build 통과.

## 적용 경계

이 패턴은 Production 배포, 고객 평가, 시각·모바일·인쇄 QA 또는 릴리스 승인을 대신하지 않는다. ignored 원본 레코드가 없으면 해시 재현은 할 수 없으므로 로컬 보존 정책이 필요하다.
