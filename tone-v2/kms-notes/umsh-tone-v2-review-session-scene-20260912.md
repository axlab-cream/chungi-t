# 운명상회 Tone V2 복기 장면 경계

## 문제

실제 `pass_angle` 출력의 `다음 복기에서 ... 나눠봐`는 구체적인 검토 장면이지만 기존 장면 정규식이 인식하지 못했다.

## 검증된 해결

복기·오답 노트·마킹 검토처럼 알아볼 수 있는 세션 설정과 긍정형 관찰 행동이 같은 문장에 함께 있을 때만 장면으로 인정한다. 행동 어근만 찾으면 `기록 기준` 같은 명사형과 `기록하지 말고` 같은 부정형이 통과하므로, 활용 종결을 요구하고 가까운 부정을 차단한다. `문제...하면/에서`는 복기 설정 없는 행동 조언까지 장면으로 오인하므로 문제 단독 경로에서는 시간·장면 접미사만 허용한다.

복기 대상은 세션 표현 앞뒤 어느 쪽에 있어도 되지만, 대상과 긍정형 행동의 순서를 하나의 제한된 구간으로 묶어야 한다. 그래야 `기록해, 문제는 잊어`처럼 대상이 행동 뒤에 우연히 등장하는 문장이 통과하지 않는다. `분류하고 싶지 않아` 같은 희망·부정형은 완료 행동으로 취급하지 않는다.
