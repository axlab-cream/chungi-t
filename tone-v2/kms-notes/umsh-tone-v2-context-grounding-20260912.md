# 운명상회 Tone V2 컨텍스트 근거 판별

## 문제

생성 문장이 실제 사용자 입력의 여러 구체 사실을 재사용해도 `적었`, `근거`, `조건` 같은 편집용 표지어가 없으면 근거 없음으로 거부됐다.

## 검증된 해결

- 기존 표지어 판별은 유지한다.
- 추가 경로는 명시한 사용자 입력 필드만 읽고 `name`, `savedChat`, 서버 계산 필드는 제외한다.
- 한국어 조사와 연결어미를 정규화한 뒤 같은 입력 사실 안에서 의미 토큰이 3개 이상, 또는 2개이면서 3글자 이상 토큰이 하나 이상 겹칠 때만 인정한다.
- 서로 다른 필드의 한 단어씩을 합산하지 않는다.

## 반례

- 단일 일반론, 컨텍스트 없는 동일 문장, 여러 필드에 흩어진 단어, 이름·저장 대화만 일치하는 경우는 근거로 인정하지 않는다.

## 증거

- 캡처된 합성 문장 `연습 점수가 목표 수준이고 객관식이라...`의 변경 없는 재평가에서 grounding PASS.
- focused 57/57, compiler/task 7/7, full regression 672/672, typecheck, Vercel build, diff check PASS.
- 규칙은 결정적 하한선이며 의미상 사실 정확성이나 전체 서비스 라이브 승인을 대신하지 않는다.
