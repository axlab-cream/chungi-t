# 운명상회 Tone V2 Today Fortune 전체 출력 증거

## 결과

`today_fortune`은 공급자 생성형 서비스가 아니라 `daily-rules-v3` 계산형 서비스다. 합성 프로필로 실제 저장 경로를 실행해 7개 고객 필드를 완성하고, 같은 KST 날짜 재호출과 UUID 재열람에서 결과 본문과 식별자가 유지됨을 확인했다. 전체 5개 오행 관계와 12개 출생연도 띠 분기도 별도로 전수 실행했다.

직접 출력 검수에서 확정된 무호칭 반말체와 달리 이름+`님`, 존댓말이 남은 결함과 근거 없는 고정 조건 개수를 발견했다. 계산·점수·날짜 로직은 바꾸지 않고 새로 생성되는 고객 문구만 확정 퍼소나에 맞췄다.

## 재사용 규칙

- 계산형 서비스를 검증하려고 LLM 호출을 추가하지 않는다.
- 공급자 증거 분모는 실제 공급자 기반 서비스만 포함하고, 계산형 서비스는 전체 출력·분기·저장 증거로 별도 승인한다.
- 개인정보 보호를 위해 출력 원문 대신 레코드와 필드별 SHA-256, 개수, 검수 결과만 추적한다.
- 기존 저장 결과는 불변으로 두고, 문구 수정은 새 결과에만 적용한다.
- 퍼소나 계약은 프롬프트뿐 아니라 규칙 기반 템플릿에도 실행형 테스트로 적용한다.
