## 보강 산출물 규칙

보강 파일은 원본 source/ 밖에 만들고 origin=SUPPLEMENT, 근거 파일/행, 보강 이유, 적용 서비스, 검수 결과를 기록한다.
원본 전체 목차가 없으면 기존 서비스 구조를 출발점으로 하되 항목을 임의 삭제하지 않는다. 수정·추가 항목은 원본 대비 표를 둔다.
감수 도구는 입력 유효성, 누락·중복, 최신 말투, 금지 표현, 수치 출처, 출력 안전을 검사한다. 의미 품질은 별도의 근거 기반 검토를 남긴다.
키·고객 개인정보·운영 DB 원문은 TASK나 Wiki에 저장하지 않는다.
