Q

カップル相性には何を入力する？

+

自分の四柱推命情報と、相手の生年月日、性別、陽暦・陰暦の区分などが必要。相手の出生時刻がわかれば入力し、不明なら「時間不明」を選んでください。

Q

カップル相性で結婚していいか決まる？

+

カップル相性は、惹かれ合う理由、話し方、ケンカ、二人の付き合い方を広く見る相談だよ。結婚の正解を出すものではない。結婚生活の現実的な条件をもっと詳しく見たいなら、結婚相性の項目を比べよう。

結婚前には、住まい、お金の管理、子どもの計画、家族関係など、直接合意することが多い。相性の要約文だけで決めるより、二人が現実に答える質問を整理するために使うといい。

Q

結婚相性と結婚の日選びは何が違う？

+

結婚相性は二人の関係と結婚生活を見て、結婚の日選びは入力した挙式・婚姻届の候補日を比べる。人同士の問題と日程選びは別の質問。

一緒に暮らしていいか迷うなら結婚相性、結婚は決めて日付を比べたいなら結婚の日選びを確認しよう。日付が有利という解釈が、関係の困難をなくしたり結婚生活を保証したりするわけではありません。

Q

結婚相性でお金の管理や生活習慣も見られる？

+

お金の管理、生活費の分担、家事、それぞれに必要な時間を、実際の話し合いのテーマとして書こう。解釈と違う部分があれば、相手の実際の答えと行動を先に確認し、未合意のことを運勢で覆い隠さないで。

結婚相性の前に二人で何を話しておく？

Q

結婚相性で結婚の時期を決められる？

+

結婚のタイミングの解釈を参考にはできますが、実際の結婚時期を確定したり、相手の同意に代えたりすることはできません。準備状況と二人の計画が優先です。

経済的な準備、住まい、家族の予定で、変えられない条件と調整できる条件を分けよう。実際の候補日ができれば結婚の日選びで比較範囲を確認できるけれど、それも日程選びを助ける参考用の解釈。

Q

挙式の候補日を比べられる？

+

結婚の日選びでは、入力した候補日を比べられる。現在は最少一つから最大三つの候補を受け付けて、それぞれの条件を見る方式だよ。

会場の予約と家族の出席が可能な日から絞って入力しよう。すべての日付を検索して予約したり、会場につないだりするサービスではない。比較結果は費用・動線・予約条件と合わせて検討してください。

Q

結婚の日選びは会場も予約してくれる？

+

会場の予約や日程の確保を代行するサービスではありません。利用者が入力した候補日を比較するオンライン運勢相談です。

会場で可能な日と契約条件を先に確認し、候補がまとまったら相談に入力しよう。解釈で好ましい日が出ても、予約の可否やキャンセル費用が変わる場合があるので、最終決定前に実際の提供業者の案内を再確認する必要があります。

Q

結婚日をもう決めていても見ていい？

+

決めた日が一つでも、その日の条件や準備することを見られる。すでに決めた日を何としても変えるのではなく、何を点検すればいいか確認するために使おう。

契約や家族の予定が決まっていたら、変更費用と混乱から考えよう。注意条件があるという説明だけで日付を取り消す理由になるわけではありません。実際に準備できる動線・日程・役割分担などは、別に整えてください。

Q

韓国伝統の「ソンのない日」と結果が違うとき、何を基準にする？

+

韓国伝統の「ソンのない日」と命式・候補日の条件は、別の視点。一つの基準がほかの基準に常に代わると考えるより、それぞれがどんな根拠を説明するか区別しよう。

家族が大切にする伝統、会場の空き日、費用、移動条件も合わせて書こう。サービスの条件比較は日を選ぶ参考資料で、結婚の成否を予言したり、すべての伝統的基準を判定したりする道具ではない。

Q

候補日を変えると結果も変わる？

+

候補日を変えれば比較対象も変わる。以前の候補同士の結果を、新しい日にもそのまま当てはめることはできません。

候補が正しいか支払い前に確認し、購入済みなら、既存の注文とは違う入力として扱われるか見よう。相手情報や候補日を変えた後に新しい支払いが必要か迷ったら、再決済前に注文と変更内容をサポートへお問い合わせください。
