# 운명상회 운영 관리자 실행 패키지
버전 1.0 | 작성일 2026-09-10 | 대상 서비스 https://umsh.kr | 문서 언어 한국어

## 목적
콘텐츠, 20종 서비스, 주문·결제·환불, 회원·CS, 리포트 생성, 코퍼스·프롬프트, 로그·분석을 하나의 운영 관리자에서 관리한다. 이 ZIP은 **구현할 LLM에게 주는 명세**다. 완성된 관리자 앱이나 자동 배포 프로그램은 포함하지 않는다.

## 즉시 실행
원본 운명상회 저장소를 작업 공간으로 열고 이 폴더를 docs/admin-ops-spec에 두거나 별도로 연결한다. LLM에게 [01-LLM-EXECUTION.md](01-LLM-EXECUTION.md)의 실행 프롬프트를 전달한다. 저장소가 없으면 UI 목업만으로 완료했다고 보고하지 말고 원본 연결이 필요한 항목을 기록한다.

## 범위와 사실 구분
- 확인됨: 이번 로컬 소스 또는 읽은 WIKI에서 확인한 사실.
- 부분 확인됨: 기록은 있으나 현재 운영 실검증이 없는 내용.
- 근거 부족: 구현·데이터·외부 연동 여부를 이번 조사에서 확인하지 못한 내용.
- 신규 제안: 구현 대상. 현재 기능으로 설명하면 안 된다.
- 충돌 있음 / 최신화 필요: 과거 기록과 현재 코드가 다르거나 운영 대조가 필요한 항목.

문서의 모든 신규 /admin 및 /api/admin 경로, 역할, KPI 목표, 신규 테이블은 제안이다. 현재 운영 매출·사용자 수·환불 성공·성능 수치는 조사하지 않았다. 원본 소스·개인정보·비밀 환경변수는 ZIP에 포함하지 않는다.

## 패키지 검증
MANIFEST.json에는 각 문서의 바이트 수와 SHA-256이 있다. 파일은 UTF-8이다. Mermaid는 도표 렌더러가 없어도 텍스트로 읽을 수 있다. 모든 내부 문서 링크는 상대 경로다.
