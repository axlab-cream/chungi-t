## 구현 전 확인 항목
PG 취소 API/서명/망 취소·부분취소 지원, 직원 MFA 가능 상태, 실제 migration 경로, DB 테이블·grant·RLS, 고객 탈퇴 흐름, 기존 행동 계측, 로그 수집원, 실사용 미디어 저장소.
각 항목은 전체 작업 중단 사유가 아니다. 의존 없는 작업을 계속하고 영향 task만 blocked로 표시한다.
