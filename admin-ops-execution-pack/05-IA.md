# 관리자 IA
제안 기본 진입 /admin. 모든 경로는 신규이며 고객 GNB와 분리한다.

| 그룹 | 경로 | 목적 | 대표 조치 |
|---|---|---|---|
| 운영 홈 | /admin | 오늘의 매출·장애·처리 대기 | 담당 배정, 상세 이동 |
| 통합 검색 | /admin/search | ID 기반 교차 검색 | 주문→회원→리포트 |
| 서비스 | /admin/services | 서비스 20종·판매·노출 현황 | 상세, 미리보기 |
| 서비스 상세 | /admin/services/:key | 개요/콘텐츠/상품/품질/변경이력 | 초안, 발행 요청 |
| 콘텐츠 | /admin/content | 랜딩·배너·FAQ·고지 | 편집, 예약, 복구 |
| 미디어 | /admin/media | 이미지·영상·포스터·폰트 참조 | 업로드, 대체, 사용처 |

| 주문 상세 | /admin/orders/:id | 거래/권한/리포트/감사 타임라인 | 대사, 환불 요청 |
| 환불 | /admin/refunds | 요청·승인·PG 처리·불확정 | 승인, 재조회 |
| 대사 | /admin/reconciliation | 일별 차이·미해결 | 원인 분류 |

| 회원 상세 | /admin/members/:id | 프로필/주문/리포트/문의 | 제한 열람, 탈퇴 작업 |
| 고객 지원 | /admin/support | 문의·품질 신고·SLA | 배정, 메모, 처리 |

| 리포트 상세 | /admin/reports/:id | 항목/시도/버전/권한 | 실패 항목 재시도 |
| 생성 작업 | /admin/jobs | 대기·실행·실패·비용 | 취소 가능성 확인, 재시도 |
| 코퍼스 | /admin/corpus | 팩·블록·출처·커버리지 | 가져오기, 검수 |

| 평가 | /admin/evaluations | 고정 사례·실행·회귀 | 후보 실행, 승인 근거 |
| 배포 | /admin/releases | 콘텐츠·지식 release | 발행, 복구 |
| 분석 | /admin/analytics | 퍼널/거래/재방문/품질/비용 | 기간·서비스 비교 |
| 로그 | /admin/logs | 요청·오류·상관관계 | 추적, 장애 생성 |

## 전역 객체 연결
memberId → orderId → reportId → generationId → attemptId → promptVersion/corpusFingerprint.
requestId는 API 추적, traceId는 여러 요청·작업 연결에 사용한다. 구버전 데이터에 값이 없으면 '미기록'으로 표시한다.

## 탐색 동작
목록 필터·정렬·페이지는 URL query로 저장한다. 상세에서 뒤로 가면 목록 위치를 복원한다. 상대 서비스 링크는 umsh.kr 절대 URL로 구성하고 새 창으로 열며 noopener noreferrer를 적용한다. 관리자 미리보기는 비공개·만료 토큰을 사용하고 검색엔진에 노출하지 않는다.

## 공통 리스트 규격
기본 25개, 최대 100개. 날짜·상태·서비스·환경·담당자 필터. 날짜는 KST 선택, UTC 전달. 긴 제목은 상세에서 전체 확인 가능하며 단어 단위 줄바꿈을 쓴다. 표를 의미 없이 카드로 변환하지 않는다.
