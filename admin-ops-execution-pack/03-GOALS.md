# Goal 및 성공 지표
아래 수치는 성과 주장이 아닌 **초기 목표안**이다. 운영 기준값은 계측 후 확정한다.

## 북극성 목표 G01
결제한 고객이 정상 리포트를 받고 다시 열 수 있도록, 운영자가 문제를 발견하고 해결하는 시간을 줄인다.
측정: PG 승인 주문 중 제한시간 안에 구매 권한·리포트 제공이 확인된 주문 비율. 유효 주문의 정의는 12에서 고정한다.

| 목표 | 기준값 | 제안 목표 | 측정·완료 기준 | 연결 |
|---|---|---|---|---|
| G01 제공 신뢰성 | 미측정 | 승인 후 10분 내 제공율 99% 이상 | 주간, 서비스별; 생성 시작 조건 별도 | R04,R06 / M2 |
| G02 CS 조사 효율 | 미측정 | 주문·회원·리포트 추적 중앙값 3분 이내 | 합성 사고 10건 운영자 실습 | R03,R05 / M1 |
| G03 변경 추적 | 미측정 | 운영자 변경 감사 기록 100% | 변경 요청과 감사 event 전수 대조 | R01,R11 / M1~ |
| G04 금융 정합성 | 미측정 | 설명 없는 대사 차이 0건 | D+1 PG·주문·환불 비교 | R04 / M2 |
| G05 콘텐츠 안정성 | 미측정 | 발행물 버전·승인·복구 100% | 발행 10건 회귀 | R02,R07 / M3 |
| G06 RAG 품질 | 고정 평가셋 없음 | 20종 최소 10사례씩 200사례 | 금지 일반화 중대 위반 0, 나머지 11 기준 | R07,R08 / M3 |
| G07 진단 시간 | 미측정 | 탐지 후 5분 내 원인 영역 식별 | PG·저장소·생성 장애 훈련 | R09,R10 / M2 |
| G08 개인정보 절제 | 미측정 | 일반 운영 로그 원문 PII 0건 | 수집 전 차단·샘플 검사 | R05,R09 / M1~ |

## 목표 해석
소표본 서비스는 건수를 같이 표시하고 순위를 숨긴다. 계측 이전 기간을 0으로 채우지 않는다. 콘텐츠 매력도는 서비스 진입→미리보기→구매 전환과 CS 품질 불만을 함께 관찰한다. 전환율 증가만으로 해석 정확도나 명리 예측력을 주장하지 않는다.

## 비목표
고객 사이트 전체 재디자인, PG 교체, 구독·포인트·정산 회계 ERP, 고객 원문 자동 코퍼스 편입, 완료 결과 일괄 재생성, 운영 시스템 자동 배포는 이번 기본 범위에 포함하지 않는다. 확장은 별도 요구와 ADR로 추가한다.
