## 막힌 이유

- 결제와 통화: 지금 가격은 숫자 유지 `9,900 KRW`다. 엔이나 달러로 바꾸면 청구 금액이 바뀐다.
- 해외 출생 시간: 계산은 한국 시간 기준이다. 언어 화면과 출생 시각 계산을 섞으면 사주가 틀린다.
- 공식 브랜드명: Fortune Shop / 運命商会는 작업용 임시명이다. 확정 이름이 아니다.
- DB 쓰기: 운영 고객 원문과 구매 기록을 덮지 않는다.
- 실제 모델 호출: 현지 말맛 규칙은 프롬프트에 연결만 됐다. 실출력 확인은 유료 호출이라 대표 확인 전이다.
