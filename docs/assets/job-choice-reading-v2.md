# 직장 선택 저장 해석 실사 이미지 v2

## 결정

- 직장 선택 저장 해석의 요약은 `00-job-choice-summary-v2.webp` 한 장을 사용한다.
- 요약 이미지는 3:2 가로 실사이며 `summaryImageFit: wide`로 원본 비율을 유지한다. 인물 머리만 남는 크롭을 피하기 위해 상반신, 손, 문서와 업무 환경이 함께 보이는 구도로 만들었다.
- 21개 세부 목차에는 역할·상사·보상·평가·출퇴근·원격·소진·입사 시점·정착·결정에 맞는 서로 다른 실사 WebP를 하나씩 사용한다.

## 배치 계약

- 공개 파일: `사주/work/job-choice/assets/job-choice/reading-v2/`
- 설정 원본: `사주/data/longform-blocks.json`의 `services.job_choice.sectionImages`
- 수량: 요약 1장 + 목차 21장. 목차끼리는 중복하지 않는다.
- 크기/형식: 모든 파일 1536×1024, WebP. 삽입형 저장 해석은 3:2 프레임으로 표시한다.
- 대체 금지: 저장 리포트의 개인값, 회사명, 문서 내용, 인물 식별 정보는 이미지에 넣지 않는다.

## 표현 규칙

- 톤: 절제된 네이비와 따뜻한 골드 조명, 실제 한국 업무 환경의 편집 사진.
- 금지: 일러스트, 점성/별자리 장식, 로고, 읽을 수 있는 문서 텍스트, 얼굴만 크게 잡은 크롭.
- 본문은 공용 마크다운 블록의 한 줄 답·근거·행동 위계를 사용하고, 토글은 `펼치기 +`/`접기 −`로 상태를 명확히 알린다.

## 검증

- `node scripts/check-jobchoice.mjs`는 wide 요약 모드, 21개 이미지 수, 중복 여부, 공개 경로와 파일 존재를 확인한다.
- `tests/unit/all-service-reading-template.test.ts`는 공용 렌더러가 직장 선택을 대표 단일 이미지 모드로 취급하지 않는지와 삽입형 스타일 계약을 확인한다.
