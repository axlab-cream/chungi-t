# ADR-0001: Project Structure

## Status

Proposed

## Context

The project needs a shared structure for product docs, AI agent configuration, tests, prompts, evals, scripts, and generated outputs.

## Decision

Use the CreamAI AIOS structure created by SETUP. Preserve existing files and add only missing folders or starter documents.

## Consequences

Agents and humans can resume work from the same operating documents without relying on a single chat session.
