# 고객 화면 오류 코드 규정

2026-10-08 시작. 회원이 고객센터에 **오류 코드만 알려 주면** 운영자가 원인을 바로 알 수 있게, 고객 화면의 모든 오류 문구에 코드를 붙인다.

## 규칙

1. **모양:** `화면 약자-두 자리 숫자`. 예: `PRF-01`.
2. **번호 구간**
   - `01~09` 입력 칸 오류. 해당 칸 바로 아래에 띄우고, 칸 테두리를 빨갛게 표시한다(`aria-invalid`). 고쳐 쓰는 순간 지운다.
   - `10~19` 로그인·권한 오류
   - `20~29` 저장 실패(서버 오류, 인터넷 끊김)
   - `30~39` 불러오기 실패
3. **문구:** 무엇이 문제인지와 어떻게 하면 되는지를 함께 쓴다. 서버·연결 오류는 "계속되면 고객센터에 오류 코드를 알려 주세요"로 끝낸다.
4. **자리:** 칸 오류는 칸 아래, 나머지는 저장 버튼 아래 상태 줄. 여러 칸이 틀리면 모두 표시하고 첫 칸으로 커서를 옮긴다.
5. **서버 문구:** 서버가 한국어 문장으로 거절하면 화면이 문장을 코드로 바꿔 같은 자리에 띄운다. 코드를 바꾸거나 새로 만들면 이 문서와 화면 코드를 같이 고친다.
6. **코드는 바꾸지 않는다.** 이미 나간 코드의 뜻을 바꾸면 고객센터 기록과 어긋난다. 없앤 코드는 번호를 다시 쓰지 않는다.

## 화면 약자

| 약자 | 화면 | 코드 위치 |
|---|---|---|
| `PRF` | 마이페이지 › 사주 프로필 수정 (`/profile`) | `사주/js/profile.js` `ERRORS` |

## PRF · 사주 프로필 수정

| 코드 | 자리 | 문구 | 원인 |
|---|---|---|---|
| PRF-01 | 이름 칸 | 이름을 입력해 주세요. | 이름이 비어 있음 |
| PRF-02 | 이름 칸 | 이름은 한글 2자 이상 20자 이하로 입력해 주세요. | 영문·숫자·한 글자 이름. 예전 경로로 영문 이름이 저장된 회원은 화면을 열 때 바로 표시 |
| PRF-03 | 생년월일 칸 | 생년월일을 입력해 주세요. | 생년월일이 비어 있음 |
| PRF-04 | 생년월일 칸 | 생년월일을 다시 확인해 주세요. 1900년 1월 1일부터 오늘까지만 저장할 수 있어요. | 1900년 이전·미래 날짜, 서버가 날짜를 거절 |
| PRF-05 | 태어난 시각 칸 | 태어난 시각을 입력해 주세요. 모르면 "시간 모름"을 눌러 주세요. | "시간을 알아요"인데 시각이 비어 있음 |
| PRF-06 | 상태 줄 | 성별을 선택해 주세요. | 서버가 성별을 거절 |
| PRF-07 | 상태 줄 | 양력 또는 음력을 선택해 주세요. | 서버가 달력을 거절 |
| PRF-10 | 상태 줄 | 로그인이 끝났어요. 다시 로그인한 뒤 저장해 주세요. | 401(로그인 만료) |
| PRF-20 | 상태 줄 | 서버에 저장하지 못했어요. 잠시 뒤 다시 저장해 주세요. 계속되면 고객센터에 오류 코드를 알려 주세요. | 500·503, 알 수 없는 거절 |
| PRF-21 | 상태 줄 | 인터넷 연결이 끊겼어요. 연결을 확인한 뒤 다시 저장해 주세요. | 요청이 서버에 닿지 못함 |
| PRF-30 | 상태 줄 | 프로필을 불러오지 못했어요. 새로고침해 주세요. 계속되면 고객센터에 오류 코드를 알려 주세요. | 화면을 열 때 프로필 조회 실패 |

### 고객센터 대응

- **PRF-02**가 계속 나오면: 이름을 한글로 바꿔야 저장된다고 안내한다. 풀이 문장에 이름이 들어가서 한글만 받는다.
- **PRF-20**이 계속 나오면: `/api/user/profile` 서버 오류다. Vercel 함수 로그에서 그 시각의 `사주 프로필 저장 실패`를 찾는다.
- **PRF-30**이 계속 나오면: 프로필 조회 실패다. 회원 번호로 관리자 › 회원 상세에서 프로필이 열리는지 본다.
