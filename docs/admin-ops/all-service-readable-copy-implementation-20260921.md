# 전 서비스 티저·해석 쉬운말 보강 결과

## 범위

- 대상: 런타임에 등록된 20개 서비스의 신규 티저와 신규 해석 본문
- 비대상: 이미 저장된 고객 리포트의 소급 재작성, 관리자 프롬프트 릴리스 수동 발행

## 적용한 공통 계약

- 중학생이 사전 없이 이해할 수 있는 쉬운 한국어를 서비스 말투보다 우선한다.
- 고객 문장에는 한자를 쓰지 않는다. 전문용어가 꼭 필요하면 쉬운 뜻을 먼저 쓰고 한글 용어만 덧붙인다.
- 티저 문장은 65자, 본문 문장은 90자를 기준으로 검사한다.
- 한 문장에 전문용어를 티저 1개, 본문 2개보다 많이 넣지 않는다.
- 불필요한 외래어와 어려운 마케팅 표현을 쉬운 한국어로 바꾼다.

## 구현

- `reviewReadableCopy`를 공통 검증기로 만들고 티저 저장 게이트와 해석 생성 검수에 함께 연결했다.
- 한자·용어 과밀·긴 문장·불필요한 외래어 지적은 완화 복구로 통과할 수 없는 차단 항목으로 올렸다.
- 결정형 해석은 정규화 단계에서 서술자 한자를 제거하되 사용자가 따옴표로 입력한 원문은 보존한다.
- 천명사주의 `문장 평균 35자 이상(장문)` 규칙을 짧은 문장·한 문장 한 생각 규칙으로 교체했다.
- 새해 흐름과 결혼 택일에 남아 있던 한자 예시를 쉬운 뜻 우선 표기로 바꿨다.
- 원본 규격을 기준으로 `tone-v2` 생성 산출물을 다시 컴파일했다.

- 집중 가독성 회귀: PASS 3/3
- 프롬프트·생성·서비스 흐름 회귀: PASS 119/119
- TypeScript: PASS
- 서비스 계약 검사: PASS, 20/20
- 전체 서비스 정적 QA: PASS, 20/20
- 전체 로컬 테스트도 실행했으나 서버 저장소 키가 필요한 항목은 환경 제약으로 실패했다. 해당 항목은 이번 변경의 집중 검증에서 분리했다.

## 운영 주의

- 코드와 생성 프롬프트 파일을 함께 반영한다. 사용자 승인에 따라 원격 push와 운영 배포를 진행하며, 관리자 프롬프트 릴리스는 별도 수동 발행하지 않는다.
- 실제 모델 출력 평가는 배포 승인 뒤 운영과 분리된 표본 생성으로 진행해야 한다.
