## 3. 챗봇 관리자센터 운영 방법 (재사용)

1. 접속: https://chatbot.kakao.com → 봇 "상주 천명". 별도 OBT 신청·승인 없이 바로 사용 가능했음(2026-10-12).
2. 문구 수정: 시나리오 → 블록 선택 → 봇 응답 텍스트 클릭 → 수정 → 확인 → 블록 **저장**.
3. 새 질문 대응: 기존 블록의 "사용자 발화"에 표현 추가(엔터) → 저장. 새 주제면 시나리오 01 "+ 블록 추가".
4. 바로연결(하단 버튼) 추가: 블록 하단 "바로연결 버튼 설정 +" → 버튼명 → 기능 "메시지 전송" → 보낼 문장(대상 블록의 발화) → 확인.
5. 반영: **배포** 메뉴 → 전체 배포 → 내용 입력 → 배포. 저장만 하면 운영 채널에 반영되지 않음. 최대 30분 소요, 배포마다 버전 +0.1.
6. 점검: 상단 "봇테스트"로 발화 입력 테스트. 운영 후 "분석"에서 폴백으로 빠진 발화를 보고 3번으로 보강.
7. 연결 해제/변경: 설정 → 카카오톡 채널 연결(운영/개발 채널). 채널은 한 번에 한 봇만 연결.

## 4. 막혔던 부분과 해결 (재발 방지)

1. **고객센터 연락처는 비울 수 없음**: 빈 값이면 저장 버튼 비활성. 전화번호 대신 이메일 입력.
2. **관리자 추가 인증 끄기**: 토글 시 문구가 "사용하시겠습니까?"로 나오고 확인하면 카카오톡 인증번호 페이지로 이동 → 인증 완료 후 다시 토글해야 "사용하지 않겠습니까?" 확인창이 뜨고 꺼짐.
3. **채널홈 저장이 조용히 실패**: 프로필 카드에 "바로가기 전체 노출 설정은 더 이상 사용할 수 없습니다. 개별 바로가기를 각각 off로…" 오류가 숨어 있었음(네트워크 요청 0건). 바로가기 최소 1개 필요 → "소식"만 켜고 마스터 ON 후 저장하니 해결. 전화하기·길찾기·카카오내비는 전화번호/매장이 없어 켤 수 없음.
4. **소개 문구 줄바꿈은 1회만** 허용.
5. **커스텀 메뉴 등록 순서**: 메뉴 편집 → "임시저장" → "상시노출 메뉴 등록" → 확인 → 상단 "커스텀메뉴 사용" ON. 임시저장 전에는 등록 버튼이 비활성.
6. **소식 링크 상자(미리보기)는 발행 후 수정 불가** ("링크, 동영상은 수정할 수 없습니다"): 새 글로 재발행 → 공지 카드 교체 → 이전 글 삭제.
7. **브랜드 카드 순서 변경은 드래그가 안 먹음**: 앞 장을 삭제하고 다시 추가(영상은 업로더 "불러오기"로 재사용)해서 순서를 맞춤.
8. **챗봇 이름에 괄호 불가**: "상주(천명)" → 관리자 이름 "상주 천명", 손님용 카드 제목에 "운명상회 상주, 천명".
9. 챗봇 카드 이미지는 필수, 최대 500KB, 와이드 800×400 권장. 텍스트 응답에 버튼을 달면 400자 제한.
