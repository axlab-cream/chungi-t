# 리포트·티저 독해 난이도 진단 브리핑 (2026-09-21)

## 결론

현재 코퍼스와 프롬프트는 근거성·안전성·서비스 말투를 제어하지만, 고객 문장을 **중학생이 한 번에 이해할 수준**으로 보장하지 않는다. 전문용어의 첫 등장 설명과 한자 형식 검사는 있으나, 쉬운 어휘·짧은 문장·용어 밀도·티저 독해 난이도는 완료 게이트가 아니다. 따라서 전문용어와 한자가 설명 형식을 지켰더라도 문장은 여전히 어렵게 통과할 수 있다.

## 확인한 현재 동작

- 운영 코퍼스 `tone-v2.2.0.20`의 28개 팩은 검색 근거다. 서비스별 판단 근거와 고급 명리 자료를 제공하지만 고객 난이도를 직접 설정하는 값은 없다.
- 운영 프롬프트 `tone-v2.20260910.1`은 실제 생성 런타임에 연결되어 있으나 `검수 진행 중`이다.
- 공통 규칙은 첫 전문용어를 `한글(한자, 쉬운 뜻)`으로 설명하도록 요구한다.
- 서비스별 페르소나 가운데 결혼 택일만 `쉬운 한국어, 짧은 문장`을 명시한다. 천명사주는 반대로 `문장 평균 35자 이상(장문)`을 명시한다.
- 관리자 발행본이 있으면 배포 파일보다 우선한다. 2026-09-21 운영 화면 기준 공통 규칙 발행본은 없고, 서비스 발행본은 커플궁합 1건만 확인됐다.
- 티저 검수는 근거·대표 장면·유료 범위·안전 문구를 검사하지만 전문용어, 한자, 문장 길이, 쉬운 어휘는 검사하지 않는다.
- 전체 리포트의 전문용어 검수도 핵심 6개(오행·용신·신강·신약·합·충)에 집중한다. 별도 품질 점수는 더 넓은 용어 목록을 보지만 180자를 넘는 문장부터 장문으로 센다.
- 생성 재시도 뒤에도 한자 설명·단락·문장 구조 같은 문체 지적만 남으면 `lenient` 완료 처리할 수 있다.

## 실제 티저 근거에서 드러난 문제

2026-09-14의 19개 유료 서비스 티저 평가는 모두 PASS였지만 독해 난이도는 평가 항목이 아니었다. 그중 실제 제공자 출력은 5개 서비스였고 14개는 production-template-qa였다.

- 새해 흐름: `세운`, `정미`, `일간`, `정인`, `편인`, `입춘`, `경칩`이 짧은 티저에 함께 등장한다. 표본 최장 문장은 87자였다.
- 이직운: `일간(日干, 태어난 날을 나타내는 두 글자 중 첫 글자)`처럼 설명 자체가 길다.
- 운 붙는 색: `오행(五行, 다섯 기운)`과 소수 점수를 한 문단에 함께 제시한다.
- 배우자운: `배우자궁`이 쉬운 말로 먼저 번역되지 않는다.
- 관계·돈·직업 티저에는 `케미`, `핏`, `DNA`, `유지각`, `N잡` 같은 외래어·유행어가 섞여 대상 독자에 따라 난이도가 올라간다.
- 표본의 최장 문장은 여러 서비스에서 76~87자였다. 현재 티저 PASS는 이 길이를 실패로 보지 않는다.

## 원인

1. **코퍼스와 고객 문장 경계가 불완전하다.** 고급 근거를 내부에서 쓰는 것은 맞지만, 검색 결과를 일상어로 번역하는 출력 계약이 느슨하다.
2. **형식 검사가 이해도 검사를 대신한다.** `한글(한자, 쉬운 뜻)` 모양만 맞으면 쉬운 뜻이 실제로 쉬운지, 한 문장에 개념이 몇 개인지는 보지 않는다.
3. **서비스 말투가 공통 독해 목표보다 우선한다.** 천명사주의 장문 지시처럼 캐릭터 규칙이 난이도를 올린다.
4. **티저 전용 가드에 독해 검사가 없다.** 본문에서 뽑은 문장이 안전하고 근거가 있으면 길고 어려워도 티저가 된다.
5. **문체 결함은 최종 차단 대상이 아니다.** 반복 실패를 줄이기 위한 `lenient` 복구가 독해 결함도 허용한다.
6. **평가 증거가 실제 출력 전체를 대표하지 않는다.** 19종 PASS 중 14종이 템플릿 표본이며, 중학생 독자 평가나 실제 제공자 전수 표본이 없다.

## 보강안

### P0 — 공통 쉬운말 계약과 차단 게이트

- 공통 프롬프트에 `중학교 1~3학년이 사전 없이 이해`, `쉬운 말 먼저`, `한 문장 한 생각`, `전문용어는 꼭 필요할 때만`을 명시한다.
- 고객 문장은 `쉬운 뜻(전문용어)` 순서로 쓴다. 한자는 기본적으로 숨기고, 학술적 확인이 꼭 필요한 경우에만 별도 용어 도움말로 둔다.
- 티저에는 전문용어 최대 1개, 문장당 전문 개념 1개를 기본 상한으로 둔다. 첫 화면은 전문용어가 없어도 뜻이 완성되어야 한다.
- 티저 문장 길이는 목표 45자 이하, 65자 초과는 자동 재작성 대상으로 시작해 실제 사용자 평가로 보정한다.
- `reviewTeaser`와 본문 검수에 쉬운말 사전, 외래어·유행어 대체, 문장 길이, 접속절 수, 전문용어 밀도를 추가한다.
- 설명 없는 한자, 티저 과밀, 핵심 전문용어 미번역은 `lenient`에서 허용하지 않는 차단 이슈로 승격한다.

### P1 — 서비스별 난이도 정렬

- 천명사주의 `35자 이상 장문`을 폐지하고 `격식은 유지하되 짧은 문장`으로 바꾼다.
- 새해 흐름·천명사주·이직운·운 붙는 색을 1차 우선 서비스로 잡는다. 명리 용어와 한자가 실제 티저에 가장 직접 노출된다.
- 결혼 택일의 `쉬운 한국어, 짧은 문장` 규칙을 공통 최소선으로 올리고, 서비스별 말투는 그 위에서만 변주한다.
- `케미/핏/DNA/N잡/유지각`은 대상 독자가 바로 아는 경우가 아니면 `잘 맞는 점/맞는 조건/돌봄 습관/부업/유지할 조건`으로 바꾼다.

### P2 — 실제 출력 평가와 운영 가시성

- 20개 서비스마다 정상·정보 부족·복합 조건 3개 시나리오를 실제 제공자로 생성해 최소 60개 티저와 첫 3개 본문 항목을 평가한다.
- 평가 항목에 `전문용어 없이도 핵심 이해`, `문장 재독 필요 없음`, `한자 도움 없이 의미 완성`, `중학생 독자 80% 이상 이해`를 추가한다.
- 관리자 평가 화면에 서비스별 평균/최장 문장 길이, 전문용어 수, 한자 수, 쉬운말 미변환 수, lenient 완료 수를 표시한다.
- 공통 난이도 프로필과 서비스 예외를 관리자 프롬프트 화면에서 분리해 보여 주고, 발행 전 대표 티저 미리보기와 회귀 평가를 필수화한다.

## 권장 실행 순서

1. 현재 운영 출력은 유지한 채 실제 제공자 4개 우선 서비스 표본을 수집해 RED 기준을 고정한다.
2. 공통 쉬운말 계약과 자동 검수기를 추가한다.
3. 티저 가드와 `lenient` 차단 경계를 수정한다.
4. 천명사주·새해 흐름·이직운·운 붙는 색을 먼저 재생성·시각 검수한다.
5. 20개 서비스 실제 제공자 평가를 통과한 뒤 공통 프롬프트를 발행한다.
