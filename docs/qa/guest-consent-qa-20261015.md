# 비회원 동의 시트·비회원 관리 운영 QA (2026-10-15)

PR #172·#173 운영 반영 직후 umsh.kr 에서 확인했다. 실제 SNS 로그인 직전(Supabase `/auth/v1/authorize`)에서 요청을 막고 본다.
브라우저 자동화는 `lane/node_modules/playwright-core` 를 썼다(umsh 저장소에는 Playwright 가 없다).

## 찾은 오류와 수정

1. **단계형 서비스 04 에서 비회원 시트가 안 뜸.** 비회원 첫 결과는 서버 프로필 저장 전이라 `umsh-funnel-auth-gate.js` 의 "로컬 입력만 있음" 길로 들어오는데, 그 길이 시트를 걸지 않고 바로 화면만 열었다(#145 부터 있던 문제). → 그 길에서도 비회원이면 시트를 건다.
2. **동의 출처가 로그인 화면으로 덮임.** 결과 시트에서 동의하고 넘어가면 로그인 화면이 SNS 를 이어 시작하면서 보류 동의를 `source: login` 으로 다시 썼다. 어드민 동의 이력의 "동의한 곳"이 틀어진다. → 시트에서 온 동의면 `guest-sheet` 를 지킨다.
