# 삽입형 대운 흐름 가독성 v2

## 관측

삽입형 06 상세의 대운 흐름은 공용 전체 리더의 CSS 범위 밖에 있어, 동적 스타일 요청이 늦거나 캐시가 남으면 기본 브라우저 글자·SVG 색으로 보일 수 있었다. 이 상태에서는 제목, 그래프, 원자료가 한 덩어리로 읽힌다.

## 결정

- `data-umsh-verified-inplace`를 가진 19개 상세 문서의 `<head>`에서 공용 삽입형 CSS를 정적으로 먼저 읽는다.
- 런타임 `ensureInPlaceStyles`는 같은 ID를 인식해 중복 스타일을 추가하지 않는 폴백으로 남긴다.
- CSS 버전은 `20260922-lifeflow-readable-v2`로 올려 이전 캐시를 분리한다.

## 읽기 위계

1. `만세력 계산 결과`는 작은 레이블, `나의 대운 흐름`은 제목으로 구분한다.
2. 현재 위치는 범위·간지·기준 연도를 한 줄 정보 칩으로 분리한다.
3. 그래프 설명은 선의 의미와 비예측 범위를 먼저 설명한다.
4. 현재 구간은 그래프 아래의 강조 박스로 다시 연결한다.
5. 올해 참고·삼재와 원자료 타임라인은 그 다음으로 둔다. 원자료 토글은 기본 공개 상태를 유지한다.

## 검증

- 19개 삽입형 상세가 같은 정적 CSS를 참조한다.
- 공용 CSS가 15px/1.85 본문, 현재 위치 칩, 그래프 텍스트 폰트, 포인트·타임라인 규칙을 보유한다.
- 대운 그래프는 저장된 계산값을 읽는 보조 표현이며, 성공·수입·사건 예측 점수가 아니다.
