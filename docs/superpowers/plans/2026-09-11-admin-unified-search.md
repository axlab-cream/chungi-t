# T13 — 통합 검색·읽기 홈

## 목표

운영자가 실제 주문·회원·리포트·지원 케이스를 정확 식별자로 안전하게 찾고, 현재 운영 요약을 읽는다.

## 화면 계획

- 사용자/상황: 운영자가 고객 문의나 장애를 처리하면서 이미 가진 주문 ID·회원 ID·리포트 ID·케이스 ID를 빠르게 확인한다.
- 주 CTA: `검색`. 검색 종류를 선택하고 정확한 ID를 입력한다.
- 데이터: server-only API가 권한별 원천을 조회하고 마스킹 DTO를 반환한다. 자동 완성·부분 이름/이메일 검색은 이번 범위에 없다.
- 상태: 빈 입력, 결과 없음(404), 권한 없음, 의존성 오류, 성공 결과를 구분한다.
- 읽기 홈: 기존 실제 운영 snapshot을 기준 시각과 함께 표시한다. 조회 오류를 0으로 표시하지 않는다.

## 보안·완료 기준

- 종류별 read scope 확인, ID 길이 제한, server-only service role.
- 고객 원문, 결제 거래번호, 리포트 본문은 반환하지 않는다.
- 실제 Production 검색 API와 `/admin/search` UI가 동작하며 unit·브라우저로 검증한다.
