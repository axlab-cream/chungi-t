# 퇴사운 무료 티저 운영 적용 계획

**목표:** 로그인 사용자의 저장 사주, 퇴사 고민 입력, 저장된 퇴사운 해석을 사용해 실제 1·2번 해석과 3~10번 잠금 목차를 운영 화면에 제공한다.

## 화면·데이터 계약

- 대상: `/work/quit/04-step-4-report/index.html?reportId=<owned-report-id>`
- 원천: 소유권이 확인된 저장 리포트의 `analysis`, `context`, `report.sections`, 기존 결제 권한 응답
- 무료 공개: 저장된 섹션 1·2의 본문, 서로 다른 기존 퇴사운 이미지, 실제 입력 표, 서버 계산 오행 차트
- 잠금: 저장된 목차 3~10의 번호·제목·분류·잠김 상태만 제공하며 본문은 응답하지 않는다.
- 전환: 잠금 목차 아래에 결제/전체 목차 CTA와 입력값 재확인 링크를 한 번만 둔다.
- 조회 횟수: API가 실제 `freeSearch` 값을 제공할 때만 5회 사용량을 표시한다. 퇴사운 전용 영속 카운터를 새로 만드는 DB 마이그레이션은 `rules.md` §6.3의 별도 승인 대상이므로 이번 UI 배포에는 포함하지 않는다.

## 세로 슬라이스

### QUIT-TEASER-01 — 저장된 첫 두 해석을 운영 티저로 읽기

- API: `quit_fortune`도 완성된 섹션 1·2만 `teaserSections`로 반환하고 목차 응답은 10개로 제한한다.
- 데이터 보강: 저장된 사용자 고민과 서버 계산 오행만 사용해 표·차트 데이터를 구성한다. 누락 값은 표시하지 않는다.
- UI: 정적 목업을 제거하고 공통 in-place 렌더러가 이미지 → 제목/도입 → 본문 → 표·차트 → 장면/질문 → 결론 순서로 렌더한다.
- 잠금: 3~10번은 기본 닫힘이며 본문을 포함하지 않는다.
- 권한: 기존 로그인·소유권·결제·보관함 경로를 그대로 사용한다.

## 검증

- API 단위 검사: 퇴사운 `teaserSections` 2개, `toc` 10개, 공개 본문 외 유료 본문 미노출
- UI 계약 검사: 정적 문구/내부 QA/원시 마크다운/중복 CTA 없음, 닫힌 잠금 목차 8개
- 서비스 검사: 실제 입력과 사주 계산값으로 표·차트 생성, 서로 다른 이미지
- 전체 단위 테스트, 타입 검사, 프로덕션 빌드
- 모바일 운영 URL에서 1·2 본문, 이미지, 시각화, 닫힌 목차, CTA, 가로 넘침, 하단 내비게이션을 확인

## 배포·복구

- 검증된 관련 파일만 `main`에 일반 push하고 기존 Vercel production 경로로 배포한다.
- 복구는 해당 커밋 revert와 이전 Vercel 배포 승격으로 수행한다.
- 운영 DB 스키마와 저장 리포트 원문은 변경하지 않는다.
