# 저장 해석 링크 공유 — 작은 기능 범위

- 목적: 저장 해석 하단의 중복 이동 링크를 복사 전용 공유 버튼으로 교체한다.
- 사용자: 이미 접근 권한이 있는 저장 해석 독자. 받는 사람은 기존 로그인·소유권 검사를 통과해야 본문을 읽는다.
- RS-01: 버튼은 `링크 공유하기`이며 `/r/:resultId` 절대 주소만 클립보드에 복사한다. 페이지 이동·네이티브 공유창·결제/권한 변경은 하지 않는다.
- RS-02: 복사 성공/실패를 같은 자리에서 화면과 보조기기에 알리고, 브라우저가 클립보드를 거부할 때 성공으로 표시하지 않는다.
- RS-03: 공유 플랫폼이 공개 HTML을 읽으면 운명상회 공통 이미지(1200×600 JPEG)를 미리보기에 쓴다. 이름·개인 풀이·계산값은 메타데이터에 넣지 않는다. 플랫폼 캐시는 자체 정책을 따른다.
- 범위: `/r/:id` 공용 리더의 저장 해석 버튼, 메타데이터, 캐시 버전 및 회귀 검사. 팝업 관리자/팝업·DB·공유 권한은 변경하지 않는다.
- 검증: 클릭 성공/거부 테스트, 메타데이터 정합성, 공개 셸 및 이미지 HTTP 200, 타입검사·Vercel 빌드·회귀 검사, diff 검토.
- 운영 게이트: `rules.md` §6 H1/H2에 따라 이번 요청에 명시적 커밋 배포 승인이 없으므로 원격 push 및 배포는 하지 않는다.
