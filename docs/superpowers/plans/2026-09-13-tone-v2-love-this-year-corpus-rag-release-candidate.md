# love_this_year corpus/RAG release candidate plan

Task: `task-tone-v2-p05-love-this-year-corpus-rag-release-candidate`

## Objective

Preserve the current 2.0.0 yearly-love corpus for stored reports, create an explicitly reviewed 2.1.0 candidate for new snapshots, and prove retrieval, prompt and saved-prose review isolation without reopening the blocked generic `/api/saju/analyze` path.

## Scope

1. Freeze the original 10 block IDs, source file and hash.
2. Add a failing executable contract for registry activation, semantic reviews, relationship/privacy/safety boundaries, active/stored retrieval, hash mismatch, prompt pinning, saved-prose review and truthful release state.
3. Separate user-confirmed relationship facts, server calculations, symbolic questions, unknown partner/future reality and labeled hypothetical examples.
4. Remove invented introductions, contact, schedules, feelings, relationship outcomes and unsupported months/counts/actions.
5. Preserve partner-birth privacy and explicit refusal, coercion, violence and stalking safety overrides.
6. Prove the dedicated `/api/love/this-year/analyze` route remains present while the generic `/api/saju/analyze` fallback remains blocked.
7. Activate 2.1.0 only for new snapshots, preserve 2.0.0 rollback and run focused, related, full, build, deterministic, review and ProjectOps gates.

## Non-scope

- Re-enabling the generic analyze route or changing product availability.
- Provider generation or provider-output quality claims.
- Production deployment, customer-record mutation, database/auth/payment/admin changes.
- Commit, push or deployment.

## Acceptance

- 10/10 review entries pass and examples are explicitly hypothetical.
- No partner-mind inference, guaranteed meeting/reunion/dating outcome, unsafe contact advice or arbitrary period/count prescription.
- Partner raw birth data is not added to corpus, prompts or release evidence.
- Old snapshots remain retrievable and fail closed on hash mismatch.
- Dedicated route remains intact and generic fallback remains blocked.
- Candidate, review and release artifacts are deterministic, reversible and truthful.
