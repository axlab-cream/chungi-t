# 오늘운 저장 결과 화면 통합

## 요구사항과 결정

- R1: 오늘운 결과의 하단 CTA는 `평생운 확인`이며 천명사주 티저로 이어진다.
- R2: `/r/:id`, `/today/free?reportId=:id`, 보관함의 오늘운은 `/cmdg/?reportId=:id#todayResult` 한 화면에서 같은 저장 결과를 연다.
- R3: 사주 정보는 현재 로그인 계정의 서버 프로필에서 읽고 URL에 싣지 않는다. 정보가 없거나 조회에 실패하면 입력·오류 안내를 보인다.
- R4: 기존 저장 ID와 계정 권한 검증을 보존하고, 오늘운을 다시 생성하지 않는다.

이슈 1개로 처리: 저장 오늘운 열기 → 기존 ID로 전용 화면 이동 → `평생운 확인` 클릭 → 계정 프로필로 천명사주 분석 → 티저. 결제·DB 스키마·기존 결과 데이터의 변경은 범위 밖이다.

## 검증

- 연결, CTA, 로그인·프로필 누락·오류, 보관함 경로의 집중 테스트.
- TypeScript 검사와 전체 회귀 테스트.
- 실제 운영 계정 클릭 검증은 배포 이후 별도 수행. 로컬 테스트만으로 운영 반영을 주장하지 않는다.

로컬 검증 결과(2026-09-22): 관련 검사 104/104, 전체 단위 테스트 1497/1497, TypeScript 검사 통과. 배포 대상에 고객 데이터 마이그레이션·결제 변경은 없다. 운영에서 기존 오늘운 주소와 보관함 진입, `평생운 확인`의 로그인·프로필 분기를 확인한다. 문제가 생기면 배포 직전 커밋으로 되돌린다.
