# 고양이 궁합 저장 리포트 Implementation Plan

> **For agentic workers:** 이 계획은 현재 세션에서 순차 실행한다. 독립 작업자 분배는 요청되지 않았다.

**Goal:** 저장된 고양이 궁합 20개 해석을 결혼궁합과 같은 읽기 구조로 표시하고, 각 항목에 서로 다른 실사 사진을 연결해 운영에서 확인한다.

**Architecture:** 기존 저장 API와 공용 렌더러를 그대로 사용한다. `cat_compatibility`의 편집 이미지 설정과 06 상세 CSS만 확장하고, 공용 렌더러에는 설정 도착 전 대기 및 오래된 저장 이미지 교체 조건만 추가한다.

**Tech Stack:** 정적 HTML/CSS, 브라우저 JavaScript, Node/TypeScript 테스트, Vercel Git 배포.

## Global Constraints

- 저장 해석·소유권·결제·회원 DB는 변경하지 않는다.
- 팝업·팝업 관리자·다른 서비스의 이미지 정책은 유지한다.
- 실사 이미지는 요약·하이라이트·20개 목차에 각각 한 장, 총 22개를 사용한다.
- 일반 `origin/main` 푸시 전 전체 테스트·타입·서비스 QA·빌드를 확인하고 운영에서 재검수한다.

## Design Notes

- 대상: 실제 저장된 반려묘 궁합을 읽는 회원. 화면의 역할은 예언이 아니라 생활 관찰 기준을 읽기 쉽게 제시하는 것.
- 색: 배경 `#030402`, 패널 `#0b0d08`, 글자 `#fff9ec`, 금색 `#efc46f`, 연두 `#a8ff18`.
- 제목·본문·보조 글자는 기존 Pretendard/MaruBuri와 공용 리더 컴포넌트를 따른다.
- 시그니처: 어두운 집 안의 금색 실내광과 회색 고양이의 실제 생활 장면. 피할 것: 그래픽 콜라주, 글자 박힌 이미지, 머리만 잘린 크롭.
