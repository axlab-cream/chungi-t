# Tone V2 pass_angle corpus/RAG release-candidate plan

## Goal

Version and review all 8 `pass_angle` corpus blocks for new snapshots while preserving `2.0.0` for stored reports and the completed 52-item record.

## Evidence and boundaries

- CreamWIKI confirms the 52-item provider record is complete, immutable and production-review replayed; it predates this corpus candidate and is not new-corpus generation evidence.
- User-confirmed exam type/date, official requirements and actual study/score records are facts; server-calculated chart values and remaining-day arithmetic are separate.
- Ten-god, day-master and luck-cycle values are symbolic questions, not evidence of intelligence, academic ability, effort, health, pass/fail or score.
- Fixed study periods, counts, D-day stages and exam-day routines cannot be invented when absent from user input or official instructions.
- Health, anxiety and burnout require user-reported observations and appropriate professional support, not chart diagnosis.

## Vertical slices

1. RED semantic/snapshot assertions.
2. Deterministic reviewed `2.1.0` pack.
3. New-snapshot registry attachment with 2.0.0 preservation.
4. Retrieval, prompt, saved-review and hash-failure proof.
5. Truthful rollback candidate that does not relabel old provider output.
6. Focused/related/full/typecheck/build/review/ProjectOps/KMS verification.

## Acceptance

- 8/8 semantic reviews pass.
- Facts, official documents, calculated values, missing inputs and symbols remain distinct.
- No intelligence/ability label, pass/fail prediction, unsupported study prescription or medical conclusion.
- Examples are labeled; actual dates/counts are used only when sourced.
- New snapshots use 2.1.0; stored 2.0.0 snapshots and the completed record remain unchanged.

## Non-scope

- New provider generation, Production, customer data, existing 52-item record mutation, DB/auth/payment/admin, commit, push and deployment.
