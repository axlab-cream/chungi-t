# wedding_day corpus/RAG release candidate plan

Task: `task-tone-v2-p05-wedding-day-corpus-rag-release-candidate`

## Objective

Preserve the current 2.0.0 wedding-date corpus for stored reports, create an explicitly reviewed 2.1.0 candidate for new snapshots, and prove retrieval, prompt and saved-prose review isolation.

## Scope

1. Freeze the original six block IDs, source file and hash.
2. Add a failing executable contract for registry activation, six semantic reviews, evidence and privacy boundaries, active/stored retrieval, hash mismatch, prompt pinning, saved-prose review and truthful release state.
3. Build six unique blocks separating submitted candidate dates and constraints, server-calculated day/month/chart relations, symbolic comparison, unknown future reality and labeled hypothetical examples.
4. Remove invented partner/family feelings, venue or contract state, wedding-day condition, post-wedding outcomes and unsupported period/count prescriptions.
5. Activate 2.1.0 only for new snapshots, preserve 2.0.0 rollback and bind local evaluation/release evidence.
6. Run focused, related and full regression, typecheck, Vercel build, deterministic replay, review, credential boundary and ProjectOps closure.

## Non-scope

- Provider generation or provider-output quality claims.
- Production deployment, customer-record mutation, database/auth/payment/admin changes.
- Commit, push or deployment.

## Acceptance

- 6/6 review entries pass and examples are explicitly hypothetical.
- Candidate dates, solar-term month and chart relations come only from submitted input and server calculations.
- No certain marriage result, partner/family state, contract, financial, health, legal or personal-state inference.
- No arbitrary period, count, date or schedule prescription.
- Missing partner data and birth time remain unknown; raw partner birth information is not added to corpus evidence.
- Old snapshots remain retrievable and fail closed on hash mismatch.
- Candidate, review and release artifacts are deterministic, reversible and truthful.
