# 서비스 공통 풍부한 해석과 올해 연애운 시각화 (2026-09-22)

## 결정

- 서비스별 고유 색·문안·썸네일·목차 이미지는 `사주/data/longform-blocks.json`을 정본으로 유지한다.
- 저장 원문은 변경하지 않는다. 공용 리더가 안전한 마크다운 서식과 저장된 실제 오행 계산값만 그린다.
- 올해 연애운의 옛 퍼센트 차트는 개인 예측처럼 오해될 수 있어 표시하지 않는다. 로그인된 리포트의 출생값과 저장 연도를 사용해 매달 15일의 월주에서 도화 지지·보완 기운·일지 일치 세 항목을 센다. 0~3은 전통 신호 일치 개수이지 만남이나 연애 성공 확률이 아니다.
- 첫 도화 하이라이트는 자연광·아이보리·핑크 계열의 새 실사 겨울 카페 배너를 사용한다. 다른 목차 이미지 10개는 유지한다.
- 한눈에 보기에는 세로형 영상 포스터를 쓰지 않는다. 같은 서비스 아트 디렉션의 전용 가로 실사 자산을 `summaryImageFit: wide`로 표시해 원본 비율과 인물 전체 구도를 보존한다.
- 앞으로 생성되는 일반 해석 항목의 분량 목표를 1200~1600자로 높인다. 과거 고객의 완료된 텍스트에는 소급 적용하지 않는다.

## 검증

- 전체 단위 테스트 1529/1529 통과. 마지막 API 저장 연도 보정 후 집중 테스트 12/12, 요약 이미지 계약 13/13 통과.
- TypeScript, 20서비스 정적 QA, Vercel build, diff check 통과.
- 팝업·팝업 관리자·결제·저장 고객 데이터는 변경하지 않았다. 원격 push·운영 배포와 로그인 실화면 검수는 하지 않았다.

## 재사용·주의

- 다른 분야의 그래프는 검증 가능한 계산값만 사용하고 예측 점수나 상승/하락 곡선을 임의로 만들지 않는다.
- 집 풍수·결혼 날짜는 독립 화면을 유지한다. 이번에는 안전 마크다운 렌더러만 공유하므로 공용 카드 레이아웃과 100% 같다고 주장하지 않는다.
- 개인 입력·이름·리포트 ID는 이 기록에 남기지 않는다.

## 공통 리더 상·하단 정렬 (2026-09-22)

- 올해 연애운 06 상세는 공용 GNB·하단 메뉴와 별도의 상태/PDF 바·채팅 입력창을 동시에 보이고 있었다. 저장 해석을 읽는 단계에서는 후자가 중복 UI이므로 legacy 표시로 남기되 인증된 리포트에서는 숨긴다.
- `ensureInPlaceReaderActions`는 standard 06 in-place 리포트의 끝에 같은 순서의 `링크 공유하기`와 `PDF 저장`을 추가한다. 첫 버튼은 권한을 양도하지 않는 canonical `/r/:id`만 복사한다.
- 이 변경은 저장 원문, 개인 계산값, DB, 결제, 팝업 관리자/팝업을 건드리지 않는다. 배포 전 로컬 정적 화면과 집중·전체 회귀, TypeScript, Vercel build로 확인했다.
