# 이직운 실제 데이터 무료 티저

## 문제

이직운 04 화면은 정적 문장과 목록 중심이라 로그인 회원의 사주, 현재 회사에서 느낀 문제, 새 회사·직무 조건이 실제 풀이로 이어졌는지 확인하기 어려웠다. 무료 공개 본문, 잠금 목차, 결제 CTA와 조회 횟수도 최신 티저 공통 패턴과 연결되지 않았다.

## 사용자 결과

- STEP2 제출 직후 03 개인화 준비 상태를 보여 준 뒤 생성된 `reportId`를 보존해 04로 이동한다.
- 04는 저장된 전체 리포트 중 실제 1·2번만 자세히 공개한다.
- 각 장은 서로 다른 실제 이미지, 개인화 제목, 긴 본문, 입력 표 또는 네 기둥 표, 실제 오행 차트, 현실 질문과 결론을 가진다.
- 03~N번은 서버 TOC를 사용해 기본 닫힘·잠김으로 표시한다.
- CTA는 잠금 목차 아래 한 번만 표시하며 미결제자는 개인 결제, 결제·관리자 권한이 확인된 사용자는 05 목차로 이동한다.
- 무료 조회는 이직운 전용 계정 키로 5회까지 저장하며 같은 리포트 재열람은 차감하지 않는다.

## 데이터 경계

- 개인화 입력: 저장 사주, 이직 진행 상태, 현재 회사 신호, 새 회사명·직무, 근무 방식·위치, 조건 체감, 우선순위, 직접 적은 불편, 준비 체크.
- 계산값: 서버가 계산한 네 기둥의 다섯 기운과 전체 오행 개수.
- 입력되지 않은 수치·사건·상대의 생각·성공 확률은 만들지 않는다.
- 고객 화면에는 원시 한자 기둥, 내부 QA·RAG·샘플 설명을 표시하지 않는다.

## 권한과 이동

`02 입력 → 03 준비 표시 → 04 무료 티저 → 결제 → 05 목차 → 06 상세`를 유지한다. 04에서 서버가 결제 또는 관리자 권한을 확인한 사용자는 결제를 건너뛰고 05로 이동할 수 있다. 05 직접 접근은 기존 공통 fail-closed 검증을 그대로 사용한다.

## 완료 조건

- 실제 1·2번과 서로 다른 이미지, 실제 입력 표, 네 기둥 표, 계산 차트가 표시된다.
- 목차·CTA 중복, 원시 마크다운, 내부 문구, 모바일 가로 넘침이 없다.
- 5회 상태와 입력값 재확인이 같은 영역에 있다.
- 전체 회귀, 타입, 서비스 계약, 전 서비스 QA, 프로덕션 빌드, 운영 모바일 검증을 통과한다.
