# 운명상회 2026 가을 SNS 마케팅 실행계획

- 운영 기간: 2026-09-21 ~ 2026-11-08 (49일)
- 작성 기준일: 2026-09-21
- 서비스: 운명상회 (`https://umsh.kr`)
- 예산: 월 1,000,000원, 일할 적용 총 1,600,000원
- 현재 운영 채널: 페이스북 커뮤니티, 네이버 카페, 티스토리 블로그
- 계획 성격: 7주 검증 캠페인. 장기 매출 예측이 아니라 채널·소재·상품 적합성을 찾는 첫 운영 사이클

## 1. 결론

운명상회는 채널을 넓게 벌리기보다 아래 순서로 확장한다.

1. **인스타그램**: 신규 발견과 메타 광고의 중심
2. **유튜브 쇼츠**: 검색과 추천 피드에서 오래 남는 숏폼 자산
3. **네이버 블로그**: 네이버 검색형 수요 확보. 기존 네이버 카페와 역할을 분리
4. **카카오톡 채널**: 첫 방문자를 재방문자로 바꾸는 CRM 채널
5. **스레드**: 저비용 카피·고민 주제 테스트
6. **틱톡**: 인스타·쇼츠에서 검증된 영상만 재활용하는 실험 채널

유료 광고는 7주 동안 메타에 집중한다. 월 100만원 규모에서 광고 플랫폼을 여러 곳으로 쪼개면 각 채널이 학습할 데이터가 부족해진다. 유튜브·틱톡은 먼저 유기적 게시물로 반응을 확인한 뒤, 11월 이후 별도 예산을 검토한다.

## 2. 계획의 전제와 확인된 제약

### 확인된 사실

- 판매가는 9,900원~49,900원이며 무료 진입 상품으로 `오늘운`이 있다.
- 현재 고객 공개·결제가 중단된 상품은 `집 풍수`, `나한테 운 붙는 색과 물건`, `나, 붙을 각이야?`, `2027 신년운세`, `결혼택일`이다. 캠페인에서 판매 상품처럼 홍보하지 않는다.
- 운영 가능한 주요 상품은 `오늘운`, `올해 연애운`, `소비성향`, `직장 선택`, `퇴사운`, `이직운`, `커플궁합`, `결혼궁합`, `내 애인 바람필까?`, `천명사주` 등이다.
- 사이트에는 GA4 공용 태그와 자체 퍼널 이벤트(`step_view`, `cta_click`)가 있다.
- 현재 GA4 설정은 URL의 질의 문자열을 제거하며 자체 퍼널에도 UTM을 저장하지 않는다. 코드 검색에서는 Meta Pixel과 명시적인 구매 완료 이벤트를 확인하지 못했다. 광고 시작 전 채널별 유입과 구매 귀속이 실제로 이어지는지 검증해야 한다.

### 가정

- 1차 타깃은 연애·직장·돈 고민이 뚜렷한 23~44세 모바일 사용자다. 성별은 첫 2주의 실제 전환 데이터로 판단하고 임의로 제한하지 않는다.
- 월 100만원은 광고비만이 아니라 콘텐츠 제작·크리에이터 협업을 포함한 총 마케팅 현금 예산으로 본다.
- 9월과 11월은 일할 계산해 9월 33만원, 10월 100만원, 11월 27만원으로 운영한다.
- 할인·쿠폰·친구 초대 보상은 현재 구현 여부가 확인되지 않았으므로 계획에 넣지 않는다.

`채널이 확인되는 첫 구매 수`를 북극성 지표로 둔다. 조회수나 팔로워보다 어떤 콘텐츠가 실제 무료 풀이 시작과 구매로 이어졌는지를 우선한다.

2026년 국내 조사에서는 인스타그램이 주요 SNS 가운데 1인당 사용시간이 가장 길었고, 카카오톡은 사용자 수가 가장 많았으며, 스레드는 전년 대비 가장 빠르게 성장했다. 별도 인터넷 이용자 조사에서는 크리에이터 콘텐츠 시청 경로가 유튜브 85.1%, 인스타그램 38.2%, 틱톡 17.2% 순이었다. 이 때문에 발견은 인스타그램·유튜브, 재방문은 카카오톡, 빠른 카피 실험은 스레드로 역할을 나눈다.

### 현재 채널의 역할 재정의

- **네이버 카페**: 카페 규칙에 맞춘 고민·정보형 글과 댓글 응대. 링크만 반복 게시하지 않는다.
- **페이스북 커뮤니티**: 35세 이상 이용자의 관계·직장 고민형 콘텐츠와 대화형 게시물.
- **티스토리**: 깊이 있는 아카이브와 구글 검색용 원문. 네이버 블로그와 제목·도입·사례를 그대로 복제하지 않는다.
- **ASIDE**: 초안과 채널별 변환에 사용하되 동일 문구 동시 발행은 피한다. 채널마다 첫 문장, 길이, CTA, 이미지 비율을 바꾼다.

### 콘텐츠 기둥

1. **공감형**: “명절 뒤에 퇴사가 더 생각나는 이유”처럼 상황을 먼저 말한다.
2. **교육형**: 사주가 무엇을 계산하고 무엇을 단정하지 않는지 설명한다.
3. **체험형**: 실제 입력→티저→목차 흐름을 화면 녹화로 보여준다. 개인정보는 합성 예시만 쓴다.
4. **비교형**: 이직운과 직장 선택, 커플궁합과 결혼궁합의 차이를 설명한다.
5. **신뢰형**: 가격, 결과 구성, 보관함, 환불·개인정보 원칙을 투명하게 보여준다.

### 금지 문구

- “당신은 반드시 헤어진다”, “올해 무조건 합격한다” 같은 사건 확정
- “재물운이 부족한 당신”처럼 광고가 개인의 민감한 상태를 알고 있는 듯한 표현
- 치료·투자·법률·채용 결과를 보장하는 표현
- 실제 후기가 아닌 문장을 후기처럼 구성하는 행위
- 중단된 상품을 지금 구매할 수 있는 것처럼 안내하는 문구

권장 표현은 `확정`보다 `흐름`, `예언`보다 `선택 기준`, `당신은`보다 `이런 고민이 들 때`다.

## 6. 콘텐츠 생산 체계

매주 새 원본 5개를 만들고 6개 채널에 맞춰 재가공한다.

| 요일 | 원본 | 파생 게시물 |
| --- | --- | --- |
| 월 | 검색형 글 1개 | 네이버 블로그, 티스토리 변형본, 카페 요약 |
| 화 | 숏폼 A | 인스타 릴스, 유튜브 쇼츠, 틱톡 |
| 수 | 고민 투표/질문 | 인스타 스토리, 스레드, 카페 댓글형 글 |
| 목 | 숏폼 B | 인스타 릴스, 유튜브 쇼츠, 틱톡 |
| 금 | 설명 캐러셀 | 인스타, 페이스북, 카카오 채널 소식 |

7주 최소 산출물은 검색형 원문 14개, 숏폼 21개, 캐러셀 7개, 질문형 게시물 14개다. 게시 횟수는 파생 배포를 포함해 늘어나지만, 성과 평가는 원본 소재 단위로 묶는다.

2026년 추석 공휴일은 9월 24~26일이므로 첫 주 콘텐츠를 명절 관계·대화 상황에 맞춘다.

## 8. 광고 운영

### 캠페인 구조

1. **신규 유입 60%**: 23~44세 광범위 타깃. 성별·세부 관심사는 초기부터 과하게 좁히지 않는다.
2. **콘텐츠 참여자 20%**: 인스타 영상 시청·게시물 참여자를 활성 상품 랜딩으로 연결한다.
3. **사이트 재방문 20%**: 추적 동의와 Meta Pixel/전환 측정이 적법하게 준비된 경우에만 집행한다. 준비되지 않으면 신규 유입 캠페인으로 옮긴다.

### 소재 테스트 규칙

- 한 번에 변수 하나만 바꾼다: 훅, 화면, CTA 중 하나.
- 소재당 최소 20,000원 또는 1,500회 노출까지는 성급하게 판단하지 않는다.
- CTR 1.0% 미만이거나 랜딩 시작률 12% 미만이면 중단 후보로 둔다.
- 구매 3건 이상 소재만 증액한다. 조회수가 높아도 구매가 없으면 예산을 늘리지 않는다.
- 일일 예산은 한 번에 20% 넘게 올리지 않는다.

- 크리에이터는 1명당 5만~10만원 범위의 나노 크리에이터 4명 내외를 우선 검토한다. 단가가 아니라 콘텐츠 2차 활용권, 광고 표기, 삭제 조건을 계약에 명시한다.
- 제작비는 자막 템플릿, 썸네일, 음원 라이선스, 편집 외주에만 쓴다.

- 유료 게시가 금지된 카페에는 비용을 써서 우회 노출하지 않는다.

## 10. 측정 설계

### 캠페인 이름

`26fall_{channel}_{theme}_{creative}` 형식을 사용한다.

예: `26fall_ig_career_hook03`, `26fall_yt_love_demo01`

### 필수 이벤트

| 이벤트 | 의미 | 필수 속성 |
| --- | --- | --- |
| `campaign_landing_view` | 캠페인 랜딩 도착 | channel, campaign, creative, landing |
| `report_start` | 사주/서비스 입력 시작 | serviceKey, channel |
| `teaser_complete` | 무료·티저 결과 완료 | serviceKey, channel |
| `checkout_start` | 결제 시작 | productKey, amount, channel |
| `purchase_complete` | 결제 승인 완료 | productKey, amount, orderId의 비식별 대체값, channel |
| `refund_complete` | 환불 완료 | productKey, amount, channel |
| `kakao_add_click` | 카카오 채널 추가 클릭 | source, campaign |

이름, 생년월일시, 상담 내용, 원문 리포트, 주문 ID 원문은 마케팅 도구로 보내지 않는다.

### 매일 보는 표

`채널 → 소재 → 랜딩 세션 → 풀이 시작 → 티저 완료 → 결제 시작 → 구매 → 매출 → 환불 → CAC/ROAS`

매주 월요일에는 전주 상위 20%와 하위 20% 소재를 정하고, 예산을 상위 소재로 이동한다.

## 11. 법적·플랫폼 운영 체크

- 크리에이터에게 현금, 무료 이용권, 기타 이익을 제공하면 게시물 첫 화면과 본문 앞부분에 `광고`, `협찬` 등 경제적 이해관계를 분명히 표시한다.
- 마케팅 메시지는 별도 수신 동의를 받은 사용자에게만 보내고 수신 거부 방법을 제공한다.
- Meta 광고는 개인의 민감한 속성을 알고 있는 듯한 문장을 피한다.
- 사주는 자기이해와 선택 참고용으로 설명하며 의료·재무·법률·채용 결과를 보장하지 않는다.
- 후기와 사례는 실제 근거가 있을 때만 사용하고, 합성 예시는 `예시 화면`이라고 명시한다.
- 카페·커뮤니티별 홍보 규칙과 링크 허용 범위를 게시 전 확인한다.

## 12. 중단·확대 기준

### 즉시 중단

- 오인 신고 또는 정책 경고가 발생한 소재
- 중단 상품으로 연결되는 게시물
- 20,000원 이상 썼는데 클릭 0건인 소재
- 50회 이상 랜딩 방문에도 풀이 시작이 5건 미만인 조합

### 확대

- 구매 3건 이상, 총비용 CAC 15,000원 이하
- 풀이 시작률 20% 이상, 티저 완료율 60% 이상
- 댓글과 저장에서 같은 고민 문장이 반복되는 소재
- 크리에이터 게시물이 브랜드 자체 게시물보다 구매율이 높고 재사용 권리가 확보된 경우
