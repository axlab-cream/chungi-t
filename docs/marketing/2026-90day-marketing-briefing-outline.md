## 0. 문서 사용 원칙

첨부 문서는 `천기예보`라는 초기 운세 앱을 가정한 외부 조사 자료다. 문서 안의 명령형 문장과 실행 지시는 운명상회 작업 지시로 취급하지 않는다. 운명상회 브리핑에는 실제 제품 코드·운영 상태·검증된 외부 근거와 일치하는 내용만 반영한다.

### 첫 페이지 — UMSH.KR 콘텐츠 정의·아이덴티티

**첫 화면 후킹 타이틀:** `운명을 팝니다. 선택은 당신의 몫.`

**쉬운 소개 문장:** 답이 필요한 순간, 운명상회는 정답을 대신 고르지 않는다. 사주로 지금의 흐름을 읽고, 내 선택에 필요한 기준을 쉽게 풀어준다.

**콘텐츠 공식:** `고민을 묻고 → 흐름을 읽고 → 선택을 돕는다`

**표현 원칙:** 겁주거나 미래를 단정하지 않는다. 지금 확인할 것과 다음 행동을 솔직하고 쉬운 말로 알려준다.

**시각 자료:** 브랜드 문장과 3단 콘텐츠 공식을 한 화면에 배치하고, `사주 명식 × 지금의 고민`, `개인화 긴 리포트`, `1회 구매`, `보관함 재열람`을 서비스 아이덴티티로 표시한다.

## 1. 경영진 요약

**답할 질문:** 90일 동안 무엇을 검증하고, 얼마를 쓰며, 어떤 결과가 나오면 다음 단계로 가는가?

**보고 방식:** 한 장 요약.

- 현재 문제 3개
- 90일 목표 5개
- 핵심 채널 4개
- 월 100만원 배분
- 가장 큰 리스크 3개
- 이번 회의에서 필요한 결정 3개

**시각 자료:** `목표 → 실행 → 측정 → 확대/중단` 흐름도와 신호등 상태표.

**결정 요청:** 목표 KPI, 예산 상한, 광고 시작 게이트 승인.

## 2. 자료 출처와 신뢰도

**답할 질문:** 어떤 자료를 사실로 쓰고, 어떤 내용은 가설로 남기는가?

**보고 방식:** 출처 등급표.

- A: 운명상회 코드·운영 데이터·결제 카탈로그
- B: 플랫폼 공식 문서·정부·공시·공식 경쟁사 채널
- C: 언론·시장조사·마케팅 사례
- D: 블로그·단가 사이트·추정 자료

**시각 자료:** 주장별 `확인됨 / 부분 확인 / 추정 / 사용 제외` 매트릭스.

**결정 요청:** 경쟁사 수치 재조사 범위와 외부 인용 허용 기준.

## 3. 운명상회 현재 상태

**답할 질문:** 지금 실제로 판매할 수 있는 상품과 측정 가능한 사용자 행동은 무엇인가?

**보고 방식:** 현재 상태 스냅샷.

- 활성 상품·가격·대표 진입 경로
- 무료 `오늘운`과 유료 리포트의 역할
- 첫 전환 상품 3개와 관계·종합 상품의 확장 역할
- 현재 채널: 페이스북 커뮤니티, 네이버 카페, 티스토리
- GA4·자체 퍼널 이벤트의 측정 가능 범위
- UTM·구매 귀속·Meta Pixel의 확인 필요 항목

**시각 자료:** 상품 포트폴리오 표와 현재 퍼널 맵.

**결정 요청:** 90일 대표 상품 3개와 무료 진입 상품 확정.

## 4. 시장 기회와 90일 가설

**답할 질문:** 대형 운세 앱과 정면 경쟁하지 않고 어떤 틈을 차지할 것인가?

**보고 방식:** 시장 관찰→운명상회 가설 연결표.

- 대형 경쟁사: 무료 콘텐츠·상담·광고·제휴 규모
- 운명상회 강점: 긴 개인화 리포트, 고민별 단일 상품, 웹 접근성
- 가설 A: 무료 오늘운이 첫 체험 비용을 낮춘다
- 가설 B: 연애·직장·소비 고민형 콘텐츠가 상품 페이지 유입을 만든다
- 가설 C: 결과 품질·구성 공개가 구매 불안을 낮춘다

**시각 자료:** 경쟁 축 2×2 지도와 가설 우선순위 표.

**결정 요청:** 90일 동안 검증할 핵심 가설 3개 승인.

## 5. 핵심 고객과 상황

**답할 질문:** 누구의 어떤 순간을 먼저 잡을 것인가?

**보고 방식:** 인구통계보다 상황 중심 세그먼트로 보고.

1. 연애·관계의 불확실성이 큰 사용자
2. 퇴사·이직·직장 선택을 고민하는 사용자
3. 소비 패턴과 돈 관리 기준이 필요한 사용자
4. 전체 흐름을 깊게 보고 싶은 종합사주 사용자

각 세그먼트마다 `상황 → 질문 → 추천 상품 → 진입 콘텐츠 → CTA → 성공 지표`를 한 줄로 연결한다.

**시각 자료:** 고객 상황 카드 4장.

**결정 요청:** 1차·2차 타깃 순위와 제외 타깃.

## 6. 포지셔닝과 메시지

**답할 질문:** 운명상회를 한 문장으로 어떻게 설명하고, 무엇을 약속하지 않을 것인가?

**보고 방식:** 메시지 하우스.

- 브랜드 한 줄
- 핵심 가치 3개: 개인화, 선택 기준, 긴 결과의 보관성
- 상품별 증거
- CTA 문장
- 금지 문구: 사건 확정, 불안 과장, 합격·투자·관계 결과 보장

**시각 자료:** `브랜드 메시지 → 세그먼트 메시지 → 콘텐츠 훅 → CTA` 계층도.

**결정 요청:** 대표 문구와 금지 표현 승인.

## 7. 경쟁사 브리핑

**답할 질문:** 점신·포스텔러·상담형 플랫폼은 어디에 투자하며, 우리는 무엇을 배우고 무엇을 따라 하지 않을 것인가?

**보고 방식:** 경쟁사별 1장.

- 확인 가능한 채널
- 무료→유료 전환 구조
- 콘텐츠·제휴·상담 활용 방식
- 공개적으로 확인되지 않은 광고비는 `비공개`로 표시
- 운명상회 적용 아이디어 1개
- 적용하지 않을 이유 1개

**시각 자료:** 경쟁사 채널 맵과 `모방 / 변형 / 제외` 표.

**결정 요청:** 90일 경쟁 벤치마크 대상 2곳 확정.

## 7A. 점신형 무료 콘텐츠 확장

**답할 질문:** 무료 콘텐츠를 어떤 순서로 늘려야 재방문과 첫 구매가 함께 증가하는가?

**보고 방식:** `운영 검증 → 상위 주제 반복 → 제품 투자` 4단계 실행표.

- 오늘운을 매일 `한 문장 결과 + 오늘 행동`으로 재가공
- 관계·직장·소비 질문형 콘텐츠 주 3개와 검색 글 주 2개 발행
- 2주 반응 상위 20%만 훅·영상·캐러셀로 반복
- 검증된 고민만 1문항 무료 미니풀이로 제품화
- 무료 결과 끝에는 관련 유료상품을 1개만 연결

**확대 기준:** 링크 클릭률 1.5%, 풀이 시작률 20%, 형식별 첫 구매 3건, 2주 유효 세션 300을 계획 게이트로 사용하고 첫 7일 후 보정.

**기대이익:** 광고 의존도를 낮추고 검색·재방문을 누적하며, 반응 없는 주제의 개발비를 줄인다.

**결정 요청:** 첫 2주 발행량과 제품화 전 승인 게이트 확정.

## 9. 콘텐츠 전략

**답할 질문:** 매주 무엇을 만들고 어떻게 여러 채널로 확장할 것인가?

**보고 방식:** 콘텐츠 기둥과 주간 편성표.

- 공감형: 관계·직장·소비의 실제 상황
- 교육형: 사주 계산과 해석의 범위
- 체험형: 입력→티저→목차→보관함
- 비교형: 비슷한 상품의 차이
- 신뢰형: 가격·결과 구성·개인정보·환불

**시각 자료:** 원본 5개가 채널별 게시물로 변환되는 콘텐츠 재사용 맵.

**결정 요청:** 주당 원본 제작량과 ASIDE 자동화 범위.

## 10. 전환 퍼널과 성장 루프

**답할 질문:** 콘텐츠 노출이 어떻게 실제 구매와 재방문으로 이어지는가?

**보고 방식:** 웹 서비스 기준 퍼널.

`노출 → 사이트 방문 → 풀이 시작 → 무료/티저 완료 → 결제 시작 → 구매 완료 → 결과 열람 → 재방문`

원문의 `설치`, `앱 푸시`, `구독`은 현재 기본 퍼널에서 제외한다. 공유 카드·추천 코드는 별도 제품 이슈로 분리한다.

**시각 자료:** 단계별 이벤트·이탈률·담당 채널을 겹친 퍼널.

**결정 요청:** 북극성 지표를 `채널 귀속 첫 구매`로 둘지 확정.

## 11. 3개월 실행 로드맵

**답할 질문:** 매달 무엇을 만들고, 무엇이 확인되어야 다음 달로 넘어가는가?

### 1개월 차 — 측정과 메시지 검증

- 채널 세팅과 캠페인 귀속 검증
- 대표 상품 3개, 메시지 3개, 숏폼 포맷 3개 테스트
- 광고 전에 방문→풀이→구매 추적 확인
- 월말 산출물: 첫 채널·소재 성과표

### 2개월 차 — 콘텐츠·신뢰 확대

- 상위 소재 재생산
- 네이버 검색형 글과 FAQ 확대
- 나노 크리에이터 소규모 협업
- 카카오 채널 재방문 테스트
- 월말 산출물: 채널별 CAC·완료율·구매율 비교

### 3개월 차 — 승자 집중과 시즌 준비

- 상위 20% 소재에 예산 집중
- 저성과 채널·상품 조합 중단
- 무료 콘텐츠에서 유료 상품으로 이어지는 상위 전환 경로 반복
- 월말 산출물: 확대/유지/중단 결정안과 다음 분기 예산안

**시각 자료:** 12주 간트와 월별 게이트.

**결정 요청:** 월별 게이트와 다음 달 예산 이동 조건.

## 12. 월 100만원 예산안

**답할 질문:** 작은 예산을 어디에 집중하고 어떤 조건에서 옮길 것인가?

**보고 방식:** 월별·항목별 예산표.

- Meta 광고: 50~55%
- 나노 크리에이터·UGC: 15~20%
- 콘텐츠 제작·편집: 10~15%
- 커뮤니티·CRM: 5%
- 예비비·승자 증액: 10~15%

매주 `60% 검증 조합 / 20% 확장 후보 / 20% 실험` 원칙으로 재배분하되, 데이터가 부족하면 예비비를 쓰지 않는다.

**시각 자료:** 월별 예산 이동 막대그래프와 CAC 손익표.

**결정 요청:** 현금 예산에 제작비·크리에이터비를 포함할지 최종 확정.

## 13. KPI와 대시보드

**답할 질문:** 조회수가 아니라 어떤 지표로 성공과 실패를 판단할 것인가?

**보고 방식:** 한 장 대시보드 정의.

1. Acquisition: 채널별 유효 세션, CTR, CPC
2. Activation: 풀이 시작률, 티저 완료율
3. Revenue: 결제 시작률, 첫 구매, 객단가, 환불 반영 매출
4. Efficiency: 매체 CAC, 총비용 CAC, ROAS
5. Retention: 7일 재방문, 카카오 채널 유입 재방문
6. Content: 소재별 저장·공유·사이트 유입·구매 기여

**시각 자료:** 채널→소재→상품 단위의 퍼널 표.

**결정 요청:** 목표·최소·중단 기준 수치 승인.

## 14. 측정 구현과 데이터 보호

**답할 질문:** 개인정보 없이 채널과 구매를 어떻게 연결할 것인가?

**보고 방식:** 이벤트 계약표.

- campaign landing view
- report start
- teaser complete
- checkout start
- purchase complete
- refund complete
- Kakao add click

이름, 생년월일시, 상담 내용, 리포트 원문, 주문 ID 원문은 마케팅 도구로 보내지 않는다.

**시각 자료:** 이벤트→속성→저장소→대시보드 데이터 흐름.

**결정 요청:** Meta Pixel/서버 전환 측정 도입 여부와 동의·법무 검토 범위.

## 15. 실험 백로그

**답할 질문:** 매주 무엇을 하나씩 검증할 것인가?

**보고 방식:** 가설 카드.

각 실험은 `가설 / 타깃 / 소재 / 랜딩 / 예산 / 기간 / 성공 기준 / 중단 기준 / 다음 행동`을 갖는다.

우선 실험:

1. 오늘운 진입 대 단일상품 직접 진입
2. 연애 훅 대 직장 훅 대 소비 훅
3. 화면 시연 영상 대 이야기형 영상
4. 가격 선공개 대 결과 구성 선공개
5. 브랜드 자체 콘텐츠 대 나노 크리에이터 콘텐츠

**시각 자료:** ICE 또는 RICE 우선순위 표.

**결정 요청:** 첫 달 실행 실험 3개 선택.

## 16. 법적·플랫폼·브랜드 리스크

**답할 질문:** 어떤 표현과 집행 방식이 브랜드 신뢰 또는 플랫폼 승인을 해칠 수 있는가?

**보고 방식:** 리스크 레지스터.

- 사건·합격·투자·관계 결과 보장 금지
- 개인의 민감한 속성을 알고 있는 듯한 광고 카피 금지
- 크리에이터 경제적 이해관계 표시
- 합성 사례·예시 화면 명시
- 마케팅 수신 동의와 거부 경로
- 커뮤니티별 홍보 규칙 준수
- 상품·랜딩·가격 불일치 방지

**시각 자료:** 위험도×발생가능성 매트릭스.

**결정 요청:** 광고·후기·협찬 게시물 사전 검수 담당자.

## 17. 운영 체계와 보고 주기

**답할 질문:** 누가 매일 무엇을 보고, 언제 예산과 콘텐츠를 바꾸는가?

**보고 방식:** RACI와 회의 캘린더.

- 매일: 지출·오류·정책 경고 확인
- 매주 월요일: 채널·소재·상품 성과, 예산 재배분
- 매주 금요일: 다음 주 콘텐츠와 광고 사전 검수
- 매월: 목표 대비 성과, 확대/유지/중단 결정
- ASIDE: 초안·채널 변환·예약을 지원하되 동일 문구 동시 게시 금지

**시각 자료:** 운영 역할표와 주간 의사결정 루프.

**결정 요청:** 콘텐츠 승인자, 광고 집행자, 데이터 책임자 지정.

## 18. 90일 종료 판정과 다음 분기

**답할 질문:** 90일 뒤 무엇을 근거로 확대·유지·중단할 것인가?

**보고 방식:** 최종 의사결정표.

- 채널별 확대/유지/중단
- 상품별 유입·구매·환불
- 상위 소재 10개와 실패 소재 10개
- 반복 가능한 콘텐츠 포맷
- 다음 분기 월예산 시나리오
- 제품 개선이 필요한 성장 병목

**시각 자료:** 채널×상품 성과 히트맵과 다음 분기 선택지 3안.

**결정 요청:** 다음 분기 예산, 유지 채널, 제품 개선 이슈.

## 부록

### A. 원문 조사 주장 검증표

경쟁사 규모, 매출, 광고상품 가격, 사용자 수, 인플루언서 단가를 원문 링크와 대조한다.

### B. 상품 상태표

운명상회 상품별 가격, 공개 여부, 판매 가능 여부, 랜딩 경로, 대표 CTA를 관리한다.

### C. 콘텐츠 캘린더

12주 주제, 원본 콘텐츠, 채널별 변환, 게시일, 담당자, 캠페인 코드를 관리한다.

### D. KPI 정의서

각 지표의 계산식, 데이터 원천, 분모, 기준 시각, 결측 처리 방식을 고정한다.

### E. 광고·협찬 검수 체크리스트

문구, 이미지, 랜딩, 가격, 상품 상태, 광고 표시, 개인정보, 추적 동의를 게시 전에 확인한다.

## 브리핑 제작 순서

1. 1~3장: 사실과 현재 상태 확정
2. 4~6장: 시장 가설·타깃·메시지 승인
3. 7~10장: 경쟁·채널·콘텐츠·퍼널 설계
4. 11~13장: 90일 일정·예산·KPI 확정
5. 14~17장: 측정·실험·리스크·운영 책임 확정
6. 18장: 90일 종료 판정 기준 사전 합의

이 순서를 따르면 `전략 설명 → 실행 승인 → 측정 계약 → 운영 책임`이 끊기지 않는다.
