사주는 한 번만,
회사는 이번 선택만.

이미 저장된 이름, 생년월일, 태어난 시가 있으면 다시 입력하지 않습니다. 이번 화면에서는 회사와 오퍼 조건을 중심으로 받습니다.

개인 사주저장 프로필 자동 사용
이번 선택회사·직무·조건 입력
저장 방식민감 정보는 URL에 미노출
저장된 사주 프로필을 확인하는 중입니다. 프로필이 완전하면 이름·생년월일·태어난 시 입력칸을 접어 둡니다.
새 사주로 볼 때만 입력

기존 회원 프로필이 있으면 이 영역은 자동으로 접히고, 새 사주로 보기일 때만 다시 열립니다.
