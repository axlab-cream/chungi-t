나, 올해 연애 가능?

올해 연애운은 무조건 된다, 안 된다로 자르지 않습니다. 입력값을 기준으로 가능성, 주의점, 지금 할 작은 행동까지 이어서 봅니다.

누구의 올해 흐름을 볼까요?

저장된 사주 프로필이 있으면 다시 묻지 않고 이어갈 수 있습니다.

입력 방식
저장된 프로필 사용을 선택했습니다. 로그인 후 기본 사주값이 확인되면 생년월일시는 다시 묻지 않고, 이 화면에서는 애인성 기준과 현재 상태만 확인합니다.

생년월일시를 알려주세요

도화와 올해 세운 흐름을 계산하려면 태어난 날짜와 시간이 필요합니다.

선택 입력입니다. 결과 문장 호칭에만 씁니다.

양력 / 음력

애인성 기준을 맞출게요

성별로 자동 판단하거나, 관성·재성 중 원하는 애인성 기준을 직접 고를 수 있습니다.

배우자성 해석에서 상대 코드와 관계 안정감을 보는 기준입니다.
전통 애인성 계산에만 사용합니다. 직접 기준을 고르면 이 값은 쓰지 않습니다.

현재 관계 상태는 어디쯤인가요?

같은 운도 솔로, 썸, 연애, 재회 고민에 따라 행동 가이드가 달라집니다.

현재 상태

올해 운 흐름 확인

일반 고객은 자동 계산으로 두고, 운영·검수 환경에서는 계산된 십성을 직접 맞춰볼 수 있습니다.

세운·대운·월운 십성 확인하기
올해 전체 연애 무드를 여는 기준입니다.
몇 년 단위의 관계 패턴과 속도감을 보는 기준입니다.
연락, 만남, 고백 타이밍을 월 단위로 좁힐 때 씁니다.
입력값은 올해 연애운 리포트 생성에만 사용합니다. 생년월일시는 주소창에 붙이지 않고, 로그인 후에도 원래 입력 흐름으로 돌아올 수 있게 이어갑니다.
