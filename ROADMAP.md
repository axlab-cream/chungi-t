## Default Roadmap Request

# 프로젝트 개발 진행 규칙

이 프로젝트는 전체 기능을 한 번에 개발하지 않는다.

모든 개발은 단계별(Task 단위)로 진행하며,
각 단계가 완료될 때마다 사용자에게 결과를 제출하고
사용자의 승인 이후에만 다음 단계를 진행한다.

절대 다음 단계를 미리 개발하거나
예측하여 구현하지 않는다.

---

# 개발 프로세스

모든 단계는 아래 순서를 반드시 따른다.

1. 작업 분석
2. 작업 계획 설명
3. 개발 진행
4. 결과 제출
5. 사용자 검토
6. 수정 반영
7. 승인
8. 다음 단계 진행

---

# 개발 규칙

## Rule 1

한 번에 하나의 Task만 수행한다.

금지

- 여러 Task 동시 개발
- 다음 단계 미리 개발
- 추측 개발

---

## Rule 2

Task가 끝나면 반드시 아래 내용을 출력한다.

### Task 완료 브리핑

각 Task 종료 시 터미널에 `CreamAI/workflows/task-completion-brief.md` 형식의
체크박스 브리핑을 먼저 출력한다.

체크박스는 실제 수행된 단계만 `[x]`로 표시한다.
수행하지 않은 단계는 `[ ]`로 남기고 `미완료/미실행 항목`에 사유와 다음 처리를 적는다.

### 완료 보고

완료 Task

진행 내용

생성 파일

변경 파일

다음 예정 작업

---

## Rule 3

반드시 사용자 승인을 기다린다.

다음과 같이 질문한다.

> 해당 단계가 완료되었습니다.
>
> 확인 후
>
> **다음**
>
> 을 입력하면 다음 단계를 진행합니다.

승인 문구는 아래 줄바꿈을 보존한다.

다음
을 입력하면 다음 단계를 진행합니다.

사용자가

- 다음
- 진행
- Continue

중 하나를 입력하기 전까지 절대 다음 단계를 수행하지 않는다.

# 수정 요청 규칙

사용자가 수정을 요청하면

새로운 기능을 추가하지 않는다.

수정 완료 후 다시 결과를 제출한다.

사용자가 승인하면 다음 단계로 이동한다.
