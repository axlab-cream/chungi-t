# C01 · Play Console 선언 자료

작성일 2026-09-10. 답은 코드에서 확인한 실제 처리 기준으로 적었다. **확인하지 못한 값은
`미확인` 으로 남기고 추정으로 채우지 않았다.**

## 1. 대상 연령층

**18세 이상으로 신고한다.**

| 근거 | 내용 |
|---|---|
| 유료 디지털 상품 | 상담 19개가 4,900~49,900원 건당 결제다 |
| 상담 주제 | 연애·결혼·이직·퇴사·소비 등 성인의 의사결정을 다룬다 |
| Families 정책 회피 | 아동을 대상에 포함하면 광고 SDK·수집 정보·연령 설계에 Families 요건이 붙는다. 이 서비스는 아동 대상이 아니다 |

**콘텐츠 등급은 여기서 확정하지 않는다.** 등급은 IARC 설문 답변으로 산출된다. 아래는 그
설문에 넣을 답과 근거이고, 결과 등급은 콘솔이 계산한 값을 그대로 쓴다.

| 설문 항목 | 답 | 근거 |
|---|---|---|
| 폭력 | 없음 | 해당 콘텐츠 없음 |
| 성적 내용 | 없음 | 연애·궁합을 다루지만 성적 묘사가 없다 |
| 욕설 | 없음 | 생성 문구에 금지 어휘 검증기가 있다 |
| 약물·주류·담배 | 없음 | — |
| 도박·모의 도박 | **없음** | 가격이 고정이고 결과가 무작위 보상이 아니다. 같은 입력은 같은 결과로 모인다 |
| 사용자 간 상호작용 | 없음 | 공개 게시·댓글·채팅 기능이 없다. 결과 화면의 질문은 본인과 서비스 사이다 |
| 위치 공유 | 없음 | 위치를 수집하지 않는다 |
| 디지털 구매 | **있음** | 상담 건당 결제 |

## 2. Data safety 대응표

`항목 → 수집 화면/SDK → 목적 → 전송 대상 → 저장 → 보관 → 삭제 → 필수/선택 → 답변`

| 데이터 | 수집 위치 | 목적 | 제3자 전송 | 저장 위치 | 삭제 | 필수 | Data safety 답변 |
|---|---|---|---|---|---|---|---|
| 이메일 | 소셜 로그인 | 계정 식별, 결제 안내 | Supabase(처리자) | `auth.users`, 주문 | 탈퇴 시 | 필수 | 개인 정보 > 이메일 · 수집 O · 공유 X |
| 이름(표시명) | 사주 프로필 | 결과에 부르는 이름 | Supabase, **OpenAI** | `cheongi_user_profiles` | 탈퇴 시 | 선택 | 개인 정보 > 이름 · 수집 O · 공유 X |
| 생년월일·시각·성별 | 사주 프로필 | 명식 계산 | Supabase, **OpenAI** | `cheongi_user_profiles` | 탈퇴 시 | 필수 | 개인 정보 > 기타 · 수집 O · 공유 X |
| 상대 생년월일 | 궁합·택일 입력 | 두 명식 비교 | Supabase, **OpenAI** | 리포트 문맥 | 탈퇴 시 | 선택 | 개인 정보 > 기타 · 수집 O · 공유 X |
| 전화번호 | 결제 화면 | 결제 안내·문의 대조 | 결제사 | `cheongi_payment_orders` | 거래 기록 보관 기간 | 필수(결제 시) | 개인 정보 > 전화번호 · 수집 O · 공유 X |
| 상담 주관식 답변 | 상담 입력 | 해석 생성 | **OpenAI** | 리포트 문맥 | 탈퇴 시 | 선택 | 앱 활동 > 기타 사용자 생성 콘텐츠 · 수집 O |
| 생성된 해석 | 서버 생성 | 결과 제공·재열람 | Supabase | `cheongi_reports` | 탈퇴 시 | — | 앱 활동 > 기타 · 수집 O |
| 결과 화면 질문 | 이어서 질문 | 추가 답변 | **OpenAI** | 리포트 `chatHistory` | 탈퇴 시 | 선택 | 앱 활동 > 기타 사용자 생성 콘텐츠 · 수집 O |
| 신고 내용 | 결과 신고 | 품질 개선 | Supabase | 리포트 `flags` | 탈퇴 시 | 선택 | 앱 활동 > 기타 · 수집 O |
| 결제 토큰·주문 | Play 결제 | 영수증 검증 | **Google** | `cheongi_payment_orders.tid` | 거래 기록 보관 기간 | 필수(결제 시) | 금융 정보 > 구매 내역 · 수집 O |

**암호화**: 전 구간 HTTPS. 앱은 `usesCleartextTraffic="false"`.
**삭제 요청**: 앱 내 `/leave`, 웹 `https://umsh.kr/leave`.

### 확인이 필요한 항목

| 항목 | 왜 미확인인가 |
|---|---|
| 보관 기간 | 개인정보처리방침의 문구와 실제 DB 보관 정책이 대조되지 않았다 |
| 분석·진단 SDK | 앱에 별도 분석 SDK 를 넣지 않았다. Vercel·Supabase 의 서버 로그 범위는 확인 필요 |
| 결제사 전송 항목 | 이니시스 MID 미수령으로 실제 전송 필드를 확인하지 못했다 |

## 3. App content 답변

| 항목 | 답 | 근거 |
|---|---|---|
| 개인정보처리방침 URL | `https://umsh.kr/privacy` | 로그인 없이 열린다(200 확인) |
| 광고 포함 | **없음** | 광고 SDK 없음 |
| App access | 로그인 필요 | 심사용 계정 제공 (C03) |

| 정부 앱 | 아니오 | — |
| 민감 권한 | **없음** | 매니페스트 권한은 INTERNET 과 BILLING 둘뿐 |

## 4. 권한 목록 (병합 매니페스트 기준으로 재확인 필요)

| 권한 | 출처 | 목적 |
|---|---|---|
| `android.permission.INTERNET` | 앱 | 해석 생성·조회 |
| `com.android.vending.BILLING` | 앱 + billing 8.3.0 | Play 결제 |

**NOT_TESTED** — 최종 AAB 의 병합 매니페스트를 확인하지 않았다. 플러그인이 권한을 더
끌어올 수 있어 빌드 후 `aapt dump permissions` 로 대조해야 한다.
