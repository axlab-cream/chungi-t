## 조사 중 확인한 기존 결함

앱 전환과 별개로 지금 운영에 있는 문제다.

| ID | 내용 | 근거 | 상태 |
|---|---|---|---|
| BASE-01 | **프로덕션이 origin/main 보다 16커밋 뒤처져 있다** | 프로덕션 홈이 아직 `UMSH` 표기, 신년운세·결혼택일이 `SOON` 태그 | 미조치 |
| BASE-02 | Vercel 프로젝트에 Git 저장소 연결이 없다. README 38행은 main push 가 자동 배포된다고 적었지만 실제로는 수동 CLI 배포다 | `vercel project inspect` 에 Git 섹션 없음 | 미조치 |
| BASE-03 | `/api/payment/config` 가 고객에게 환경변수 이름(`INICIS_MID, INICIS_SIGNKEY`)을 노출한다 | 프로덕션 응답 확인. 코드는 `aca0bf3` 에서 이미 수정됨 | 코드 수정됨, 미배포 |
| BASE-04 | `cheongi_reports` 에 저장소 SQL 의 컬럼 7개가 없다 | 익명 컬럼 프로브 8/15 | 앱이 쓰지 않는 관리용 컬럼. 기능 영향 없음 |
| BASE-05 | `INICIS_SIGNKEY` 가 Vercel 환경변수에 없어 웹 결제가 열려 있지 않다 | `vercel env ls production` | 미조치 |
| BASE-06 | 생성형 AI 결과에 신고 경로가 없다 | 코드 전수 확인 | **앱 심사 차단 요인 (R14)** |

BASE-01·03·05 는 앱 작업 이전에 웹 배포로 해결해야 한다. 앱은 이 웹을 그대로 띄우므로
프로덕션 상태가 곧 앱의 상태가 된다.
