# 이미지 교체 폴더

이 폴더의 이미지는 디자인 검토용 복사본입니다. 운영 원본과 분리되어 있습니다.

- `teaser-hero.webp`: 티저 상단 이미지, 권장 4:3
- `reading-list-cover.webp`: 목록 카드 이미지, 권장 1:1
- `reading-detail-hero.webp`: 해석 상세 상단 이미지, 권장 4:3

`services/`에는 서비스별 대표 이미지 복사본을 두었습니다. `../js/services.js`의 각 `image` 경로를 확인한 뒤, 같은 파일명으로 교체하면 해당 서비스의 티저·목록·상세에 반영됩니다. 공통 이미지를 쓰는 서비스는 한 이미지를 교체하면 여러 화면에 함께 반영되므로, 개별 이미지를 원하면 새 파일을 넣고 `image` 경로를 바꾸세요.
