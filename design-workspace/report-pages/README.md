# 서비스별 해석 디자인 작업실

운영 서비스와 연결되지 않은 정적 미리보기입니다. `index.html`에서 20개 서비스 각각의 **티저·해석 목록·해석 상세**를 열 수 있습니다. 주소의 `?service=work_move`처럼 서비스 키가 달라지므로 화면별 비교 링크를 공유하기 쉽습니다. 픽셀 단위 100% 일치는 운영 화면별 대조 작업이 끝난 서비스부터 확정합니다.

## 자료의 범위

- **보관함 확인**: 2026-09-22 기준 `good1621` 보관함에서 본문을 읽을 수 있었던 서비스 11종의 해석 요지를 비식별·축약했습니다.
- **무료 티저 확인**: 공개된 유료 서비스 10종 모두 입력 후 무료 화면의 구조와 핵심 신호를 확인해 쉬운 말로 재작성했습니다. 운영 원문 그대로의 복제는 아닙니다.
- **개인값 제거**: 궁합류는 운영 티저의 화면 구조·섹션·안내 흐름을 기준으로 만들고, 상대 이름·생년월일 같은 개인값은 작업실에 저장하지 않습니다.
- **오늘운**: 무료 결과의 비식별 요지를 배치했습니다. 결제 전 티저가 없는 서비스이므로 별도 표시합니다.
- **본문 미확인**: 나머지 9종은 공개 서비스 설명을 바탕으로 화면 구조만 만들었습니다. 실제 해석처럼 보이지 않도록 각 화면에 표시했습니다.
- 개인 이름·생년월일·회사명·리포트 ID·주소는 이 폴더에 저장하지 않았습니다. 유료 상세의 원문 전체나 구매 권한도 복제하지 않았습니다.
- 운영 홈에서 공개된 서비스는 로그인 상태로 스토리 → 입력 → 무료 티저를 확인할 수 있습니다. 입력 과정에서 새 리포트가 생성될 수 있으므로, 이 작업실은 운영 화면과 자동 연결하지 않습니다.
- 상대 생년월일이 필요한 궁합류에는 실존 인물 정보를 넣지 않았습니다. 가상 입력 결과는 화면 구조 검토에만 사용하고, 실제 두 사람의 해석 검증으로 간주하지 않습니다.

## 수정할 곳

| 대상 | 파일 |
|---|---|
| 20개 서비스별 제목·티저 해석·상세 요약·목차·이미지 경로 | `js/services.js` |
| 공통 화면 구성과 링크 | `js/preview.js` |
| 색상·글꼴·간격 | `css/tokens.css` |
| 서비스 목록과 화면별 배치 | `css/pages.css` |
| 버튼·상단 탐색·편집 표시 | `css/components.css` |

각 화면의 **편집 가이드 보기**를 누르면 수정 필드와 이미지 파일명을 볼 수 있습니다. 이미지는 `assets/services/` 안에서 서비스 키와 같은 이름의 파일을 교체하면 됩니다. `love_mind`, `love_again`, `love_spouse`는 공통 `assets/reading-list-cover.webp`, `today_fortune`은 공통 `assets/teaser-hero.webp`를 쓰므로, 서비스별로 따로 교체하려면 이미지를 추가하고 `js/services.js`의 해당 `image` 경로를 바꾸세요.

## 안전 범위

- 실제 회원·주문·리포트 저장소, 서버 API, 인증, 결제, 분석 및 브라우저 저장소와 연결되지 않습니다.
- 정적 파일만 사용합니다. 이 폴더를 수정해도 운영 서비스에 반영되지 않습니다.
- 디자인 승인 후 실제 서비스 적용은 별도 요청과 검증이 필요합니다.
