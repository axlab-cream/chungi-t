# good1621 실제 화면 디자인 복제본

`site/`은 `사주/` 운영 화면 소스와 이미지·글꼴을 별도 폴더로 원형 복사한 것입니다. 운영 코드·파일과 분리되어 있으므로 이 폴더에서 디자인을 수정해도 운영 화면에는 반영되지 않습니다.

- 티저: 각 서비스의 `04-step-4-report/index.html`
- 해석 목록: 각 서비스의 `05-step-5-chat/chat.html`
- 해석 상세: 각 서비스의 `06-step-6_1-report-detail/index.html`
- 천명사주 티저는 `site/cmdg/index.html`에 구현되어 있습니다.

`good1621-live-pages.html`은 로그인된 `good1621` 계정의 실제 티저·목록·상세 화면으로 바로 열어 대조하는 전용 목록입니다. 개인값과 리포트 ID를 포함하므로 로컬 작업 폴더 밖으로 공유하지 마세요.

일부 서비스는 운영 소스에 특정 단계 파일이 아직 없거나, 상세가 결제 권한·서버 데이터로 조립됩니다. 이런 경우에도 존재하는 운영 소스는 원형으로 포함했으며, 실제 화면은 목록의 `운영 화면` 링크로 확인합니다.

## 이미지 검토본

- `review/cmdg-longform.html`: 천명사주 저장 해석의 한눈에 보기·첫 하이라이트를 검토하는 격리 화면입니다.
- 이 화면의 요약 이미지는 세로 원본 전체를 카드 폭에 맞춰 보여 주며, 첫 하이라이트에는 `site/사주/assets/cmdg-wood-order-highlight-v1.png`만 사용합니다.
- 위 검토본의 CSS와 이미지는 운영 파일과 분리되어 있습니다. 운영 반영은 검토 확정 뒤 별도 변경으로 진행합니다.
