# 천명사주 검토본 — 인생 흐름 지도

상태: 로컬 격리 검토본 구현 완료 · 운영 반영 전  
대상: `review/cmdg-longform.html`

## 목적

긴 해석을 읽기 전에 사용자가 **지금 어느 해석 층에 있는지**와 **돈·직장·관계에서 실제로 확인한 정보가 어디까지인지** 한 화면에서 파악하게 한다.

## 근거와 표시 규칙

| 영역 | 현재 검토본의 근거 | 표시 방식 |
| --- | --- | --- |
| 큰 흐름 | 저장 리포트의 `경진 대운` | 현재 큰 흐름 레일 |
| 올해 참고 | 저장 리포트의 `2026년 병오` | 현재 큰 흐름 안의 연간 참고 레일 |
| 삼재 | 저장 리포트의 출생년 지지와 기준 연도 | 3년 주기·현재 단계·계산 근거 |
| 재물·보상 | 제안 카드의 역할·보상·마감을 담은 한 문장 | 확인 항목 0~1개 진행 막대 |
| 일·직장 | 현재 자리와 새 선택을 담은 두 문장 | 확인 항목 0~2개 진행 막대 |
| 관계·연애 | 약속·부담·경계를 담은 한 문장 | 확인 항목 0~1개 진행 막대 |

진행 막대는 좋은/나쁜 운, 돈·직장·연애의 확률 또는 인생 점수가 아니다. 각 영역을 실제 조건까지 얼마나 확인했는지를 나타낸다.

## 사용자 흐름

1. 요약 다음의 `인생 흐름 지도`에서 큰 흐름·올해 참고·현재 삼재 단계와 기간을 본다.
2. 분야별 확인 그래프에서 비어 있는 실제 조건을 확인한다.
3. `재물·보상 카드로 이동` / `일·직장 카드로 이동` / `관계·연애 카드로 이동`을 눌러 해당 추가 정보 입력 카드로 이동한다.
4. 실제 조건을 입력하면 해당 분야의 `확인한 항목 n/m`과 막대가 갱신된다. 항목 수는 입력칸 수이며 운세 평가가 아니다.

## 회원별 변경 계약

운영 적용 시 그래프는 리포트별로 다음처럼 계산된 **실제 원자료**만 받아야 한다.

```ts
type LifeFlowMapSource = {
  daeun?: { label: string; basis: string }
  yearly?: { year: number; label: string; basis: string }
  samjae?: { status: 'active' | 'upcoming' | 'none'; basisYear: number; label: string }
  domains: Record<'money' | 'work' | 'love', { sourceCards: string[]; actualConditionFields: string[] }>
}
```

- `samjae`는 저장 리포트의 출생년 지지와 기준 연도에서만 계산한다. 원자료가 없으면 `계산할 정보 없음`으로 정직하게 표시하고, 다른 값으로 추정하지 않는다.
- 도메인별 수치는 사용자가 입력한 현실 조건의 완성도일 뿐, 운세의 좋고 나쁨을 나타내지 않는다.
- 사주 해석을 확률·수입·승진·연애 성공 예측 그래프로 바꾸지 않는다.

## 디자인 계획

- 대상/화면 역할: 긴 개인 리포트의 첫 판단 지점, 모바일 우선.
- 토큰: 배경 `#16130e`, 표면 `#17140f`, 주 강조 `#d8ba72`, 본문 `#fff3d6`, 보조 `#d5cec1`, 미연결 `#c9b78e`.
- 서체 역할: 기존 서비스 한글 본문을 유지하고, 제목 24px·레이블 11~12px·본문 12~14px으로 계층화.
- 시그니처 요소: 대운 곡선 아래에 현재 삼재의 3년 기간과 현재 단계를 쉬운 말로 표시하고, 원자료·계산 근거는 접힌 영역에 둔다.
- 피할 것: 의미 없는 상승 곡선, 녹색=좋음/빨강=나쁨 점수, 임의 연령대·날짜, 점성술식 사건 예언, 화려한 장식 차트.

## 검증 기준

- 큰 흐름 `경진 대운`, 올해 `2026년 병오`, 계산된 삼재 기간·현재 단계가 화면에 보여야 한다.
- 세 분야는 초기 `0/n`이며, 추가 정보 입력에 맞춰 해당 막대만 갱신해야 한다.
- 카드 이동 버튼은 대응하는 열림 가능한 카드로 이동해야 한다.
- 모바일 375px에서 가로 넘침 없이 읽혀야 하고, 키보드 포커스와 reduced-motion 환경을 고려한다.
- 운영 API·저장소·회원 리포트는 변경하지 않는다.
