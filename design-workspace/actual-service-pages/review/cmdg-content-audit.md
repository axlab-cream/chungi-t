# 천명사주 저장 리포트 해석 검수 메모

문장·강조·표/그래프 제안의 상세 명세: [천명사주 문안·시각화 정밀 검토](cmdg-editorial-visual-audit-20260922.md)

검수 기준일: 2026-09-22  
대상: 로그인한 관리자 보관함의 천명사주 저장 리포트 16개 해석 카드  
범위: 운영 원문은 변경하지 않고, 운영 반영 전 수정 요건만 기록한다.

## 우선 반영이 필요한 공통 요건

1. 카드 제목의 원문 기호와 전문어를 사용자용 제목에서 분리한다. `乙亥`, `을목`, `편재`, `편관격`, `조후 cool`, `庚辰`, `丙午` 등은 펼친 뒤의 `해석 근거`로 옮기고, 제목에는 쉬운 말 한 문장만 남긴다.
2. 한 카드의 첫 화면은 `한 줄 요약 → 왜 그렇게 읽는지 → 오늘 해볼 행동` 순서로 3단 구성한다. 현재는 문단이 길고 전문어가 초반에 몰려 중학생 독해 난도가 높다.
3. 사람의 마음, 만나는 상대, 시기, 돈의 결과를 단정하지 않는다. 해석은 가능한 경향과 확인할 조건으로 쓰고, 실제 결정은 계약·비용·대화·건강 상태 등 확인 가능한 정보로 하도록 안내한다.
4. 문단당 2~3문장, 문장당 45자 안팎을 기준으로 나눈다. 한자어·명리 용어에는 첫 등장 시 쉬운 풀이를 붙인다.

## 카드별 수정 요건

| 카드 | 판정 | 수정 요건 |
| --- | --- | --- |
| 1. 나의 매력 기본 스펙 | 우선 | 약 1,420자·33문장으로 가장 길다. `乙亥 일주·을목 일간`은 보조 근거로 내리고, 첫 문단을 3문장 요약으로 축약한다. |
| 2. 내가 버티는 방식 | 보완 | `을목·불 기운`을 풀어 쓰고, 무리하는 신호와 쉬어 가는 행동을 각각 한 문장으로 제시한다. |
| 3. 숨겨진 진짜 성격 | 우선 | 약 900자·19문장이다. 타인의 평가를 단정하는 표현을 줄이고, 상황별로 달라질 수 있음을 먼저 밝힌다. |
| 4. 내 기운이 쏠린 곳 | 우선 | 제목의 `목 과다·화 보완·수 중심·편관격·조후 cool`은 사용자용 문장으로 교체한다. 예: `힘이 한쪽에 몰릴 때 살필 점`. |
| 5. 내 기운을 살리는 것 | 보완 | 전문어보다 수면·일정·대화 속도처럼 실제로 조절 가능한 행동부터 보여 준다. |
| 6. 지금 이 고민, 무엇부터 | 우선 | 약 777자·18문장이다. 고민 해결 순서를 최대 3단계 체크리스트로 바꾸고, `편재`는 근거 영역에 한 번만 둔다. |
| 7. 일과 돈의 결 | 보완 | 금전 결과를 보장하는 말이 없는지 재검수한다. 보상·계약·예산을 확인하는 행동 중심으로 정리한다. |
| 8. 버틸지 옮길지 | 보완 | 이직을 권하거나 만류하는 인상 대신, 역할·보상·성장·건강의 비교 기준을 제시한다. |
| 9. 돈이 들어오는 방식 | 보완 | 수입 시기·금액의 예고처럼 읽히지 않도록, 가치 제공 방식과 비용 확인의 조언으로 한정한다. |
| 10. 인연의 반복 패턴 | 보완 | 관계 실패 원인을 개인 성향으로 단정하지 않고, 반복되는 대화·경계 설정의 관찰 항목으로 쓴다. |
| 11. 만나게 될 사람의 분위기 | 우선 | 특정 사람의 외모·성격을 예측하는 제목은 `편안한 관계의 조건`처럼 바꾼다. |
| 12. 거리를 둬야 할 사람 | 우선 | 타인을 배제하도록 유도하지 않게, 위험 신호·대화 경계·도움 요청 기준을 구분해 쓴다. |
| 13. 인연이 오는 시기 | 우선 | 만남 시점을 확정하지 말고, 관계를 시작하거나 점검하기 좋은 개인의 준비 조건으로 전환한다. |
| 14. 앞으로 흘러갈 큰 운 | 우선 | 결과를 예고하는 제목은 `앞으로 살펴볼 흐름`으로 완화한다. `庚辰·丙午`는 근거의 괄호 설명으로 이동한다. |
| 15. 올해 달라지는 것 | 우선 | `달라진다`의 확정형을 피하고 `올해 살필 변화`로 고친다. 변화 여부를 확인할 행동 지표를 덧붙인다. |
| 16. 지금 붙잡아야 할 신호 | 보완 | 당장 실행할 한 가지를 굵게 제시하고, 심리·건강·금전 문제는 전문 도움 또는 실제 기록 확인을 병행하도록 안내한다. |

## 반영 전 확인 항목

- 카드 1, 3, 6은 길이 축약 후 실제 모바일 화면에서 스크롤 부담을 다시 확인한다.
- 카드 7~9는 재무 조언으로 오해될 수 있는 확정·수익 표현을 별도 점검한다.
- 카드 10~13은 특정 상대·관계의 결론을 단정하는 표현을 제거한다.
- 카드 14~16은 미래·시기 단정형을 조건형 문장으로 바꾸고, 사용자가 확인할 행동 지표를 넣는다.
