# 운명상회 저비용 영상 제작기 PRD

## 1. 무엇을 만드는가

사진 1장을 바탕으로 7초 세로 영상을 만들기 위한 내부 제작 도구를 만든다.

목표는 Higgsfield 같은 유료 서비스를 무조건 쓰는 것이 아니라, 먼저 무료 또는 저비용 초안을 만들고 필요한 컷만 유료 고품질로 넘기는 것이다.

## 2. 왜 필요한가

현재 영상 제작은 비용이 바로 늘어난다.

- 실패한 컷도 크레딧을 쓴다.
- 크레딧이 부족하면 작업이 멈춘다.
- 프롬프트를 매번 다시 쓰느라 시간이 든다.
- 결과물이 웹툰처럼 보이거나, 옆모습만 나오거나, 핸드폰만 보는 문제가 반복된다.
- 남성 컷이나 커플 컷이 빠질 수 있다.

이 도구는 실제 생성 전에 이런 문제를 먼저 잡는 역할을 한다.

## 3. 핵심 목표

- 유료 크레딧 사용량을 줄인다.
- 컷별 프롬프트를 자동으로 만든다.
- 4컷 또는 6컷씩 나눠서 작업한다.
- 무료 컷과 유료 컷을 구분한다.
- 예상 크레딧을 먼저 보여준다.
- 결과물을 압축파일로 묶는다.
- 실패 원인을 기록한다.

## 4. 만들지 않는 것

- 영상 생성 모델 자체를 새로 만들지는 않는다.
- 완벽한 얼굴 동일성을 보장하지는 않는다.
- 유료 크레딧을 자동 구매하지 않는다.
- 사람의 최종 눈검수를 대체하지 않는다.
- 노출이 강한 성인 콘텐츠는 만들지 않는다.

## 5. 사용자

- 영상 제작자: 컷을 준비하고 영상을 만든다.
- 검수자: 실사감, 얼굴 동일성, 컷 구성, 비용을 확인한다.

## 6. 기본 사용 흐름

1. 작업표를 불러온다.
2. 제작 방식을 고른다.
3. 4컷씩 또는 6컷씩 나눌지 고른다.
4. 다시 계산한다.
5. 전체 컷 수, 무료 컷 수, 유료 컷 수, 예상 크레딧을 확인한다.
6. 컷별 프롬프트를 확인한다.
7. 준비 압축파일을 만든다.
8. 무료 영상 초안을 만든다.
9. 필요한 컷만 유료 고품질 제작으로 넘긴다.

## 7. 제작 방식

### 무료 초안만

유료 크레딧을 쓰지 않는다.

사용처:

- 테스트
- 배경 컷
- 단순 카메라 움직임 컷
- 프롬프트 검토

### 무료 초안 + 중요 컷만 유료

대부분은 무료 초안으로 만들고, 중요한 컷만 유료 고품질로 계산한다.

사용처:

- 22컷 전체 제작
- 비용을 줄이면서 품질이 필요한 경우
- 커플 컷이나 첫 화면 컷만 고품질이 필요한 경우

### 전체 유료 고품질

모든 컷을 유료 고품질로 계산한다.

사용처:

- 최종 납품 전 비용 계산
- 전체 컷을 최고 품질로 만들 때

## 8. 필수 기능

### 작업표

컷 정보를 담는다.

포함 내용:

- 작업 이름
- 한 번에 만들 컷 수
- 제작 방식
- 기준 얼굴 이미지
- 컷 목록
- 각 컷의 장소, 행동, 카메라, 움직임, 소리

### 프롬프트 만들기

각 컷마다 영상 생성용 프롬프트를 만든다.

반드시 들어갈 내용:

- 실사 영상
- 같은 인물 유지
- 20대 후반 또는 요청 연령
- 정면 또는 살짝 정면
- 자연스러운 작은 움직임
- 웹툰/애니/그림체 금지
- 글자/로고/워터마크 금지
- 핸드폰 반복 금지

### 비용 계산

유료 컷이 몇 개인지와 예상 크레딧을 보여준다.

현재 기준:

- 무료 초안: 0 크레딧
- 저가 유료: 7초 기준 약 17.5 크레딧
- 고품질 유료: 7초 기준 약 45.5 크레딧

### 묶음 계획

컷을 4컷 또는 6컷씩 나눈다.

예:

- 1번째 묶음: 1~4번 컷
- 2번째 묶음: 5~8번 컷
- 3번째 묶음: 9~12번 컷

### 주의할 점 표시

다음 문제를 화면에 보여준다.

- 기준 얼굴 이미지 없음
- 옆모습이 너무 많음
- 핸드폰 중심 컷이 너무 많음
- 남성 컷 없음
- 커플 컷 없음
- 침대/샤워/수영장/의상 컷에 안전 문구 없음

### 압축파일 만들기

다음 파일을 압축파일로 묶는다.

- 작업표
- 컷별 프롬프트
- 묶음 계획
- 비용 계산
- 검수 체크리스트
- 결과 설명 파일

## 9. 화면 요구사항

화면은 쉬운 한국어를 사용한다.

사용자에게 보이는 주요 단어:

- 작업표
- 다시 계산
- 준비 압축파일
- 무료 영상 초안
- 컷
- 묶음
- 인물
- 구도
- 방식
- 크레딧
- 주의할 점

내부 코드값은 프로그램 처리를 위해 유지한다.

- `free_local`
- `hybrid`
- `paid_quality`
- `woman`
- `man`
- `couple`

## 10. 완료 기준

- 화면을 열 수 있다.
- 예제 작업표를 불러올 수 있다.
- 다시 계산하면 컷 목록과 비용이 나온다.
- 프롬프트가 한글로 나온다.
- 준비 압축파일을 만들 수 있다.
- 실제 이미지 1장으로 무료 7초 영상 초안을 만들 수 있다.
- 영상은 720x1280, 7초로 생성된다.
