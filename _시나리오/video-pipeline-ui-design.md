# 운명상회 영상 제작기 UI/UX 설계

## 1. 화면 목표

이 화면은 예쁘게 보여주는 페이지가 아니라, 영상을 만들 때 실수를 줄이는 작업 화면이다.

사용자가 바로 알아야 하는 것은 다섯 가지다.

- 전체 몇 컷인지
- 무료로 만들 컷이 몇 개인지
- 유료로 만들 컷이 몇 개인지
- 예상 크레딧이 얼마인지
- 어떤 컷에 문제가 있을 수 있는지

그래서 화면은 `작업표 편집`보다 `요약, 비용, 컷 목록, 주의할 점`을 먼저 보여준다.

## 2. 화면 구성

### 상단

항상 보이는 버튼 영역이다.

- `예제 불러오기`: 샘플 작업을 불러온다.
- `다시 계산`: 컷 정보, 비용, 프롬프트를 다시 만든다.
- `준비 ZIP 만들기`: 실제 영상을 만들기 전에 프롬프트와 작업표를 ZIP으로 묶는다.
- `무료 영상 초안`: 내 컴퓨터에서 비용 없이 7초 영상 초안을 만든다.

### 작업 요약

상단 바로 아래에서 현재 상태를 보여준다.

- 계산 전 / 계산 완료 / ZIP 완료 / 일부 실패
- 작업 이름
- 전체 컷
- 무료 컷
- 유료 컷
- 예상 크레딧

### 작업 순서

현재 어느 단계인지 보여준다.

1. 작업표
2. 계산
3. 검토
4. 묶기

### 제작 설정

왼쪽 영역이다.

- 제작 방식
- 한 번에 만들 컷 수
- 구성 확인
- 주의할 점

제작 방식은 세 가지다.

- `무료 초안만`: 크레딧을 쓰지 않는다.
- `무료 초안 + 중요 컷만 유료`: 대부분은 무료로 만들고 중요한 컷만 유료로 계산한다.
- `전체 유료 고품질`: 모든 컷을 유료 고품질로 계산한다.

### 구성 확인

현재 컷 구성이 한쪽으로 쏠렸는지 확인한다.

- 여성 컷 수
- 남성 컷 수
- 커플 컷 수
- 정면 컷 수
- 유료 컷 수

이 영역은 이전 제작에서 나온 문제를 막기 위한 것이다.

- 전부 여성만 나오는 문제
- 남성이 빠지는 문제
- 전부 옆모습인 문제
- 핸드폰만 보는 문제
- 유료 컷이 너무 많아지는 문제

### 컷 목록

가운데 가장 큰 영역이다.

각 컷마다 다음을 보여준다.

- 컷 이름
- 인물
- 구도
- 제작 방식
- 예상 크레딧
- 검수 상태

행을 클릭하면 오른쪽에서 그 컷의 자세한 프롬프트를 볼 수 있다.

### 선택한 컷

오른쪽 영역이다.

- 인물
- 구도
- 제작 방식
- 모델
- 영상 길이
- 크레딧
- 최종 프롬프트
- 결과 경로

`프롬프트 복사` 버튼으로 바로 복사할 수 있다.

### 작업표 편집

하단 영역이다.

컷 정보 JSON을 붙여넣거나 수정한다. 수정 후 `다시 계산`을 누르면 화면 전체가 업데이트된다.

## 3. 쉬운 단어 기준

화면에서는 가능하면 쉬운 한국어를 쓴다.

- 작업표: 컷 정보를 모아둔 파일
- 다시 계산: 컷 목록, 비용, 프롬프트를 새로 만드는 버튼
- 준비 압축파일: 실제 생성 전에 필요한 파일을 묶은 압축파일
- 묶음: 한 번에 처리할 컷 그룹
- 컷: 영상 한 장면
- 방식: 무료 초안인지 유료 제작인지 나타내는 값
- 인물: 여성, 남성, 커플, 손과 소품, 배경 컷
- 구도: 정면, 살짝 정면, 옆모습, 부분 확대
- 크레딧: 유료 생성에 드는 비용 단위
- 무료 영상 초안: 내 컴퓨터에서 돈을 쓰지 않고 만드는 간단한 7초 영상
- 프롬프트: 영상 생성기에 넣을 장면 설명
- 주의할 점: 만들기 전에 확인해야 하는 문제

단, 시스템 내부 값은 그대로 둔다.

- `free_local`
- `hybrid`
- `paid_quality`
- `woman`
- `man`
- `couple`

이 값들은 프로그램이 읽는 값이므로 화면 표시만 한글로 바꾼다.

## 4. 디자인 기준

- 내부 작업 도구처럼 보이게 한다.
- 설명문은 짧게 쓴다.
- 숫자와 상태가 먼저 보이게 한다.
- 카드 안에 카드를 넣지 않는다.
- 버튼은 짧은 명령형으로 쓴다.
- 경고는 노란색, 성공은 초록색, 오류는 빨간색으로 구분한다.
- 모바일에서도 세로로 쌓여 읽히게 한다.
