# CMDG 운영 공통 템플릿·썸네일 이식

- 날짜: 2026-09-22
- 범위: 천명사주 신규 생성 및 기존 저장 리포트의 공통 카드 구조·공용 이미지 매핑

## 결정

공용 썸네일은 개인정보가 아니므로 16개 정적 자산을 배포 원본에 둔다. 회원별로 달라지는 이름, 저장된 풀이 원문, 만세력 계산값과 회원이 직접 기록한 현실 조건은 공유하지 않고 기존 리포트 API 값만 표시한다.

## 구현

- 신규 리포트 생성에서 천명사주 16개 섹션에 공용 이미지 키와 공개 경로를 순서대로 설정했다.
- 기존 저장 리포트는 저장 데이터를 쓰지 않고, 렌더링 직전에만 같은 공용 이미지를 매핑했다.
- 대운과 삼재는 서버 만세력 계산 결과를 API로 내보내고, 브라우저는 표시만 한다.
- 이미지 원본은 `사주/사주/assets/cmdg-review`에 둬 정적 빌드의 `public/assets/cmdg-review`로 복사되게 했다.

## 검증

- 집중 테스트 78/78 통과
- TypeScript, JavaScript 구문, diff 공백 검사 통과
- Vercel production build 통과 및 공개 산출물 이미지 16개 확인

## 주의·교훈

- 배포 스크립트의 실제 입력 경로는 최상위 `사주/assets`가 아니라 중첩된 `사주/사주/assets`다. 자산을 추가할 때 build 출력도 함께 확인한다.
- 공용 템플릿을 이식할 때 검토본의 특정 회원 문장이나 수치는 복사하지 않는다.
- 원격 push와 운영 배포는 프로젝트 `rules.md` §6 gate에 따라 실행하지 않았다.
