# 이직운 공용 리더 아래 구형 본문 중복 제거

## 증상

저장 이직운 리포트에서 공용 장문 리더가 정상으로 채워진 뒤에도 구형 결론, 풀이 흐름, 근거 카드, 상세 풀이, 행동, 주의, 연관 항목이 아래에 다시 노출됐다.

## 원인

정적 CSS는 `#detail-stack[data-umsh-filled] ~ #content` 형태의 형제 관계를 가정했다. 실제 런타임에서는 공용 렌더러가 `#detail-stack`을 `#content` 내부로 이동하므로 이 선택자가 일치하지 않았다.

## 해결

공용 리더가 이미 사용하는 `data-umsh-legacy-reading-ui` 표식을 구형 전용 노드에 부여했다. 공용 리더가 채워진 뒤 해당 노드만 숨기므로 대표 이미지, 진행률, 10개 토글, 고유 이미지, 마크다운 표, 회원별 대운 그래프, 공유/PDF 도구는 유지된다.

## 재사용 원칙

- 런타임이 DOM 위치를 바꾸는 화면에서는 형제 선택자보다 의미 기반 데이터 속성으로 구형 UI 범위를 명시한다.
- 컨테이너 전체를 숨기면 새 공용 리더까지 사라질 수 있으므로 구형 노드만 표식한다.
- 실제 저장 원문과 회원 계산값은 수정하지 않고 표현 중복만 제거한다.
