# 천명사주 검토본 추가 정보 입력 — 2026-09-22

## 결정

저장 리포트에 없는 현실 조건을 해석 문장으로 추정하지 않고, 로컬 격리 검토본에서 독자가 실제로 확인한 정보를 입력해 비교표에 반영하는 공통 패턴을 만들었다.

## 재사용 패턴

- 맥락별 정의: 제안 조건, 현재·새 직장 비교, 관계 실제 조건, 현재 계획.
- 동작: 한 항목 이상 입력 → 같은 맥락 카드의 표·안내문 반영 → 현재 탭 메모리에서만 유지 → 지우기 시 초기값 복원.
- 안전: 비어 있는 값은 `직접 확인`; 자동 의사결정·예언 없음; `textContent` 출력; 120자 제한; API/저장소/URL/브라우저 영속 저장소 미사용.

## 검증

- 단위·정적 검사 7/7, JavaScript 구문, TypeScript, diff 공백 검사 통과.
- 로컬 브라우저에서 직장 6칸 반영·초기화, 관계 조건 반영, 10개 패널 렌더를 확인했다.

## 범위

운영 리포트, 사용자 데이터, 인증, API, 배포는 변경하지 않았다. 운영 채택 시에는 별도의 개인정보 동의, 저장 위치·보존 정책, 권한·삭제 흐름, 서버 검증이 필요하다.
