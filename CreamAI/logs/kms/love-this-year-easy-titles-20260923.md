# 올해 연애운 해석 목록 쉬운 제목

## observation

- 운영 저장 리포트의 10개 토글 제목에 `일지 해(亥)`, `丙午`, `수(水) 기운`, `배우자성`, `관계궁` 같은 계산 근거가 한 줄에 함께 붙어 있었다.
- 제목만 읽어서는 무엇을 알려 주는 항목인지 바로 이해하기 어려웠고, 모바일 목록이 길어졌다.

## decision

- 저장 해석 본문과 계산 근거는 유지하고, 공용 리더가 올해 연애운 섹션 ID별로 쉬운 표시 제목을 사용하게 한다.
- 목록 제목은 질문·생활 장면 중심으로 쓰고 20자 이하로 제한한다.
- 한자·천간지지·도화·배우자성·관계궁·기운 같은 전문어는 목록에서 빼되 본문에서는 삭제하지 않는다.

## QA result

- 운영 실데이터의 섹션 ID 10개와 현재 제목을 브라우저에서 대조했다.
- 회귀 테스트를 기존 상태에서 먼저 실패시킨 뒤 구현 후 통과했다.
- 관련 테스트 14/14, TypeScript, JavaScript 구문 검사, diff 공백 검사 통과.
- 원문·회원별 계산값·이미지·표·그래프·토글 동작은 변경하지 않았다.

## lesson

해석 목록은 계산 근거를 모두 압축해 넣는 곳이 아니라 사용자가 읽을 순서를 고르는 내비게이션이다. 전문 근거는 본문에 남기고 목록은 질문 한 문장으로 정리해야 접근성이 좋아진다.
