# 메인 오늘운 무료 카드 키비주얼 상단 이동

## observation

- 운영 메인에서 `오늘 나한테 들어오는 운` 무료 카드는 대표 상품 캐러셀 아래에 있어 첫 화면의 무료 진입점으로 늦게 인지됐다.
- 카드 자체의 링크, 오늘 날짜 상태, 포인트 애니메이션, 금색·검정 스타일은 이미 정상 동작했다.

## decision

- 카드 마크업을 `phone-scroll`의 첫 항목으로 옮겨 `오늘운 카드 → 키비주얼 → 대표 상품 캐러셀` 순서로 만든다.
- 카드 기능과 문구는 바꾸지 않고, 새 위치에 맞게 여백만 상단 14px·하단 12px로 조정한다.
- CSS 캐시 키를 갱신해 이전 카드 위치의 여백이 남지 않게 한다.

## artifact

- `사주/portal.html`
- `사주/css/portal.css`
- `tests/unit/portal-newyear-coming-soon.test.ts`

## QA result

- 회귀 테스트를 먼저 추가해 기존 순서에서 실패한 뒤, DOM 이동 후 통과했다.
- 관련 포털 테스트 12/12 통과.
- 로컬 브라우저에서 첫 세 요소 순서, 카드 1개, `/today/free` 링크, 12px 간격, 가로 넘침 0px를 확인했다.
- 팝업·팝업 관리자·분석 이벤트·다른 서비스 카드는 변경하지 않았다.

## lesson

홈의 핵심 무료 CTA는 상품 캐러셀 이후에 강조하는 것보다 키비주얼 직전에 배치할 때 스크롤 이전에 발견된다. 기존 컴포넌트를 복제하지 않고 DOM 위치만 이동하면 오늘 상태와 분석 로직을 그대로 유지할 수 있다.
