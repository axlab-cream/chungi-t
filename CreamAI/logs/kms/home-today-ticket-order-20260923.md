# 메인 오늘운 무료 카드 키비주얼 상단 이동

## observation

- 운영 메인에서 `오늘 나한테 들어오는 운` 무료 카드는 대표 상품 캐러셀 아래에 있어 첫 화면의 무료 진입점으로 늦게 인지됐다.
- 카드 자체의 링크, 오늘 날짜 상태, 포인트 애니메이션, 금색·검정 스타일은 이미 정상 동작했다.

## decision

- 카드 마크업을 `phone-scroll`의 첫 항목으로 옮겨 `오늘운 카드 → 키비주얼 → 대표 상품 캐러셀` 순서로 만든다.
- 카드 기능과 문구는 바꾸지 않고, 새 위치에 맞게 여백만 상단 14px·하단 12px로 조정한다.
- CSS 캐시 키를 갱신해 이전 카드 위치의 여백이 남지 않게 한다.

## QA result

- DOM 순서와 단일 렌더링, `/today/free` 링크를 회귀 테스트로 고정했다.
- 팝업·팝업 관리자·분석 이벤트·다른 서비스 카드는 변경하지 않았다.
