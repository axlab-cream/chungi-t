# 일반 회원가입·로그인 진단 (2026-09-22)

## observation

- 일반 회원은 Google·Kakao·Naver 소셜 인증이며, 관리자 로그인과 분리되어 있다.
- 운영 인증 설정은 활성이고 세 공급자 진입점은 각 공급자 도메인으로 302를 반환했다.
- 기존 로그인 세션은 회원가입 진입 후 MY로 복귀하고 계정 화면을 읽었다.
- 익명 요청의 프로필·리포트·주문 API는 401로 차단되었다.

## decision

- 사용자 요청을 진단으로 해석해 계정·설정·코드 변경 없이 확인했다.
- 기존 사용자 세션을 로그아웃하지 않고 신규 가입과 재로그인은 미검증으로 남겼다.

## artifact

- `status.md`, `tests.md` 진단 기록

## QA result

- 인증·세션·로그인 관문·계정별 이력 집중 테스트 19/19 PASS.
- 운영 설정·공급자 리디렉션·익명 API 접근 차단 PASS.
- 신규 계정 생성 및 로그아웃 후 재로그인 E2E NOT_RUN.

## lesson

- 소셜 인증 공급자 설정과 기존 세션 복귀는 신규 가입 성공의 증거가 아니다. 전체 정상 판정에는 격리된 테스트 계정으로 가입·재로그인·프로필 저장·재조회가 필요하다.

## relation

- 2026-09-20 관리자 비밀번호 재설정 후 로그인 401 복구 기록은 별도 관리자 인증 흐름이다.
