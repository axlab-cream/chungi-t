# 이직운 저장 리포트 시각 계약 — 2026-09-23

## 관측

- 실제 저장 리포트에는 완료된 해석 10개와 개인별 오행·대운 계산값이 이미 존재했다.
- `work_move`가 `summary-only`에 남아 공용 렌더러가 모든 토글 이미지를 의도적으로 제거하고 있었다.
- 공용 리더 뒤에 구형 상세와 상담 입력이 함께 남아 저장 원문이 중복 노출될 수 있었다.

## 결정

- 운영 저장 원문과 회원별 계산값은 유지한다.
- 요약·하이라이트·10개 목차에 서비스 아이덴티티를 공유하는 실사형 단일 컷을 각각 연결한다.
- 계산값이 있는 표와 그래프만 표시한다. 성공 확률이나 임의 운세 점수는 추가하지 않는다.
- 저장 리포트가 채워진 경우에만 구형 상세와 상담 입력을 숨긴다.

## 재사용 규칙

1. 항목별 이미지가 필요한 서비스는 `sectionImageMode: summary-only`에서 제외한다.
2. `sectionImages` 순서는 서버 섹션의 `order`와 1:1로 고정한다.
3. 설정 JSON이 늦게 도착해도 `data-umsh-template-image`가 붙어 있으면 공용 갱신 함수가 구형 저장 이미지를 교체할 수 있다.
4. 좁은 화면은 본문 15px·1.9 행간, 요약 15px·1.55 행간, 이미지 3:2를 기본으로 검증한다.
5. 회원별 계산값이 없는 차트는 만들지 않는다.

## 검증 대상

- 이미지 파일 수·고유 경로·HTTP 200
- 저장 카드 수와 카드별 이미지 1장
- 시맨틱 표와 대운 그래프
- 펼치기/접기 상태 텍스트
- 페이지 마지막까지 스크롤
- 하단 구형 상세·상담 입력 숨김
