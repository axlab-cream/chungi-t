# 보관함 오늘운 출석 달력 계약 — 2026-09-23

## 관측

- 오늘운은 `serviceKey=today`이고 운세 기준일은 `context.concern`에 `YYYY-MM-DD`로 저장된다.
- 서버는 같은 회원·같은 날짜의 오늘운을 한 건으로 정리한다.
- 기존 보관함은 오늘운을 긴 카드 목록으로 모두 노출해 날짜별 이용 흐름을 한눈에 보기 어려웠다.

## 결정

1. 달력은 화면에서 날짜를 추측하지 않고 저장된 `initialConcern` 날짜만 출석 도장으로 표시한다.
2. 출석 날짜 링크는 서버가 내려준 `openPath`를 사용한다. 화면에 서비스별 상세 경로를 다시 적지 않는다.
3. 날짜가 없는 구형 행만 저장 시각의 로컬 날짜로 보완하며, 잘못된 값에는 도장을 만들지 않는다.
4. 오늘운 목록은 최신 5건으로 제한하고 구매한 운 목록은 자르지 않는다.
5. 한 달 31일이 다른 구매 리포트에 밀리지 않도록 `view=list` 경량 메타데이터를 최대 100건 받는다. 해석 본문은 목록 응답에 싣지 않는다.

## 재사용 검증

- 월 이동 뒤에도 저장된 날짜 맵을 다시 사용한다.
- 도장 날짜는 실제 저장 리포트 주소로 열린다.
- 오늘운 탭을 벗어나면 달력과 최근 목록 제목을 숨긴다.
- 삭제 후 같은 탭을 다시 렌더링해 달력 도장과 최근 5건을 함께 갱신한다.
- 모바일 7열 셀은 정사각형 비율, 키보드 초점, 날짜별 접근성 이름을 유지한다.
