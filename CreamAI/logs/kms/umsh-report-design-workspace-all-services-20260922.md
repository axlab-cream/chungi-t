# 서비스별 해석 디자인 작업실 — KMS 등록 대기

## 결정

- 운영 데이터와 분리된 정적 작업실에서 20개 서비스마다 티저·해석 목록·상세를 따로 검토한다.
- 실제 저장 해석을 확인한 서비스와 공개 설명만으로 만든 틀을 화면에서 구분한다.
- 무료 티저의 확인 여부는 유료 해석 본문의 확인 여부와 따로 관리한다.

## 오류·교훈

- 로그인 보관함에 유료 본문이 있어도 동일 서비스의 무료 티저가 자동으로 검증되는 것은 아니다.
- 상대 생년월일이 필수인 서비스에 본인 프로필을 복사하거나 임의의 실존 인물 정보를 넣으면 거짓 근거가 된다.
- 사용자별 리포트 ID·생년월일·회사명은 디자인 작업실에 복제하지 않는다.

## 검증

- 20개 서비스 × 3개 로컬 화면, 작업실 테스트 7/7, TypeScript 통과.
- 공개 유료 서비스 무료 티저 10종은 실제 입력 뒤 화면을 확인하고 쉬운 말로 재작성했다. 상대 정보 필수 3종은 가상 상대를 넣었으므로 관계 해석이 아니라 화면 구조만 검증했다.
- 운영 천명사주·직장 선택 무료 화면에는 한자·전문용어가 남아 있어 프롬프트 생성물 외에 정적 티저 문구도 별도 수정해야 한다.
- 운영 연락 신호 무료 화면에도 한자·전문용어가 다량 남았다. 커플궁합은 입력 직후 `이전 입력을 찾지 못했습니다`를 보여 주므로 세션 전달을 별도 점검해야 한다.
- 운영 API·인증·결제·저장소와 무연결이며 커밋·배포하지 않았다.

CreamWIKI 로컬 터널 연결이 거부되어 서버 저장·재조회는 보류한다.
