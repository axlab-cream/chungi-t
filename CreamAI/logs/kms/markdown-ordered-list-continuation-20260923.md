# 공용 마크다운 번호 목록 연속 표시

## 증상

저장 해석에서 `1. 항목` 다음에 설명 문단이 있고 다시 `1. 항목`이 이어지면 화면에서도 모든 항목이 1로 보였다.

## 원인

빈 줄 기준으로 나눈 각 문단을 `richText()`가 독립 `<ol>`로 만들었고, 각 목록에 시작 번호가 없어서 브라우저가 매번 1부터 표시했다.

## 결정

- 저장 원문은 수정하지 않는다.
- 같은 요약·하이라이트·해석 블록 안에서만 번호 상태를 공유한다.
- 두 번째 분리 목록부터 `<ol start="N">`을 사용한다.
- 서로 다른 해석 블록은 독립 목록으로 보고 다시 1부터 시작한다.

## 검증

- 설명 문단 사이에 분리된 목록이 1, 2, 3으로 이어지는 회귀 테스트 추가.
- 요약·하이라이트·토글 본문이 공용 목록 렌더러를 쓰는지 정적 검사.
- 공용 스크립트 버전을 상세 리포트 전체에서 동일하게 유지하는 기존 계약 검사 통과.

## 재사용 규칙

마크다운 문단을 먼저 분리한 뒤 렌더링하는 구조에서는 번호 목록 상태를 문단 함수 내부가 아니라 의미상 하나인 상위 해석 블록에서 관리한다.
