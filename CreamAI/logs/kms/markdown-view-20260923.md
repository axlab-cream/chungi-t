# 운명상회 공용 마크다운 뷰 가독성 보강

## 문제

삽입형 저장 리포트에서 첫 토글의 읽기 순서가 시맨틱 `table`이었지만, 전체화면 리더에만 스타일이 있어 모바일 운영 화면에서는 일반 텍스트처럼 보였다. 저장 원문의 표·목록·강조 문법도 동적 최소 스타일에 의존해 서비스별 포인트 색상과 읽기 위계가 약했다.

## 결정

- 저장 원문과 계산값은 유지하고 공용 렌더러·공용 CSS만 보강한다.
- 읽기 순서, 마크다운 표, 오행 계산값은 실제 `table`을 사용한다.
- 표 헤더에는 `scope="col"`, 가로 스크롤 래퍼에는 `role="region"`, `aria-label`, `tabindex="0"`을 둔다.
- 굵게·기울임·밑줄·형광·코드·소제목·인용·목록은 서비스 accent 변수를 사용한다.
- 그래프는 실제 계산 데이터가 있을 때만 렌더하며 성공·수입 같은 예측 점수를 만들지 않는다.

## 검증

- 집중 테스트 23/23
- 전체 단위 테스트 1,540/1,540
- TypeScript, 고양이 서비스 계약, 서비스 QA 20/20, Vercel build 통과
- 운영 고양이 궁합 화면에서 읽기 순서 표의 헤더·행 경계·연두 accent, 오행 5열 표, 대운 SVG, 토글 접기/펼치기, 카드 20개·이미지 20개를 확인했다.
- 운영 브라우저 콘솔 경고·오류 0건. Vercel 요청은 HTTP 200이며 Node deprecation 경고 1건이 로그에 남았으나 사용자 요청 실패는 아니다.

## 재사용 규칙

새 리포트 UI는 별도 표 스타일을 만들지 말고 `umsh-verified-inplace.css`의 `.umsh-reading-guide`, `.reading-table`, `.reading-list`, `.reading-subhead`, `.reading-quote`, `.story-table`, `.story-chart` 계약을 재사용한다.
