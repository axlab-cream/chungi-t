# UI·UX 배포 실행 규칙 조정 (2026-09-22)

- observation: 프로젝트 실행 정책의 H1/H2가 사용자 요청을 받은 일반 원격 push와 기존 운영 배포까지 차단해, 검증된 UI·UX 수정이 운영에 반영되지 않았다.
- decision: 사용자가 특정 서비스 UI·UX의 커밋·배포를 명시적으로 요청한 경우에 한해 검증된 범위의 일반 push와 기존 배포 경로를 허용한다. 범위 밖 변경과 force push, 브랜치 삭제, PR 머지, 인프라 변경, DB 마이그레이션, 시크릿 전송, 비가역적 삭제는 계속 차단한다.
- artifact: `rules.md` §6.3, local commit `12971e3`.
- verification: 정책 diff 검토 및 `git diff --check` 통과. 운영 push·배포는 이번 정책 수정 단계에서 실행하지 않았다.
- lesson: 릴리스 게이트는 사용자의 명시적 범위와 위험 수준을 구분하고, 배포 후 실제 화면 확인을 완료 기준에 포함해야 한다.
