# 이직운 중복 전체 목록 버튼 제거

## 관측

이직운 06-1 화면은 공용 리더가 전체 해석 목록을 이미 표시하지만, 구형 상세 마크업의 `전체 목록으로 돌아가기` 링크가 하단에 남아 있었다.

## 결정

- 현재 화면과 같은 정보 구조로 되돌리는 중복 링크는 제거한다.
- 사용되지 않게 된 `.list-link` CSS도 함께 제거한다.
- 공용 `링크 공유하기`와 `PDF 저장`은 리포트 도구이므로 유지한다.

## 검증

- 이직운 상세 HTML에 `전체 목록으로 돌아가기`가 없다는 회귀 테스트를 추가했다.
- 공용 리포트 템플릿 집중 테스트 18/18과 TypeScript 검사를 통과했다.

## 재사용 규칙

전체 목록을 인라인으로 제공하는 상세 리더에서는 같은 목록 화면으로 이동하는 별도 복귀 CTA를 노출하지 않는다.
