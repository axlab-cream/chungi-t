# KMS note — corpus-bound long-outline evidence

- A provider result proves only the corpus snapshot stored with that result; never relabel an older completed report as evidence for a newer corpus.
- Pin path, version, full SHA-256 and short content hash before provider use, then replay accepted prose with that stored snapshot.
- For long sequential generation, immutable attempts plus first-unresolved-failure stopping prevent later successful items from hiding an earlier gap.
- Natural Korean action, scene and grounding variants require bounded regression fixtures. Preserve negative safety fixtures whenever widening recognition.
- Independently read the whole accepted outline because automated gates cannot judge cross-section usefulness and editorial repetition alone.
- Release evidence should contain hashes and aggregates only, with explicit no-provider-prose, no-secret and no-personal-data flags.
