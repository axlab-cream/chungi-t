# 운명상회 전체 서비스 티저 신뢰 게이트 — 2026-09-14

## 문제

유료 서비스의 중간 티저가 리포트 첫 문단만 사용해 실제 생성 결과에 생활 장면이 있어도 추상적인 문장만 보여 주었다. 빈 `signals`가 존재하면 유효한 `insights`도 화면에서 사라졌고, 일반적인 직무의 결정 권한이나 소비 계획을 인증·결제 운영 문구로 잘못 분류할 여지도 있었다.

## 결정

- 19개 유료 서비스만 같은 신뢰 게이트로 평가한다. 무료 완성 결과인 오늘운에는 가짜 유료 티저를 만들지 않는다.
- 결론 1개, 대표 근거 1~2개, 생활 장면 1개, 전체 해석의 정확한 항목 범위를 요구한다.
- 장면은 새 문장을 발명하지 않고 현재 리포트 앞 6개 항목에서 이미 작성된 문단을 가져온다.
- 로그인·결제 상태와 접근 권한만 차단하고, 직무 결정 권한·실생활 구매 판단은 허용한다.
- 티저 UI는 결론 → 대표 근거 → 전체 범위 → 비압박 CTA 순으로 표시한다.

## 검증 결과

- RED 8/19 → GREEN 19/19.
- 집중 테스트 75/75, 회귀 34/34, TypeScript, Vercel Production build, 20개 persona/prompt/corpus 계약 검사 PASS.
- 실제 공통 리더의 데스크톱 및 390px 모바일 시각 검수 PASS. 모바일 가로 넘침 0, CTA 높이 53.75px.
- 결제, 고객 레코드, 운영 DB는 사용하거나 변경하지 않았다.

## 재사용 교훈

티저 품질은 글자 수가 아니라 `판단 + 근거 + 장면 + 다음 범위`의 증거 구조로 검수해야 한다. 배열 필드가 존재한다는 이유만으로 빈 배열을 우선하지 말고, 의미 있는 대체 필드를 확인한다. 운영 문구 필터는 일반 도메인 문장까지 막지 않도록 `결제`나 `권한` 단어 자체가 아니라 상태·접근 맥락을 검사한다.

## 남은 경계

이 슬라이스의 PASS는 전체 Tone V2 릴리스 GO가 아니다. 전체 서비스의 provider 출력, 전체 목차 독립 검수, 시각 증거가 완성될 때까지 종합 판정은 `NO_GO`다.
