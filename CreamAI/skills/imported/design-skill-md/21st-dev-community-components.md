# 21st.dev Community Components

## Purpose

웹 디자인과 프론트엔드 구현 중 참고할 수 있는 커뮤니티 UI 컴포넌트 카탈로그다.

## Use As

- 컴포넌트 패턴 참고
- 마케팅 블록 구조 참고
- 인터랙션 아이디어 참고
- 상태별 UI 구성 참고
- 디자인 시스템 컴포넌트 후보 탐색

## Observed Categories

페이지에서 확인한 주요 분류:

- Marketing Blocks: announcements, backgrounds, calls to action, features, footers, heroes, navigation menus, pricing sections, testimonials, texts, videos
- UI Components: accordions, AI chats, alerts, avatars, badges, buttons, calendars, cards, dialogs/modals, dropdowns, forms, inputs, menus, popovers, selects, sidebars, sliders, tables, tabs, text areas, toggles, tooltips

## CreamAI Rule

21st.dev는 필수 디자인 스킬 자체가 아니라 지원 사용도구다. 작업 시 그대로 복사하지 말고 다음을 기준으로 변형한다.

- 프로젝트의 `design-system/MASTER.md`
- 접근성 기준
- 반응형 요구사항
- 브랜드/도메인 특성
- 기존 컴포넌트 구조
- 라이선스와 출처 확인
