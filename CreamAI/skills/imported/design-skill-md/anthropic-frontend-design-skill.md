# Anthropic Frontend Design Skill

## Purpose

웹/프론트엔드 UI를 만들거나 리디자인할 때, 템플릿처럼 보이는 기본값을 피하고 주제·대상·브랜드에 맞는 의도적인 시각 방향을 만들기 위한 필수 스킬이다.

## Required Use

다음 작업에는 반드시 참조한다.

- 랜딩 페이지
- 웹 앱 첫 화면
- 대시보드
- 앱 화면
- 리디자인
- 디자인 시스템 정리
- 시각 QA

## Core Operating Rules

- 실제 제품/서비스의 subject, audience, single job을 먼저 고정한다.
- 색상, 타이포그래피, 레이아웃, 시그니처 요소를 코드 작성 전에 계획한다.
- 흔한 AI 기본 스타일을 자동으로 선택하지 않는다.
- 과감한 요소는 하나에 집중하고 나머지는 절제한다.
- 카피도 디자인 재료로 다루며, 사용자가 이해하고 행동하기 쉽게 쓴다.
- 모바일, 키보드 포커스, reduced motion, 텍스트 맞춤을 검증한다.
