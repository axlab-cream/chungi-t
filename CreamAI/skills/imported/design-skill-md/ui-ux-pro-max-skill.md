# UI UX Pro Max Skill

## Purpose

제품 유형과 산업 맥락에 맞는 UI 패턴, 스타일, 컬러, 타이포그래피, UX 체크리스트를 생성하고 검증하기 위한 디자인 지능 스킬이다.

## Source Summary

저장소 `skill.json` 기준:

- name: `ui-ux-pro-max`
- version: `2.5.0`
- license: `MIT`
- supported platforms include Claude, Codex, Gemini, Antigravity, Cursor, Windsurf, Copilot, and more.
- install pattern: `npx uipro-cli init --ai {{platform}}`

README 기준 핵심 기능:

- UI styles
- color palettes
- font pairings
- UX guidelines
- chart types
- stack-specific guidance
- design-system generation

## Required Use

다음 작업에는 반드시 참조한다.

- UI/UX 구현
- 디자인 시스템 생성
- 랜딩 페이지
- SaaS/CRM/운영 대시보드
- 모바일 앱 UI
- 접근성/반응형 QA

## Local CreamAI Usage

SETUP된 프로젝트에서는 다음 파일을 읽는다.

- `.claude/skills/ui-ux-pro-max/SKILL.md`
- `CreamAI/workflows/web-design-skills.md`

전체 설치가 필요하면 프로젝트 루트에서 실행한다.

```bash
npx uipro-cli init --ai claude
npx uipro-cli init --ai codex
npx uipro-cli init --ai all
```
