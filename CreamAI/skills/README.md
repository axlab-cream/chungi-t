# Project Skills

Keep project-local skill notes here when a workflow needs repeatable instructions.

Global Codex or Claude skills should remain in their normal user-level locations unless this project requires a local copy.

Local project skill notes:

- `default-cream-cli-skills.md`: default CreamAI/Cream CLI skill router.
- `skill-*.md`: CreamAI skill-pipeline wrappers for `.claude/skills/*/SKILL.md`.
- `imported/`: source snapshots and import manifest for desktop skill folders.
- `comfyui-mcp.md`: Comfy Cloud/ComfyUI MCP usage, Cloud vs Local selection,
  and synthetic dataset prompt contracts.
