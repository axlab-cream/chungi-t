# 20개 서비스 공통 해석 템플릿 보강

## 결과

- 19개 유료 장문 해석 서비스는 같은 공용 리더에서 대표 이미지, 확장형 토글, 읽기 안내 표, 저장 원문, 실제 만세력 흐름을 같은 순서로 표시한다.
- 대표 이미지는 각 서비스의 메인 카드 썸네일을 그대로 사용한다. 이후 기본 토글은 해당 서비스의 공개 `cutA`/`cutB` 장면을 교차 사용하며, 저장 리포트가 항목별 이미지를 가진 경우 그 이미지를 우선한다.
- 19개 서비스의 대표 썸네일·A/B 장면 57개 경로가 실제 공개 자산으로 존재함을 검사했다. 빈 기본 이미지 자리는 남기지 않는다.
- 첫 토글에는 한 번만 서비스별 읽기 안내 표를 넣었다. 표의 문구는 서비스별 주제·말투를 유지하며 개인 조건이나 예측 수치를 만들지 않는다.
- 만세력 흐름 그래프는 저장 리포트에 `analysis.fortune.daewoon`이 있을 때만 표시한다. 그래프는 결과·성공·수입 점수가 아니라 "힘을 쓰기 쉬움 / 기준을 정리 / 속도 조절"의 해석 기준이다.
- 이후 새로 생성되는 하이라이트는 최소 6/6/5문단 계약을 사용한다. 저장된 원문은 클라이언트에서 줄이거나 다시 작성하지 않는다.

## 보존 범위

- 팝업 관리자·팝업, 결제, DB schema/migration, 회원 입력 데이터는 변경하지 않았다.
- 오늘운은 장문 해석 토글 서비스가 아닌 일일 결과 화면이므로, 그 화면 구조에는 장문 템플릿을 강제로 주입하지 않았다.

## 검증

- 집중 단위 테스트 23/23 통과: 공용 이미지/표/실제 그래프, 원문 유지, 토글 상태, 19개 서비스의 57개 이미지 경로.
- `npm test`, `npm run typecheck`, `npm run qa:all-services`, `npm run vercel-build`, `git diff --check` 통과.
- 로컬 브라우저에서 올해 연애운 검수 payload로 메인 썸네일, 첫 토글의 안내 표, 원문, 대운 그래프, 삼재·원자료 펼침 상태를 확인했다.
