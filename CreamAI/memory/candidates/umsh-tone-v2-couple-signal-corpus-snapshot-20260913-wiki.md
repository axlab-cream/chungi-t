# 운명상회 연애 신호 코퍼스 스냅샷 원칙

관계에 관한 현실 사실은 사용자가 확인한 행동, 직접 들은 말, 명시적 합의와 확정 일정으로 한정한다. 연락량, 표현 방식, 타인의 관심과 서버가 계산한 명식 값은 상대의 마음·의도·애정·외도 여부·관계 미래를 증명하지 않는다. 계산값은 상징적 질문으로 표시하고 입력되지 않은 사적 상태는 알 수 없음으로 둔다.

모든 예시는 가상 사례로 표시한다. 임의의 기간·횟수나 대화 결과를 만들지 않으며 감시, 위치 추적, 계정·기기·기록의 무단 접근을 확인 방법으로 제안하지 않는다. 연락 거부와 대화 거절을 존중하고, 위협·강요·폭력·스토킹이 있으면 재접촉이나 공동 대화보다 안전 확보와 지역의 긴급·전문 지원을 우선한다.

코퍼스 교체 시 기존 파일과 고객 결과를 덮어쓰지 않는다. 신규 결과만 새 버전을 사용하고 저장된 결과의 검색·프롬프트·재검수는 당시 스냅샷과 콘텐츠 해시를 따른다. 해시 불일치는 실패로 닫고 롤백은 레지스트리 포인터만 되돌린다.
