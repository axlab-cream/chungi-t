# 운명상회 집 풍수 코퍼스의 측정 경계와 스냅샷 격리

집 풍수 콘텐츠에서는 사용자가 직접 관찰한 사실, 서버가 제공한 측정값, 측정되지 않은 항목, 풍수·오행 상징을 서로 다른 증거 층으로 유지한다. 미측정 항목은 `알 수 없음`이며 비슷한 장소의 패턴이나 상징 해석으로 채우지 않는다.

상징 해석은 질문과 점검 순서를 제안할 수 있지만 구조 안전, 사고, 건강, 수면 회복, 생산성, 재물, 관계, 부동산 가치 또는 계약 결과의 근거가 될 수 없다. 실제 결정에는 현장 점검, 계측, 계약 자료와 적절한 전문가 판단이 우선한다. 예시는 반드시 `가상 사례:`로 표시한다.

코퍼스 스냅샷 격리는 일반 RAG 검색기만 검사해서는 부족하다. 별도 도메인 helper가 코퍼스 인덱스를 직접 만들면 저장된 과거 리포트가 최신 코퍼스로 재해석될 수 있다. 생성 프롬프트, 저장 원고 재검수, 전용 helper를 포함한 모든 소비자가 저장된 `CorpusSnapshot`을 전달받아야 하며 해시 불일치는 fail-closed로 처리한다.

검증 근거: home_fit 12/12 의미 검수, focused 8/8, related 107/107, full 807/807, typecheck/build PASS. 공급자 출력과 Production은 실행하지 않았다.
