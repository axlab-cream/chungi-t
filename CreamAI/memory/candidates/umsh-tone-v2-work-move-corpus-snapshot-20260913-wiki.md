# 운명상회 이직운 코퍼스의 문서 근거와 스냅샷 격리

이직 판단에서는 사용자가 확인한 현재 업무 사실, 실제 오퍼·근로계약 문서, 사용자가 보고한 구두 약속, 확인되지 않은 회사 조건, 서버 계산값과 상징 해석을 분리한다. 구두 약속은 보고된 발언이지 서면 조건이나 지급 보장이 아니다. 새 회사 문화·기밀·조직 변화, 상사·동료 의도와 채용 결과는 확인 전까지 알 수 없음이다.

일간·오행·십신·대운·세운은 비교 질문을 만들 수 있지만 직업 적합도, 합격, 연봉, 퇴사·입사 날짜의 성패를 증명하지 않는다. 건강·괴롭힘·근로조건·계약·세금·재무 문제는 실제 기록과 의료·노무·법률·재무 지원을 우선한다. 사례는 `가상 사례:`로 표시하고 입력되지 않은 기간·횟수를 만들지 않는다.

코퍼스 전환은 신규 리포트만 새 버전을 사용한다. 저장된 리포트의 검색, 생성 프롬프트와 재검수는 저장 당시 `CorpusSnapshot`과 해시를 사용하고 불일치는 fail-closed로 처리한다. 롤백은 registry만 이전 파일로 되돌리며 고객 레코드를 다시 쓰지 않는다.

검증 근거: work_move 10/10 의미 검수, focused 8/8, related 153/153, full 815/815, typecheck/build PASS. 공급자 출력과 Production은 실행하지 않았다.
