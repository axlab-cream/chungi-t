# 운명상회 Tone v2 신년운세 코퍼스 스냅샷 전환

## 재사용 지식

시간 흐름 코퍼스는 서버 계산값, 상징 해석, 확인된 사용자 사실, 알 수 없는 미래, 가상 사례를 분리해야 한다. 연도·입춘·세운·월운·대운 계산은 미래 사건이나 사람의 상태를 증명하지 않으며, 제목과 검색 주제에도 예언형 문장을 남기면 안 된다.

## 검증된 패턴

1. 기존 2.0.0을 보존해 저장 리포트와 롤백 근거로 둔다.
2. 열 개 블록과 검색 주제를 개별 검수해 새 2.1.0 파일로 발행한다.
3. 새 리포트는 활성 버전을, 기존 리포트는 저장된 버전과 SHA-256을 사용한다.
4. 해시가 다르면 최신 코퍼스로 자동 대체하지 않고 실패 폐쇄한다.
5. 가상 사례를 라벨링하고 미래 사건·성과·감정·건강·재정 상태와 임의 기간·횟수를 만들지 않는다.
6. 릴리스 후보에는 provider 호출, 배포, 고객 레코드 변경 여부를 사실대로 기록한다.

- 의미 검수 10/10 PASS
- 집중 테스트 8/8 PASS
- 관련 테스트 218/218 PASS

## 제한

이 기록은 코퍼스의 의미 경계와 버전 고정 구조를 검증한 것이다. 미래 예측 정확도나 실제 모델 출력 품질을 증명하지 않는다. 원격 CreamWIKI 등록은 인증된 CLI 세션에서 별도로 수행하고 재조회해야 한다.
