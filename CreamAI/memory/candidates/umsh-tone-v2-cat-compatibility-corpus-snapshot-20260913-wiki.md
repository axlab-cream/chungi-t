# 운명상회 고양이 궁합 코퍼스 스냅샷 원칙

고양이에 관한 사실은 사용자가 입력하거나 실제로 관찰한 가정 형태, 나이대, 행동, 접촉·놀이 반응, 생활 루틴, 일정과 메모로 한정한다. 보호자의 사주 계산과 오행은 별도의 상징 질문이며 고양이의 출생 명식, 성격, 마음, 질병, 미래 행동, 적응 속도나 궁합 결과를 증명하지 않는다.

가상 장면은 반드시 가상 사례로 표시한다. 임의의 일수·횟수·성공 보장을 만들지 않고, 근거가 있는 환경 기준도 현재 가정이 1묘인지 다묘인지와 실제 자원 배치를 확인한 뒤 적용한다. 갑작스러운 식사·배변·통증·호흡·활동 변화는 운세와 분리해 수의사에게 확인하며, 학대·방치·처벌·강제 접촉은 어떤 상징으로도 정당화하지 않는다.

코퍼스 교체 시 기존 파일과 고객 결과를 덮어쓰지 않는다. 신규 결과만 새 버전을 사용하고, 저장된 결과의 검색·프롬프트·재검수는 당시 스냅샷과 콘텐츠 해시를 따른다. 해시 불일치는 실패로 닫고 롤백은 레지스트리 포인터만 되돌린다.
