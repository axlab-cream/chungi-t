# 운명상회 Tone v2 결혼 택일 코퍼스 스냅샷 전환

## 재사용 지식

택일 코퍼스는 사용자가 제시한 후보일, 서버 계산, 확인된 일정·계약 조건, 알 수 없는 미래, 가상 사례를 분리해야 한다. 상대 정보나 출생 시각이 없으면 관련 명식 판단을 보류하고, 가족 감정·예식장 상태·당일 컨디션·결혼 이후 결과를 날짜 계산으로 만들면 안 된다.

## 검증된 패턴

1. 기존 2.0.0을 보존해 저장 리포트와 롤백 근거로 둔다.
2. 여섯 블록을 개별 검수해 새 2.1.0 파일로 발행한다.
3. 새 리포트는 활성 버전을, 기존 리포트는 저장된 버전과 SHA-256을 사용한다.
4. 해시가 다르면 최신 코퍼스로 자동 대체하지 않고 실패 폐쇄한다.
5. 가상 사례를 라벨링하고 상대 개인정보·시각 미상·계약·재무·의료·안전 경계를 명시한다.
6. 부정문이어도 고객 본문 금지 용어가 RAG에 들어갈 수 있으므로 실제 소비자 문장 회귀를 함께 실행한다.

## 제한

이 기록은 코퍼스 의미 경계와 버전 고정 구조를 검증한 것이다. 길한 날짜의 정확도나 실제 모델 출력 품질을 증명하지 않는다. 원격 CreamWIKI 등록은 인증된 CLI 세션에서 별도로 수행하고 재조회해야 한다.
