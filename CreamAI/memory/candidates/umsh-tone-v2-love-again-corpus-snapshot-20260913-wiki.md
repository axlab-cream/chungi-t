# 운명상회 재회운 코퍼스 동의·거절·안전 경계와 스냅샷 전환

## 문제

재회운 코퍼스의 기존 자동 이관 문구와 라벨 없는 사례는 과거 연락·이별이라는 확인 사건을 상대의 그리움, 재회 의향, 향후 연락과 같은 미확인 상태로 확장할 위험이 있었다.

## 검증된 해결 패턴

1. 사실은 사용자가 확인한 이별 원인, 실제 연락, 상대의 직접 표현, 관찰 가능한 행동 변화와 현재 경계로 제한한다.
2. 연락 사실은 연락 사실일 뿐 그리움·동의·재회 의향의 증거로 사용하지 않는다.
3. 명시적 거절과 연락 중단 요청은 상징 해석보다 우선한다.
4. 위협·강압·스토킹·폭력이 있으면 재회 해석을 중단하고 안전 확보와 지원 경로를 우선한다.
5. 모든 가상 사례는 `가상 사례:`로 표시하고 연락 날짜, 대기 기간, 횟수, 재회 결과를 임의로 예측하지 않는다.
6. 신규 리포트만 검수된 2.1.0을 사용한다. 저장 리포트는 자신이 보관한 경로·버전·해시로 검색, 프롬프트 생성, 재검수를 수행한다.
7. 저장 해시가 다르면 최신 코퍼스로 조용히 대체하지 않고 닫힌 상태로 실패한다.

## 적용 범위

상대의 감정, 연락 의향, 재결합 가능성을 다루는 관계형 코퍼스의 신규 버전 전환에 재사용한다. 거절·강압·스토킹·폭력을 낭만적 신호로 바꾸는 용도로 사용하지 않는다.
