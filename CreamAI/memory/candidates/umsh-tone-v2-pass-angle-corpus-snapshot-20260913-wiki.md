# 운명상회 붙을 각 코퍼스의 시험 근거와 기존 결과 보존

시험 해석의 현실 근거는 사용자가 확인한 시험 종류·날짜, 시험 주관 기관의 공식 안내, 실제 학습·오답·답안·면접·실기 기록이다. 서버가 계산한 인성·식상·관성·비겁·일간 강약·대운·세운은 별도의 상징적 질문이며 지능, 학습 능력, 성실성, 체력, 적성, 점수나 합격 가능성을 증명하지 않는다.

기간과 횟수는 사용자 입력, 공식 일정 또는 그 날짜에서 계산된 산술값이 있을 때만 쓴다. 고정 학습 주기나 D-day 단계, 당일 루틴을 임의로 만들지 않는다. 집중 저하·불안·소진·수면·건강 문제는 사용자 보고로만 설명하고 지속되거나 심하면 의료 지원을 우선한다.

새 코퍼스 이전에 생성된 완료 결과는 새 코퍼스의 공급자 평가 증거가 아니다. 기존 결과는 저장 당시 코퍼스 스냅샷과 ID를 유지하고, 신규 결과만 새 버전을 사용한다. 검색·생성 프롬프트·저장 원고 재검수는 저장된 해시를 따라야 하며 불일치는 fail-closed로 처리한다.

검증 근거: pass_angle 8/8 의미 검수, focused 8/8, related 143/143, full 823/823, 타입 검사·빌드 PASS. 기존 52개 결과는 변경하지 않았고 2.1.0 공급자 출력과 Production은 실행하지 않았다.
