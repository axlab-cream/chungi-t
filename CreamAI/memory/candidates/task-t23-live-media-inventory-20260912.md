# T23 Slice 1 — 실제 배포 미디어 인벤토리

## 문제

관리자 미디어 메뉴가 실데이터 없이 준비 안내만 표시했고, 어떤 파일이 실제 배포되며 어디에서 사용되는지 확인할 근거가 없었다.

## 적용 패턴

- 배포 빌드가 공개 허용 루트만 스캔해 결정적 JSON 인벤토리를 생성한다.
- 확장자만 신뢰하지 않고 파일 시그니처를 검사하며 SHA-256, 크기, 해상도와 MP4 재생시간을 함께 기록한다.
- 소스의 파일명 직접 참조를 찾아 사용 위치를 보수적으로 표시한다. 참조가 없다는 결과는 미사용 확정이 아니라 `확인된 직접 참조 없음`이다.
- 서버는 별도 read scope 뒤에서 검증된 DTO만 반환하고 내부 파일 경로는 노출하지 않는다.
- 권리 증빙이 없으면 전부 `unverified`, poster 연결이 없으면 전부 미연결로 표시한다. 추정 승인은 금지한다.
- 넓은 운영 표는 동적 grid child에 `min-width: 0`을 주고 표에 명시적 최소 폭을 주어 페이지가 아니라 컨테이너만 스크롤하게 한다.

## 발견한 실패와 예방 규칙

자체 관리자 쿠키 권한 배열과 직원 membership 권한 배열이 분리되어 있어 새 scope가 한쪽에만 추가됐다. API bearer 테스트만으로는 발견하지 못했다. 새 관리자 scope를 추가할 때는 두 인증 경로 모두로 해당 API를 호출하는 테스트를 둔다.
