# 운명상회 Tone v2 행운색 코퍼스 스냅샷 전환

## 재사용 지식

상징 기반 색상 추천 코퍼스는 계산값, 상징, 확인된 사용자 사실, 알 수 없는 현실, 가상 사례를 명시적으로 분리해야 한다. 색·물건·재료·방향·음식·생활 루틴은 효능이나 결과를 증명하지 않으며, 사용자가 제공하지 않은 공간·복장·소유물·식사·수면·반응·일정을 사실처럼 만들면 안 된다.

## 검증된 패턴

1. 기존 2.0.0을 그대로 보존해 저장 리포트와 롤백의 근거로 둔다.
2. 24개 블록을 개별 검수하고 새 2.1.0 파일로 발행한다.
3. 새 리포트는 활성 버전을, 기존 리포트는 저장된 버전과 SHA-256을 사용한다.
4. 해시가 다르면 자동으로 최신 코퍼스로 대체하지 않고 실패 폐쇄한다.
5. 가상 사례를 라벨링하고, 효능·건강·수면·집중·기분·재정·결과 단정을 금지한다.
6. 릴리스 후보에는 provider 호출, 배포, 고객 레코드 변경 여부를 사실대로 기록한다.

## 검증 증거

- 의미 검수 24/24 PASS
- 집중 테스트 8/8 PASS
- 관련 테스트 147/147 PASS
- 전체 테스트 847/847 PASS
- 타입 검사 및 Vercel 빌드 PASS
- 후보 SHA-256: `ad21c843643ed77301d15fe1e48c544fa0e86f89a40cc8de5ab0774d245b51f6`

## 제한

이 기록은 코퍼스의 의미 경계와 버전 고정 구조를 검증한 것이다. 색상의 물리적·의학적·심리적 효능이나 실제 모델 출력 품질을 증명하지 않는다. 원격 CreamWIKI 등록은 인증된 CLI 세션에서 별도로 수행하고 재조회해야 한다.
