# 운명상회 배우자운 코퍼스 미래 인물·자율성·안전 경계와 스냅샷 전환

## 문제

배우자운 코퍼스의 자동 이관 문구와 라벨 없는 생활 사례는 사용자가 원하는 관계 조건과 미래 배우자의 신원·속성·등장 시점을 혼동하게 만들 위험이 있었다.

## 검증된 해결 패턴

1. 사실은 사용자가 직접 밝힌 동반자 조건, 선호와 현재 관계에서 관찰한 행동으로 제한한다.
2. 배우자궁과 계산값은 특정 인물을 확인하는 정보가 아니라 관계 조건을 점검하는 상징적 질문으로만 사용한다.
3. 이름·나이·외모·직업·국적·거주지와 등장·만남·결혼 시점, 상대 감정과 관계 결과를 예측하지 않는다.
4. 돈·집안일·책임을 성별 역할로 정하지 않고 합의와 관찰 가능한 행동 변화를 기준으로 둔다.
5. 거절·강압·통제·스토킹·폭력은 강한 인연으로 미화하지 않고 경계와 안전, 적절한 지원을 우선한다.
6. 모든 가상 사례는 `가상 사례:`로 표시하며 임의 수치·기간·확률을 만들지 않는다.
7. 신규 리포트만 검수된 2.1.0을 사용하고 저장 리포트는 자신의 경로·버전·해시로 검색, 프롬프트 생성, 재검수를 수행한다. 해시 불일치는 닫힌 상태로 실패한다.

## 증거

- 의미 검수 1/1 PASS
- 집중 테스트 8/8, 관련 테스트 88/88, 전체 테스트 799/799 (111 suites) PASS
- 타입 검사, Vercel 빌드, 결정적 재생성, 종료 리뷰 PASS
- 후보 코퍼스 SHA-256: `4184031e0d22badd49fe17e0825bd74077be90e982424053f77ff0d481db802a`

## 적용 범위

미래의 사람, 배우자 속성, 만남 시점 또는 관계 결과를 다루는 코퍼스의 신규 버전 전환에 재사용한다. 특정 인물 식별, 성별 역할 처방 또는 위험 신호의 낭만화에는 사용하지 않는다.
