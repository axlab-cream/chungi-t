# 관리자 LNB 계층·접기 패턴

## 재사용 결론

- 운영 도구 LNB는 카테고리 헤더와 링크를 같은 시각 무게로 두지 않는다. 카테고리에는 굵은 버튼형 헤더와 구분선을, 하위 메뉴에는 한 단계 들여쓰기와 작은 원형 블릿을 사용하면 밀도를 유지하면서 계층이 즉시 보인다.
- 접기·펼치기는 네이티브 `button`, `aria-expanded`, `aria-controls`, 연결된 패널의 `hidden`을 한 함수에서 동기화한다. 화살표는 텍스트나 이모지 대신 CSS 선으로 만들고 `prefers-reduced-motion`에서 전환을 제거한다.
- 접힘 상태를 세션에 저장하더라도 현재 경로가 속한 그룹은 라우트 표시 단계에서 강제로 펼친다. 그렇지 않으면 활성 메뉴가 숨겨져 사용자가 현재 위치를 잃는다.
- 데스크톱의 세로 LNB와 모바일의 수평 LNB는 같은 접기 규칙을 억지로 공유하지 않는다. 좁은 화면에서는 카테고리 헤더를 숨기고 링크를 평탄화해 모든 목적지에 계속 접근할 수 있게 한다.

## 검증 근거

- 관리자 셸 회귀 테스트에서 그룹·토글·ARIA·블릿·들여쓰기·세션 저장·활성 그룹 펼침 계약을 확인했다.
- Production 브라우저에서 카테고리 접기, 새로고침 후 상태 유지, 현재 메뉴 그룹 자동 펼침, 콘솔 오류 0건을 확인했다.
- 인증·실데이터 API·관리자 계정 정보는 이 패턴에서 변경하거나 저장하지 않는다.
