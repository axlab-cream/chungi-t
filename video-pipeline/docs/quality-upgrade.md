# 품질 고도화 기준

이 문서는 힉스필드에서 안정적으로 보였던 완성도 기준을, 크레딧을 쓰지 않는 ComfyUI/오픈소스 제작 흐름에 적용하기 위한 내부 기준입니다.

## 목표

- 웹툰, 일러스트, 그림체 느낌을 줄이고 실제 사람 영상처럼 보이게 한다.
- 같은 얼굴, 같은 나이대, 같은 체형, 자연스러운 손을 유지한다.
- 모든 컷을 옆모습이나 핸드폰 중심으로 만들지 않는다.
- 4컷씩 나누어 테스트하고, 낮은 점수 컷만 다시 만든다.
- 힉스필드는 품질 기준으로만 참고하고, 기본 제작은 넥서스 GPU와 ComfyUI 쪽으로 옮긴다.

## 참고 우선순위

생성할 때는 아래 순서를 고정한다.

1. `pinterest_images`: 1차 참고. 원하는 실사 톤, 배경, 정면 구도, 자연스러운 생활감을 본다.
2. `source_room`: 2차 참고. 말 그대로 소스방이다. 만들고자 한 원천 소스, 기준 얼굴, 실제 대상 장면을 둔다.
3. `higgsfield_results`: 3차 참고. 마지막 완성도 기준으로만 본다. 빛, 감정선, 영상 분위기, 움직임의 완성도를 맞추는 역할이다.

소스방은 스타일 참고방이 아니다. 실제 만들 대상의 원천 자료를 넣는 방이다.

## 컷별 통과 기준

- `90점 이상`: 최종 후보. 바로 리뷰 가능.
- `80-89점`: 테스트 가능. 얼굴이나 손을 눈으로 확인해야 한다.
- `70-79점`: 수정 권장. 프롬프트나 기준 이미지를 보강한다.
- `69점 이하`: 재작성 필요.

## 자동 점검 항목

- 기준 얼굴 이미지가 있는가.
- 실사 사람 기준이 명확한가.
- 정면 또는 살짝 정면 구도인가.
- 핸드폰이 중심이 되지 않는가.
- 움직임, 카메라, 조명, 소리 설명이 있는가.
- 침대, 샤워, 수영장, 의상 컷에 안전 문구가 있는가.
- 프롬프트가 `보존`, `움직임`, `카메라`, `조명`, `소리`, `금지` 구조를 갖는가.

## 프롬프트 구조

각 컷 프롬프트는 아래 순서를 따른다.

1. 의도: 7초 세로 실사 영상.
2. 보존: 기준 얼굴, 피부 결, 머리, 옷, 손 모양 유지.
3. 장면: 인물, 구도, 장소, 행동.
4. 움직임: 눈 깜빡임, 호흡, 옷감, 배경 움직임.
5. 카메라: 느린 접근, 느린 이동, 초점 이동 중 하나.
6. 조명: 실제 촬영처럼 얼굴과 배경에 닿는 빛.
7. 소리: 공간음과 소품 소리.
8. 제한: 글자, 로고, 자막, 얼굴 변형, 손 왜곡, 선정적 노출 금지.

## 테스트 절차

1. 작업표를 불러온다.
2. `다시 계산`으로 품질 평균과 컷별 점수를 확인한다.
3. 80점 미만 컷은 장면 설명을 고친다.
4. `준비 압축파일`로 컷별 프롬프트를 묶는다.
5. 넥서스에서 `엔진 확인`으로 ComfyUI와 GPU 상태를 확인한다.
6. 모델 파일이 준비된 뒤 4컷씩 생성한다.
7. 결과 영상은 얼굴 동일성, 피부, 손, 배경 움직임, 자막 없음, 로고 없음 순서로 본다.

## 현재 넥서스 상태

- ComfyUI 실행 확인 가능.
- GPU: NVIDIA GB10.
- PyTorch CUDA 사용 가능.
- 모델 폴더는 비어 있으므로 실제 고품질 생성 전 체크포인트와 영상 워크플로 모델을 넣어야 한다.
