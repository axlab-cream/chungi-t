# ComfyUI 모델 체크포인트

넥서스 ComfyUI에서 실제 표정 변화와 작은 몸동작을 생성하기 위해 Wan 2.1 이미지-투-비디오 모델 세트를 설치했습니다.

## 현재 반영 상태

| 역할 | 모델 | 위치 | 용도 |
|---|---|---|---|
| 생성 모델 | `wan2.1_i2v_480p_14B_fp16.safetensors` | `models/diffusion_models/` | 사진 1장을 7초 영상 움직임으로 생성 |
| 문장 이해 모델 | `umt5_xxl_fp8_e4m3fn_scaled.safetensors` | `models/text_encoders/` | 프롬프트 의미 해석 |
| 이미지 참고 모델 | `clip_vision_h.safetensors` | `models/clip_vision/` | 원본 이미지 인물과 분위기 참고 |
| 영상 복원 모델 | `wan_2.1_vae.safetensors` | `models/vae/` | 생성된 잠재 영상을 실제 프레임으로 복원 |

설치 경로:

```text
/home/creamboss/project/comfyui-umsh/ComfyUI/models
```

다운로드 캐시:

```text
/home/creamboss/project/comfyui-umsh/hf-cache
```

모델 파일은 캐시에 보관하고 ComfyUI 모델 폴더에는 심볼릭 링크로 연결했습니다. 같은 모델을 다시 받을 때 중복 용량을 쓰지 않기 위함입니다.

## 선택 이유

- `i2v`: 사용자가 올린 이미지를 기준으로 영상을 만들기 위한 방식입니다.
- `480p`: 7초 세로 테스트와 반복 개선 속도를 우선한 기본 모델입니다.
- `14B fp16`: 표정, 손, 옷감, 조명 같은 실사 품질을 최대한 확보하기 위한 고품질 체크포인트입니다.
- `720p` 모델은 더 무겁고 느리므로, 현재는 품질 기준선이 부족할 때 추가 설치 대상으로 둡니다.

## 앱 반영

영상 제작기 화면의 `엔진 확인` 버튼은 이제 ComfyUI 실행 상태와 함께 모델 개수를 보여줍니다.

표시는 아래처럼 나와야 합니다.

```text
모델: 전체 4개 / 생성 1개 / 문장 1개 / 이미지 참고 1개 / 복원 1개
```

생성 모델이 `0개`로 나오면 `models/diffusion_models/` 안에 `.safetensors` 파일 또는 링크가 없는 상태입니다.

## 다음 품질 단계

1. 현재 480p 모델로 1컷 7초 영상을 먼저 생성합니다.
2. 얼굴 동일성, 손가락, 옷감, 실제 사람 느낌, 움직임 과장을 확인합니다.
3. 기준 미달이면 프롬프트와 샘플 수를 조정합니다.
4. 속도보다 품질이 더 중요해지는 컷만 720p 모델 추가 설치를 검토합니다.
