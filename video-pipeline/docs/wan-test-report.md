# Wan 2.1 ComfyUI 테스트 보고

테스트 기준일: 2026-09-05

## 설치 상태

넥서스 ComfyUI에서 체크포인트 4개가 정상 감지됩니다.

```text
전체 4개 / 생성 1개 / 문장 1개 / 이미지 참고 1개 / 복원 1개
```

## 테스트 입력

- 입력 이미지: 카페에 앉아 있는 20대 후반 한국인 여성 실사 이미지
- 목표: 사진 1장을 기준으로 실제 표정 변화와 작은 몸동작이 있는 세로 영상 생성
- 모델: Wan 2.1 I2V 480p 14B fp16
- 출력 형식: WebM, 480x832, 12fps

## 결과

| 테스트 | 조건 | 출력 길이 | 생성 시간 | 결과 |
|---|---:|---:|---:|---|
| 풀 7초 기준 | 81프레임, 20스텝, fp16 로딩 | 6.75초 | 981초 | 성공 |
| 빠른 확인 기준 | 33프레임, 12스텝, fp8 로딩 | 2.75초 | 190초 | 성공 |

풀 7초 기준은 첫 실행 모델 로딩 시간이 포함되어 있습니다. 그래도 운영 기준으로 보면 1컷 약 16분은 느린 편입니다.

## 품질 체크

| 항목 | 평가 | 메모 |
|---|---|---|
| 실사감 | 통과 | 웹툰/그림체로 무너지지 않고 실사 질감 유지 |
| 얼굴 동일성 | 보통 | 전체 인상은 유지되지만 중간 프레임에서 얼굴이 조금 부드러워짐 |
| 표정 변화 | 통과 | 정면 응시에서 시선이 아래로 내려가는 변화가 자연스러움 |
| 몸동작 | 보통 | 큰 몸동작보다는 작은 손/컵 움직임 중심 |
| 손/소품 | 보통 | 큰 손가락 오류는 없지만 컵 주변 디테일은 더 엄격한 검수 필요 |
| 배경 안정성 | 통과 | 카페 배경과 창밖 비 오는 분위기 유지 |
| 광고 완성도 | 보통 | 자연스러운 실사 테스트로는 가능하지만, 힉스필드처럼 장면 감정선이 풍부하진 않음 |

## 힉스필드 기준 대비

| 기준 | ComfyUI Wan 2.1 현재 | 힉스필드 기준 |
|---|---|---|
| 비용 | 로컬 GPU라 컷당 외부 크레딧 없음 | 컷마다 크레딧 사용 |
| 속도 | 7초 1컷 약 16분 | 보통 더 빠르고 대량 작업 관리가 쉬움 |
| 실사감 | 기준 통과 | 기준 통과 |
| 얼굴 보존 | 약간 흔들림 | 더 안정적인 편 |
| 연출력 | 정적인 사진에 생명감 부여 | 감정선, 카메라, 분위기 연출이 더 강함 |
| 반복 개선 | 비용 부담은 낮음, 시간 부담 큼 | 시간은 낫지만 비용 부담 있음 |

현재 결론은 “무료 자체 생성 가능성은 확인, 최종 광고 완성도는 힉스필드보다 한 단계 낮음”입니다.

## 다음 개선 방향

1. 7초 최종용은 `81프레임 / 16스텝 / fp8_e4m3fn`부터 다시 테스트합니다.
2. 얼굴 보존 문구를 더 강하게 하고, 과한 표정 변화 대신 눈깜빡임·호흡·미세한 시선 변화로 제한합니다.
3. 손이 컵이나 카드와 만나는 컷은 움직임을 더 줄입니다.
4. 최종 후보 컷은 2개 시드 이상 생성해 얼굴 안정성이 좋은 결과만 채택합니다.
5. 480p 결과가 충분하면 후처리 업스케일을 붙이고, 부족하면 720p 체크포인트 추가 설치를 검토합니다.

## 반영된 고도화

- `final_7s`: 81프레임, 20스텝, fp16 로딩. 품질 우선 최종 후보용입니다.
- `balanced_7s`: 81프레임, 16스텝, fp8 로딩. 운영 기본 후보입니다.
- `fast_check`: 33프레임, 12스텝, fp8 로딩. 구도와 얼굴 흔들림 확인용입니다.
- 준비 압축파일에 컷별 ComfyUI Wan 워크플로우 JSON이 자동 포함됩니다.
- Wan 전용 프롬프트에는 얼굴 동일성, 피부 결, 손가락, 소품 변형 방지, 미세 움직임 제한을 영어로 강하게 고정했습니다.
- 앱 화면에서 ComfyUI 생성 설정을 선택하고 예상 시간을 볼 수 있게 했습니다.
