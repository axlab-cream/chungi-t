# LOVE-SPEED-01 · 금사빠·금사식 모바일 게임

## PRD / 범위
사용자 요청(2026-09-29)이 정본. `/play/love-speed/`에서 20~30초 행동 테스트 → 로그인 → 개인 결과 → 올해 연애운으로 이동한다.
- R1 기존 골드 로고, Black & Gold, 최대 440px 모바일 게임 화면.
- R2 MBTI 16종/모름 → 지정 5문항 4지선다 → 즉시 POP 전환, 중복 탭 방지, 진행률, 모션 축소.
- R3 분석 연출 → 로그인 게이트. 기존 Supabase 세션과 `/signup` 복귀 계약 재사용. 답변은 2시간 동안 sessionStorage에만 유지, 저장 실패 시 로그인 전 안내.
- R4 서버 인증 후 본인 프로필만 조회. 답변 수치 0~100와 4유형 계산; MBTI/사주를 해석에 결합. 사주 미등록·시간 모름은 정확하게 표시. 점수는 오락용 답변 지표이며 미래 확률이 아님.
- R5 공유 URL에는 기본 유형 코드만 포함. 이름/생일/MBTI/답변/개인 점수/사주를 공유하지 않음. 다시하기와 정확한 CTA `https://umsh.kr/love/this-year/01-step-1-story/index.html`.
- R6 별도 `preview.html`은 샘플임을 명시하고 인증·실제 결과와 분리. 실제 모바일 클릭 및 결과 화면 검증.

## 화면 / CTA / 상태
시작(테스트 시작) → MBTI(선택 완료/모름) → 질문(답변 카드/이전) → 분석 → 잠금(로그인하고 결과 열기/재확인) → 결과(자세히 보기/공유/다시하기).
복귀 시 답변 유지. 네트워크 오류는 결과를 만들지 않고 재시도. 401은 로그인, 미등록 사주는 답변+MBTI 결과와 미반영 안내. 공유 취소는 오류로 취급하지 않으며 미지원 브라우저는 복사 또는 선택 가능한 링크 제공.

## 데이터 / 운영 / 갭 감사
신규 DB·결제·관리자 기능 없음. 콘텐츠는 버전 관리되는 코드, 배포 시 반영. 기존 개인정보/약관 링크 사용. 별도 분석 수집 없음(개인 응답 전송은 동일 사이트 인증 API만). SEO는 제목/설명/canonical, 결과/미리보기 noindex. 과학적 진단·연애 예측 표현 금지. 사주를 수치로 변환하는 검증된 규칙은 없으므로 수치는 행동 답변만, 사주·MBTI는 출처 표시한 참고 해석으로 결합한다.
