# Report Design Workspace

## 목적

티저, 해석 목록, 해석 상세 화면을 운영 기능과 분리한 상태로 검토하고 수정한다. 실제 서비스 반영 전 디자인 승인용 기준 화면으로 사용한다.

## 시각 언어

- 배경: 검붉은 흑색 `#080405`
- 본문 표면: `#170c0e`, 강조 표면 `#221315`
- 강조: 황금색 `#e5bc6d`, 경고·브랜드 적색 `#a92e28`
- 제목: 명조 계열, 본문: 고딕 계열
- 모서리: 버튼은 pill, 카드 16~24px
- 본문은 중학생이 한 번에 읽을 수 있는 짧은 문장과 쉬운 풀이 상자를 우선한다.

## 화면별 역할

1. 티저: 한 문장 결론 → 대표 이미지 → 세 가지 핵심 신호 → 다음 행동.
2. 해석 목록: 상태 필터 → 리포트 제목·설명 → 진행률 → 열기 행동.
3. 해석 상세: 대표 이미지 → 쉬운 한 문장 요약 → 흐름 → 확인 기준 → 작은 실천.

## 격리 원칙

`design-workspace/report-pages` 내부 상대 경로만 사용한다. 운영 API, 회원 인증, 주문, 분석, 브라우저 저장소에 접근하지 않는다. 모든 내용은 디자인 확인용 예시임을 화면에 표시한다.

## 2026-09-22 서비스별 검토 상태

- 20개 서비스에 티저·해석 목록·해석 상세 URL을 각각 제공한다.
- `good1621` 보관함에서 본문을 확인한 11종은 비식별·축약 요지로 표시한다. 나머지 9종은 서비스 설명 기반 편집 틀임을 표시한다.
- 공개 유료 서비스 10종은 입력 후 실제 무료 티저 화면까지 확인했다. 작업실에는 운영 티저의 구조·섹션·문구 흐름을 옮기되 개인 입력값은 제거한다. 운영 문구는 중학생이 읽기 쉬운 말로 재작성한다.
- 운영 천명사주 무료 티저에는 한자와 `일간·오행·재성·일지`가, 직장 선택 무료 티저에는 `관록·재백·묘시권`이 남아 있다. 작업실 쉬운말 교체와 별개로 운영 화면 자체의 후속 수정이 필요하다.
- 운영 연락 신호 티저에도 `충·묘유충·도화·홍염·편재·식신·상생` 및 한자가 많이 남아 있다. 결혼궁합과 커플궁합 무료 화면에는 `일간·오행·지지` 등 전문어가 남고, 커플궁합은 입력 요약이 있음에도 `이전 입력을 찾지 못했습니다` 안내를 노출했다.
- 배우자/상대 생년월일이 필요한 서비스는 실제 상대 정보를 받지 못했으므로 임의 개인 정보를 넣지 않는다. 본문과 티저의 검증 상태는 별개로 표시한다.
- 해석 목록과 상세는 원본 결제 결과 전체 복제가 아니라 디자인 검토용 주요 목차와 요약이다.

## 2026-09-22 천명사주 인생 흐름 지도

- 적용 대상은 별도 격리본 `design-workspace/actual-service-pages/review/cmdg-longform.html`이다. 운영 상세·저장 리포트에는 연결하지 않는다.
- 이 지도는 평생운의 상승·하락 점수나 사건 예측 그래프가 아니다. 저장 원문에 있는 큰 흐름·연간 참고점과 실제 조건 입력의 확인 완성도를 분리해 보여 준다.
- `경진 대운`, `2026년 병오`는 레일의 근거 텍스트로, 삼재는 계산값이 없는 상태를 점선·`계산값 미연결`으로 표시한다.
- 재물·보상·관계·연애는 한 문장, 일·직장은 현재와 새 선택 두 문장만 받아 막대를 갱신한다. 막대는 관련 실제 조건 입력이 채워진 비율이며 좋고 나쁨, 금전·승진·연애 결과를 의미하지 않는다.
- 어두운 금색 운명상회 리포트 톤을 유지한다. 세로 레일 하나를 시그니처로 쓰고, 별도의 화려한 라인 그래프·녹적 신호등·임의 연령 축은 사용하지 않는다.
