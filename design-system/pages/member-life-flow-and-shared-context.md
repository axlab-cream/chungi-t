# 회원 대운 흐름·공통 현실 기준

## 목적

저장 해석의 계산 결과를 사실 그대로 읽기 쉽게 보이고, 해석에 필요한 현실 조건은 회원이 한 번만 관리한다.

## 대운 흐름

- 제목: `나의 대운 흐름`
- 보조 문장: 현재 대운·현재 연도 간지(서버가 실제 계산해 준 값)를 그대로 표시한다.
- 본문: 10개 대운을 나이 범위·시작 연도·간지로 나열하고 현재 구간만 금색 테두리와 `현재` 라벨로 구분한다.
- 접근성: 각 항목에 숫자/글자 라벨을 함께 두어 색만으로 현재 위치를 구별하지 않는다.
- 금지: 상승/하락 선, 성공 확률, 예측 점수, 계산되지 않은 삼재 표기.

## 현실 기준

- 프로필 화면에서만 입력한다. 저장 해석 화면에는 입력 폼을 반복하지 않는다.
- 항목: 일·직장, 재물·보상, 관계·연애, 계획 기준. 각 항목은 한 문장(최대 180자)이다.
- 빈 상태: `아직 등록한 현실 기준이 없습니다. MY에서 한 번 등록하면 이후 해석에서 다시 사용합니다.`와 프로필 링크.
- 저장 상태: 리더에는 등록한 항목만 읽기 전용으로 표시한다.

## 데이터 표현 원칙

- 리포트의 `fortune` 계산 결과와 회원이 직접 적은 현실 기준을 시각적으로 분리한다.
- 현실 기준은 판단 근거 보조용이며, 유지·이직·수입·관계 결과를 자동 판정하지 않는다.
