# 운영 관리자 화면 시스템

## 화면 목적

운영자가 주문·고객·콘텐츠·AI 생성·시스템 상태를 같은 좌측 LNB에서 빠르게 이동하며 확인하는 관리 화면이다. 데이터가 아직 연결되지 않은 영역은 임의 지표 대신 명시적인 빈 상태로 표시한다.

## 토큰

- 배경 `#f6f6f8`, 표면 `#ffffff`, 구분선 `#dfdfe4`
- 본문 `#1b1b1f`, 보조 텍스트 `#5b5b63`, 비활성 `#8a8a93`
- 주 행동/포커스 `#1f4fd8`, 정상 `#1f6f3f`, 주의 `#8a5a00`, 오류 `#a3231f`
- 본문은 시스템 산세리프, 수치·금액은 tabular numeral을 사용한다.

## 레이아웃

- 데스크톱: 232px 고정 좌측 LNB, 우측에 헤더와 콘텐츠 영역.
- 모바일(768px 이하): 수평 스크롤 LNB와 2열 KPI.
- 목록은 카드가 아닌 표를 기본으로 하며, 작은 화면에서는 표 컨테이너만 가로 스크롤한다.

## 공통 상태

- 지표를 집계하지 못했을 때 `0`을 표시하지 않고 `— / 데이터 연동 대기`를 표시한다.
- 빈 목록, 필터 결과 없음, 조회 실패, 권한 없음은 각각 다른 문구와 상태로 표시한다.
- 아직 연결되지 않은 변경 CTA는 `aria-disabled`와 이유를 함께 제공하며, 성공한 것처럼 보이지 않는다.

## 미디어 운영

- 업로드 폼은 목록 위 한 섹션에만 두고 `업로드 주소 발급 → private Storage 전송 → 서버 원본 검사 → 등록` 상태를 실제 순서대로 설명한다.
- 파일, 대체 텍스트, 권리 근거 유형·증빙을 필수로 하고 영상에는 승인된 이미지 poster 선택을 요구한다.
- 승인된 Storage 자산만 짧은 signed preview를 제공한다. 정적 배포 자산은 기존 `/assets` URL을 유지하며 둘을 같은 표에서 출처와 상태로 구분한다.
- 참조 중인 자산의 삭제 버튼은 비활성화하고, 서버의 원자적 참조 검사가 다시 거절할 수 있음을 문구로 알린다.
- 768px 이하에서는 업로드 입력을 1열로 바꾸고 넓은 자산 표만 내부 가로 스크롤한다.

## 검증 기준

- 1440px, 1024px, 768px, 390px에서 LNB·표·긴 한국어 텍스트가 페이지 전체를 넘치지 않아야 한다.
- 키보드 포커스, 색 이외의 상태 라벨, 비활성 CTA 의미를 확인한다.
