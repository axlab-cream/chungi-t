# 운영 관리자 화면 시스템

## 고객 해석 공통 템플릿

저장 해석은 `사주/data/longform-blocks.json`을 단일 계약으로 사용한다. 20개 서비스 모두 결론·요약·하이라이트, 실제 만세력 흐름, 확장형 본문을 공유하되, 서비스마다 설정한 `accent`, `thumbnail`, `cutA`, `cutB`, 읽기 안내 표의 문구만 달라진다. 대표 이미지는 메인 카드의 썸네일을 그대로 우선 사용하고, 이어지는 장면은 기존 공개 실사 자산을 쓴다. 회원별 계산값이 없는 점수·그래프·조건은 만들지 않는다.

- 첫 번째 해석 토글: 메인과 같은 서비스 대표 썸네일 → 한 줄 답 → 서비스 읽기 안내 표 → 저장 원문 순서.
- 이후 토글: 서비스별 실사 A/B 컷을 교차해 쓴다. 저장 리포트의 항목별 이미지가 있으면 그것을 우선한다.
- 흐름 그래프: 저장 리포트 `analysis.fortune.daewoon`이 있을 때만 표시하며, 결과·성공률 점수가 아니라 힘을 쓰기 쉬운지와 속도를 조절할지를 읽는 기준으로 라벨링한다.
- 모든 토글은 `펼치기 +`/`접기 −`를 텍스트로 함께 제공하고 키보드 포커스를 보여 준다.

고객 퍼널의 입력·버튼 키트는 `design-system/customer-kit.md`와 `사주/css/umsh-kit.css`를 본다. 이 문서는 관리자 `/admin` 전용이다.

## 화면 목적

운영자가 주문·고객·콘텐츠·AI 생성·시스템 상태를 같은 좌측 LNB에서 빠르게 이동하며 확인하는 관리 화면이다. 데이터가 아직 연결되지 않은 영역은 임의 지표 대신 명시적인 빈 상태로 표시한다.

## 토큰

- 배경 `#f6f6f8`, 표면 `#ffffff`, 구분선 `#dfdfe4`
- 본문 `#1b1b1f`, 보조 텍스트 `#5b5b63`, 비활성 `#8a8a93`
- 주 행동/포커스 `#1f4fd8`, 정상 `#1f6f3f`, 주의 `#8a5a00`, 오류 `#a3231f`
- 본문은 시스템 산세리프, 수치·금액은 tabular numeral을 사용한다.

## 레이아웃

- 데스크톱: 232px 고정 좌측 LNB, 우측에 헤더와 콘텐츠 영역.
- 모바일(768px 이하): 수평 스크롤 LNB와 2열 KPI.
- 목록은 카드가 아닌 표를 기본으로 하며, 작은 화면에서는 표 컨테이너만 가로 스크롤한다.

## 공통 상태

- 지표를 집계하지 못했을 때 `0`을 표시하지 않고 `— / 데이터 연동 대기`를 표시한다.
- 빈 목록, 필터 결과 없음, 조회 실패, 권한 없음은 각각 다른 문구와 상태로 표시한다.
- 아직 연결되지 않은 변경 CTA는 `aria-disabled`와 이유를 함께 제공하며, 성공한 것처럼 보이지 않는다.

## 검증 기준

- 1440px, 1024px, 768px, 390px에서 LNB·표·긴 한국어 텍스트가 페이지 전체를 넘치지 않아야 한다.
- 키보드 포커스, 색 이외의 상태 라벨, 비활성 CTA 의미를 확인한다.
