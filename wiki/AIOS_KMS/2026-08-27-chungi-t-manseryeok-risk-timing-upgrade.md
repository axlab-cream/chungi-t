# AIOS KMS 기록: chungi-t 만세력 엔진 및 위험/시기 해석 보강

작성일: 2026-08-27  
상태: 확인됨

## 요청

사주 시스템의 RAG/코퍼스 보강에 이어 만세력 엔진까지 포함해 품질을 높이고, 좋은 말뿐 아니라 안 좋은 흐름도 과감하게 표현하되 그것을 언제 어떻게 풀 수 있는지 시기적으로 설명하도록 개선한다. GBR(Graph-Based Retrieval/Graph Boosted Ranking) 추가 여부도 판단한다.

## 적용 내용

| 영역 | 변경 |
|---|---|
| 한국 음력 변환 | `korean-lunar-calendar@0.4.0` 추가. 음력 입력은 한국 음력 기준 양력일로 변환한 뒤 사주를 계산 |
| 절기 경계 | `lunar-typescript@1.8.6`의 24절기 테이블을 사용. 중국 표준시 표기를 UTC로 환산하고 KST 출생 시각과 비교 |
| 년주/월주 | 입춘 및 월절 기준으로 년주와 월주를 계산. 입춘 전후 경계 테스트 추가 |
| 월간 계산 | 오호둔 월간 계산에서 `丑`월 같은 입춘 직전 월이 틀어지지 않도록 12개월 순환 오프셋 적용 |
| 지장간 | 12지지 지장간과 가중치를 추가하고 오행 강약 계산에 반영 |
| 십신 | 단순 인덱스 차이 방식에서 오행 생극 + 음양 기준 방식으로 수정 |
| 합충형파해 | 천간합, 육합, 충, 형, 파, 해 감지 메타를 `manseryeok.interactions`에 저장 |
| 대운 | 순행/역행, 시작 나이, 시작 나이 텍스트(`약 n년 n개월 n일`), 현재 대운, 10개 대운 흐름 제공 |
| 리포트 말투 | 안 좋은 패턴을 숨기지 않고 선명하게 경고하도록 템플릿과 OpenAI 보강 프롬프트 수정 |
| 시기 해법 | 위험 신호를 현재 대운 구간, 올해 세운, 전환 신호, 행동 기준과 연결 |
| 회귀 테스트 | 샘플 팔자, 입춘 경계, KST 입춘 시각, 음력 변환, 지장간/십신/대운 메타 테스트 추가 |

## 남은 한계

- 23시 자시의 일주 변경은 야자시/조자시 관례가 갈리므로 아직 옵션화하지 않았다. 현재는 날짜 기준 일주를 기본값으로 사용한다.
- 대운 시작 시기는 `3일=1년, 1일=4개월` 근사 환산을 사용한다. 실서비스에서 95% 이상을 더 강하게 보장하려면 `만 나이/세는 나이`, `대운 시작일 표기`, `성별/관례 선택`을 UI 옵션으로 노출하는 것이 좋다.
- 격국, 조후, 통관, 신살, 납음, 12운성은 아직 1차 메타 수준이며 고급 해석 코퍼스와 계산 모듈을 추가하면 품질을 더 올릴 수 있다.

## GBR 판단

GBR은 추가할 가치가 있다. 다만 지금 즉시 1순위는 아니다.

판단:

- 현재는 만세력 계산, 선택지 컨텍스트 핀, 코퍼스 registry, 섹션별 RAG가 먼저 안정화되었다.
- GBR을 먼저 넣으면 잘못 계산된 명식이나 부정확한 청크 관계가 오히려 더 강하게 증폭될 수 있다.
- 이제 계산 엔진이 올라왔으므로 다음 단계에서 `일간 -> 십신 -> 관계 상태 -> 고민 -> 대운/세운 -> 위험/해법` 그래프를 만들면 검색 정밀도를 95%에서 97%권까지 올릴 가능성이 있다.

권장 순서:

1. 23시 자시 옵션과 대운 시작일 표기 보강
2. 사주 요소 그래프 스키마 정의
3. GBR re-ranker를 topK 후처리로 추가
4. 사용자 선택지별 retrieval regression set 확대

## 근거

- `korean-lunar-calendar`: 한국 음력-양력 변환 라이브러리, KARI 기준 설명이 있는 패키지
- `lunar-typescript`: 절기, 간지, 팔자 API를 제공하는 캘린더 라이브러리
- 24절기 정의: 태양 황경 15도 간격의 절기 경계가 전통 달력과 월절 판단에 사용됨
