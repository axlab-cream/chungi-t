# 집 풍수 공개 보류

## 요청

`/place/home/01-step-1-story/index.html`로 시작하는 집 풍수 서비스를 재공개 전까지 비공개로 전환한다. 구현 코드, 코퍼스, 기존 결과 매핑은 삭제하지 않는다.

## 적용

- 포털의 풍수 필터와 메인 대표 카드를 HTML 주석으로 보존하며 화면에서는 제거했다.
- 서비스 디렉터리와 공개 결제 상품 목록에서 `home_pungsu`를 제외했다.
- `/place/home/*` 직접 진입은 메인으로 돌려보낸다.
- `home_fit` 신규 분석 요청과 `home_pungsu` 신규 주문 생성을 차단한다.
- 기존 생성 코드, 데이터셋 연결, 프롬프트, 코퍼스, 저장 결과의 서비스 매핑은 유지한다.

## 재공개 절차

1. `HOME_FIT_PUBLICLY_ENABLED`를 열고 포털의 풍수 필터·대표 카드 주석을 해제한다.
2. 서비스 디렉터리의 `home_pungsu.hidden`을 제거한다.
3. `PUBLICLY_DISABLED_PRODUCT_KEYS`에서 `home_pungsu`를 제거한다.
4. 전체 QA, 타입 검사, 운영 직접 경로와 포털 노출을 다시 확인한다.

## 검증 기준

- 포털에 집 풍수 카드와 풍수 필터가 렌더링되지 않는다.
- `/api/services`와 `/api/payment/config`에 `home_pungsu`가 없다.
- 직접 주소는 `/`로 302 응답한다.
- 신규 `home_fit` 분석 요청은 404로 거절한다.
- 다른 공개 서비스 링크와 20개 서비스 프롬프트·코퍼스 QA는 그대로 통과한다.
