# 집 풍수 서비스 재공개

## 결정

공개 보류했던 `/place/home/01-step-1-story/index.html` 집 풍수 서비스를 다시 연다. 기존 구현·코퍼스·저장 결과를 그대로 사용하고 다른 서비스의 노출 상태는 변경하지 않는다.

## 복원 범위

- 포털 메인 대표 카드와 풍수 카테고리 필터
- 검색 서비스 디렉터리의 `home_pungsu`
- 공개 결제 상품 목록과 신규 주문
- `/place/home/*` 01~06 직접 경로
- `home_fit` 신규 분석 요청

## 검증 기준

- 집 풍수 시작 페이지가 HTTP 200을 반환한다.
- 포털 렌더링 영역에 `/place/home` 카드와 풍수 필터가 있다.
- `/api/services`와 `/api/payment/config`에 `home_pungsu`가 있다.
- 20개 서비스 QA, 타입 검사, 전체 단위 테스트가 통과한다.
