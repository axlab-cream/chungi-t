# AIOS KMS 기록: chungi-t GBR 및 RAG/코퍼스 활용 품질 평가기 보강

작성일: 2026-08-27  
상태: 확인됨

## 요청

남은 보강 항목인 23시 자시 옵션, 격국·조후·통관, GBR을 추가하고, 현재 풀이가 RAG와 코퍼스를 몇 퍼센트 활용하는지와 각 분류별 말투/LLM 근거 생성 완성도를 평가한다.

## 적용 내용

| 영역 | 변경 |
|---|---|
| 23시 자시 옵션 | `BirthInput.dayBoundaryRule` 추가. 기본은 `midnight`, 선택 시 `zi_hour_next_day`로 23:00~23:59 일주를 다음 날로 계산 |
| 격국 | 월지 주기운의 십신을 기준으로 `manseryeok.gyeokguk` 산출 |
| 조후 | 월지 계절과 가중 오행을 바탕으로 온도/습도/보완 오행을 `manseryeok.climate`에 저장 |
| 통관 | 강한 상극 오행 쌍 사이의 중재 오행을 `manseryeok.flowBridges`로 산출 |
| GBR | `graphBoostTokens`를 RAG scoring에 추가해 일간·오행·십신·관계 상태·대운·세운·격국·조후·통관 연결 청크를 재랭킹 |
| 고급 코퍼스 | `data/corpus/saju-advanced-manseryeok-gbr.json` 추가, registry version `1.1.0` |
| 품질 평가기 | `src/report/report-quality.ts` 추가. RAG 활용률, 코퍼스 연관성, 말투 접지, LLM 근거성, 분류별 완성도 산출 |
| 리포트 payload | `SajuReport.quality`에 평가 결과 저장 |
| 프롬프트 | 격국·조후·통관·지장간·합충형파해·자시 계산 규칙과 RAG 근거를 실제 판단에 녹이도록 지시 강화 |
