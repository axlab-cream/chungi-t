# 신년운세 홈 카드의 COMING SOON 이동

## 요청 / Improvement

- 사용자가 홈 `RELEASED NOW · 지금 열린 운명`의 ‘내 2027년, 풀릴 각이야?’ 카드를 아래 커밍순 영역으로 옮기도록 지정했다.
- 기준 소스는 최신 main을 포함한 `5f20249`. 기존 키·DB·저장 결과·서비스 API는 변경 대상이 아니다.

## Fix / 구현

- `사주/portal.html`: 신년운세 카드를 상단 출시 영역에서 제거하고 `COMING SOON · 곧 다가올 운명`의 첫 번째로 이동했다.
- 기존 결혼택일 카드와 같은 `button.is-soon`, `SOON` 배지 및 ‘준비 중인 서비스’ 접근성 안내를 사용한다. 클릭은 기존 `portal.js`의 준비 중 안내로 연결된다.
- 썸네일·상품명·흐름 분류는 보존했다. 다른 출시 카드 및 결혼택일 순서는 유지했다.
- 직접 서비스 URL, 검색 디렉터리, 결제 카탈로그와 저장 UUID 재조회 경로는 유지한다. 홈 카드의 노출 상태만 바꾼 것이며 전체 서비스를 비활성화한 변경이 아니다.

## Success Case / 검증

- 홈 카드 배치 4개 + 신년 프런트 9개 + 기존 홈 스플래시 1개, 총 14개 테스트 통과.
- `npm run check:newyear`, `npm run vercel-build`, TypeScript 및 diff 검사 통과.
- 이전 검사에 있던 ‘홈 링크/is-live 필수’ 조건은 최신 요청과 충돌하므로, 하단 커밍순에 카드가 한 개만 존재하고 SOON 버튼인지 검증하는 조건으로 교체했다. 서비스·계산·API·코퍼스 연결 검사는 유지했다.

## Theory / REG 재사용

- 홈의 마케팅 노출 상태와 서비스 구현·기존 결과 접근 권한은 별개다. 카드 이동을 이유로 API나 고객의 저장 결과를 삭제하지 않는다.
- 기존 커밍순 컴포넌트와 클릭 처리를 재사용하면 별도 이벤트 핸들러나 CSS 추가 없이 접근성·동작을 일치시킬 수 있다.
- 배포 전 최신 main 포함 여부를 검사하고 Git main 자동 배포의 READY·홈 DOM 위치·준비 중 클릭 동작을 확인한다.
