# 집 풍수 해석 범위 분리 및 데이터 대시보드

## 해석 개선

10개 항목별 질문 범위를 분리했다. 공통 공간 순회·입력값 반복을 줄이고, 사주·기준 연도의 전통 해석·확인된 집 조건을 연결하도록 지침을 보강했다. 일반 생활 예시는 실제 지역 사례로 쓰지 않는다. 긴 문장 2개 이상을 다른 항목에서 재사용하면 검수에서 감지한다. 이는 의미적 중복을 전부 검출하는 보장은 아니다.

기존 reportId 66770b5c-97b6-4427-aedd-b455a17a4360의 운영 조회는 로컬 서버 자격증명 미설정으로 불가했다. 10개 저장 본문을 전수 조회·수정했다고 주장하지 않는다. 생성 개선은 이후 새 생성에 적용되며 기존 저장 결과를 덮어쓰지 않았다.

## 실제 데이터 가용 범위

사주 elements/fortune 및 home 입력, terrainEvidence 경사·요약은 기존 권한 확인된 응답에서 사용. 현재 dataset-client는 출처·시기·관찰 결과가 있는 지역 사례나 사례 유사도 점수를 전달하지 않으므로 실제 지역 사례를 새로 만들어 넣지 않는다.

## 대시보드

05 목차와 06 상세에 접기 가능한 대시보드 추가. 총평에서 처음 열림. 오행 비중 막대그래프, 생활 조건 비교표/상세 링크, 경사 수치/meter, 기준 연도와 세운, 입력 충족도 표시. 입력 충족도는 6개 정보의 입력 비율이며 궁합 점수가 아니다. 궁합 총점·다른 집 순위·주택 오행값은 근거 없이 만들지 않는다. 출생시간 미상 시 오행 차트 숨김. 계산값 누락/잘못된 경사/사용자 HTML 안전 처리.
